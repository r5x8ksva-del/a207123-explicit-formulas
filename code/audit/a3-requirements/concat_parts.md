### C-3　整张表的母函数与 D-finite 判定

> 环的约定：𝓟 = Q[[x,t]]。λ := (1−x)/x³，a := −t/x³。₁F₁(α;β;z)=Σ_n (α)_n z^n/((β)_n n!)，参数 β∈Q(x)（如 β=j+1−λ）时各 (β)_n≠0，所以 ₁F₁(…;a) 是 Q(x)[[t]] 的元素。关键恒等式 (j+1−λ)_n = (−1)^n x^{−3n}∏_{i=j+1}^{j+n} b_i。

**T3.1（「不以上升结尾」部分 = ₁F₁）【已证明】** 在 Q(x)[[t]] 中
  Σ_{m≥0} t^m/P_m = ₁F₁(1; 1−λ; −t/x³) / (1−x)，
每个 t^m 系数 1/P_m 属于 Z[[x]]，所以恒等式实际落在 Z[[x,t]] 中；[x^k t^m] 右边 = 不以上升结尾的合法序列数 Σ_s S(m+s,m)C(k+m−2s,k−3s)。还有：Kummer 形式 ₁F₁(1;1−λ;a)=e^a·₁F₁(−λ;1−λ;−a) 与下不完全 Gamma 形式 Σ_m t^m/P_m = −x^{−3}e^a·a^λγ(−λ,a)（a^λγ(−λ,a) := Σ_n(−a)^n/(n!(n−λ)) 作形式定义）也成立，**但只在 Q(x)[[t]] 中成立**：单个因子 e^a 的 t^n 系数 (−1)^n x^{−3n}/n! 在 x=0 有极点，不能逐因子放进 Q[[x,t]]。
证明：(1−λ)_n=(−1)^nx^{−3n}∏_{i=1}^{n}b_i，代入 t^n 系数即得 1/P_n。Kummer 形式比较 a^n 系数，归结为 Q(λ) 中 1/∏_{j=0}^{n}(λ−j) 的部分分式恒等式，再用 λ↦(1−x)/x³ 是单同态。∎
核对：c3a.c3a-1f1-const（Pochhammer 按 x 的 Laurent 级数逐因子展开，负幂全部消去，非负幂等于按 s 细化 DP 的完整序列数，k≤40,m≤20）、c3a.c3a-1f1-exact、c3a.c3a-1f1-stirling、c3a.c3a-kummer、c3a.c3a-gamma、c3a.c3a-1f1-shift。

**T3.2（F 的形式 Laplace 表示；一般原理）【已证明】**
陈述：设 A∈Q[[x]]，A(0)=1，L_A[Y]:=(A−t)Y−x³t∂_tY。则 (i) L_A 是 𝓟 上的双射（形式环里齐次方程只有零解）；(ii) 对任意 γ∈𝓟，L_A[Y]=γ 的唯一解是
  Y = A^{−1}·ℒ_s[ exp((t/x³)(e^{vs}−1))·γ(x, t e^{vs}) ]，v=x³/A，ℒ_s[s^N]:=N!（逐系数）。
特别地（A=1−x，γ=1+x²t/(1−t)²，u=x³/(1−x)）：
  **F(x,t) = (1/(1−x))·ℒ_s[ exp((t/x³)(e^{us}−1))·(1 + x²·t e^{us}/(1−t e^{us})²) ]。**
ℒ_s 的含义：对 Ψ=Σ_N Ψ_N s^N∈𝓟[[s]] 且 ord_{(x,t)}Ψ_N→∞，ℒ_s(Ψ):=Σ_N N!Ψ_N（每个单项式 x^kt^m 只在有限个 Ψ_N 中出现）。良定义靠赋值界：[s^N]被积式的 (x,t)-阶 ≥N，更细地 [s^N t^m] 的 x-赋值 ≥3N−3m，所以 [x^kt^m] 只涉及 N≤k/3+m（注：「(e^{us}−1)/x³ 是 u 的幂级数」本身不足以保证良定义）。
证明：(i) 系数式 y_{k,m}=γ_{k,m}−Σ_{i≥1}A_iy_{k−i,m}+y_{k,m−1}+m y_{k−3,m}，按 k+m 归纳唯一确定。(ii) 记 Ψ=Φ_A·γ(x,te^{vs})，直接求导得 x³t∂_tΨ=A∂_sΨ−tΨ，即 (A−t)Ψ−x³t∂_tΨ=A(Ψ−∂_sΨ)；两边作用 ℒ_s，用形式分部积分 ℒ_s[∂_sΨ]=ℒ_s[Ψ]−Ψ|_{s=0} 与 ℒ_s∂_t=∂_tℒ_s，得 L_A[ℒ_sΨ]=Aγ。∎ 由此还可逐系数取出 [t^m]F=1/P_m+x²Σ_j j/∏_{i=j}^{m}b_i（T2.2 的第二个独立证明：ℒ_s[e^{jus}(e^{us}−1)^n/n!]=u^n/∏_{i=j}^{j+n}(1−iu)）。
核对：c3a.c3a-lap-F（EGF 记法全程整数精确展开，对照 DP，k≤60,m≤30）、c3a.c3a-lap-naive（独立朴素实现，k≤15,m≤6）、c3a.c3a-lap-general（6 个随机右端、两种 A）、c3a.c3a-lap-operator、c3a.c3a-lap-coeff（k≤60,m≤30）。

**T3.3（整张表的 ₁F₁ 和式与 Humbert 有限闭式）**

**T3.4（解析版本：积分与 Σ_m t^m G_m(x) 的关系）**

**T3.7（F 与 𝒩 都不是 D-finite）【已证明】**（提示词要求「猜不到只能报告没找到」；这里不是靠猜不到，而是给出了证明）
陈述：(1) 不存在不全为 0 的 p_0..p_r∈C[x,t]（甚至 C[x][[t]]）使 Σ_j p_j ∂_x^j F=0；所以 F 不是 D-finite（Lipshitz 1989 Def. 2.1：全部偏导数在 C(x,t) 上张成有限维空间 ⇒ 每个变量都有多项式系数 ODE）。(2) 推论：不存在系数只依赖 k 的多项式、在某个象限 k≥k_0,m≥m_0 上成立的非平凡递推 Σ_{a≤A,b≤B}p_{ab}(k)U_{k−a}(m−b)=0。(3) 𝒩 同样不是 D-finite，N 也没有只依赖 k 的象限递推。

核对：proof-only；其组成部分由 c3b.C3B-CUB（ρ_i 唯一实根、单调、复根模长，i≤60）、c3b.C3B-PX、c3b.C3B-RES（留数非零）、c3b.C3B-GCD1/2/3、c3b.C3B-PSI 等核对。

## ③ 最终推荐的显式公式（一页）

**公式（全正项，两层和）**　对 k≥0、m≥0：

  U_k(m) = Σ_{s=0}^{⌊k/3⌋} S(m+s, m)·C(k+m−2s, k−3s)　+　Σ_{j=1}^{m} j·Σ_{s=0}^{⌊(k−2)/3⌋} H(m,s,j)·C(k−2+m−j−2s, k−2−3s)，

其中 S 为第二类 Stirling 数，H(m,s,j) := h_s(j, j+1, …, m) = Broder r-Stirling 数 {m+s ⧵ m}_j（r=j）。约定 C(a,b)=0 除非 0≤b≤a；k<2 时第二项为空。

**H 的计算**：递推 H(m,s,j) = H(m,s,j+1) + j·H(m,s−1,j)，H(m,0,j)=1，H(m,s,m+1)=[s=0]；或完全显式 H(m,s,j) = (1/(m−j)!)·Σ_{i=0}^{m−j}(−1)^{m−j−i}C(m−j,i)(j+i)^{s+m−j}（代价是变成三层交错和）。

**组合意义（每一项都可数）**：合法序列 = 块词（单块 [v]、三块 [a,v,v]（a<v）按层弱降排列，末尾可再接一个截断块 [a,j]），见 T2.1。
- 第一项 = 不以上升结尾的序列；对每个 s（= 上升数 = 三块数）是**单项**：在 k+m−2s 个位置中选 S 的位置 × [m+s] 分成 m 块的集合划分。
- 第二项 = 以截断块 E_j 结尾的序列：j 是 E 的谷的选法，H(m,s,j) 是 E 左侧 s 个三块的加权数，二项式是 S 只能放在 E 左侧的放法。
- 按上升数细化：U_k(m,s) = S(m+s,m)C(k+m−2s,k−3s) + Σ_{j=1}^{m} j·H(m,s−1,j)·C(k+m−j−2s, k+1−3s)。

**等价形式**：
- 单和减双和（无权重 j）：U_k(m) = Σ_s S(m+s,m)C(k+1+m−2s, m+s) − Σ_{j=1}^{m}Σ_s H(m,s,j)C(k+m−j−2s, m−j+s)。提示词 (C4) 的 Θ 公式与这一形式逐项相同（每个 Θ_t 就是一个 j=m−t 的正项单和）。
- 母函数：Σ_k U_k(m)x^k = W_m/P_m = 1/P_m + x²Σ_{j=1}^{m} j/∏_{v=j}^{m}(1−x−v x³)。
- 以线性递推序列 c_i(n)=[x^n]1/(1−x−ix³) 为原子：m!·U_k(m) = Σ_{i=0}^{m}(−1)^{m−i}C(m,i)[c_i(k+3m) + Σ_{j=1}^{i} j·i^{\underline j}·c_i(k+3m−3j−2)]（只除一次 m!；如 R_k=c_1(k+3)+c_1(k−2)−1）。

**与 (C4) 双和公式的比较**

| | 推荐式（H 型） | (C4) Θ 型 |
|---|---|---|
| 层数 | 2（原子 H 用递推表）；完全展开为 3 | 2（原子 c_i）；完全展开为 3 |
| 项数 | ≈(m+1)·k/3 个「r-Stirling × 二项式」 | ≈m²/2 个 c 值，c 共 ≈m²k/6 项 |
| 符号 / 除法 | 全正、无除法 | 交错，除以 t!（m+1 次） |
| 抵消 | 无 | 有：k=m=100 时 U 有 99 位，中间单项最大 289 位（约 3 倍长） |
| 实测单值（原子都用递推） | (300,300) 0.255 s；(1500,30) 0.294 s；(3000,3) 0.156 s | (300,300) 0.289 s；(1500,30) 0.020 s；(3000,3) 0.003 s |
| 实测单值（原子都用显式和） | (300,300) 17.5 s | (300,300) 138 s |

**何时用哪种方法计算**（实测见 T2.9）
- **整张表**（所有 k≤K、m≤M）：用引理 1 三项递推 U_k(m)=U_k(m−1)+U_{k−1}(m)+mU_{k−3}(m)，O(KM)，比任何显式公式快 300–1000 倍。
- **需要按上升数分层、或需要正项/组合意义**：用推荐式，O(mk) 次大整数运算。
- **单个值的最快显式算法**：m≪k 时用 Θ 型或 c_i 偏分式型，且 c_i(n) 用三项递推 c(n)=c(n−1)+i·c(n−3) 计算（(1500,30) 时比 H 型快约 15 倍）；m≈k 时两者同量级。（第一轮曾建议「m 大时不要用 Θ 型」，那是原子算法不对等造成的误判，已由第二轮复核更正。）
- **m 小、k 极大**：固定 m 的 3m+1 阶常系数递推（特征多项式恰为 P_m，T1.3(2)；可配合矩阵幂）。
- **k 小、m 极大或要 m 的多项式**：N 三角（O(k²)）后 U_k(m)=Σ_q N(k,q)C(m+1,q)。

**不能再短（在明确的意义下）**：由 T2.6（已证明），对每个 m≥1 不存在系数与 k 无关的「单族 Stirling×二项式」单和 Σ_s A(s)C(k+c−2s, m+s+d)；以上升结尾的那一族正是障碍。由 T3.7，F 不是 D-finite，所以也不存在真超几何项的有限多重和表示（该推论引用文献定理）。

## ④ 失败或未解决的方向

**A. 没做成的数学（如实记录试了什么、卡在哪里）**
