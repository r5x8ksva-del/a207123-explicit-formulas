## 0. 记号与约定

- 合法序列：h = (h_1,…,h_k) ∈ {0,…,m}^k，每个相邻三元组 (a,b,c) 都满足"b=c 或 a ≥ max(b,c)"。合法序列的个数记为 U_k(m)，U_0 ≡ 1。
- N(k,q)：值域恰为 {1,…,q} 的合法词的个数。N(0,0)=1；当 q>k 或 q<0 时 N(k,q)=0；k≥1 时 N(k,0)=0。
- b_i(x) = 1 − x − i x³；P_m = ∏_{i=0}^{m} b_i，P_{−1} = 1；G_m(x) = Σ_{k≥0} U_k(m) x^k；W_m := 1 + x² Σ_{j=1}^{m} j P_{j−1}。
- f_j(y) = y³ − y² − j，Z_j = {f_j 的三个根}（j≥1），Z_0 = {1}。ρ_j 是 f_j 的实根，ρ_0 := 1；e_n(u) := Σ_{i=0}^{n} u^i/i!，e_{−1} := 0。
- c(n,k)：无符号第一类 Stirling 数。m^{\underline j} = m(m−1)…(m−j+1)。
- D(k,d) := N(k,k−d)。
- h_k(t)：由 Σ_{m≥0} U_k(m) t^m = h_k(t)/(1−t)^{k+1} 定义；h_{k,i} := [t^i]h_k。
- "多项式恒等式的有限次核对即证明"：若两边都已证明是次数 ≤ D 的多项式，那么在 D+1 个点上相等就推出恒等。下文凡写"（多项式比较）"的地方都用这一原则，并注明程序核对了多少个点。

## 1. 预备引理（本节全部自证；后文只用这里的结论）

### 引理 1.1（三项递推）【已证明】[c5a-lemma1-Gm]
对 k≥1、m≥0：U_k(m) = U_k(m−1) + U_{k−1}(m) + m·U_{k−3}(m)，约定 U_{−1} ≡ 1，U_{−2} ≡ 0，U_k(−1) = 0（k≥1，"值取自空集"的计数）。

**证明。** 按最大可取值 m 第一次出现的位置 i 分类。
- (i) m 不出现：这样的序列有 U_k(m−1) 个。
- (ii) i=1：任何形如 (m,·,·) 的三元组都合法（a=m≥max(b,c)），所以 h_2…h_k 是任意长 k−1 的合法序列，共 U_{k−1}(m) 个；k=1 时就是 1 个，等于 U_0。
- (iii) i=2：h_1 = a < m，共 m 种取法。
  - k=2：直接 m 种，等于 m·U_{−1}。
  - k≥3：三元组 (a, m, h_3) 合法当且仅当 h_3 = m（因为 a < m 使 a≥max 不成立，只能 b=c）。此后 (m,m,·) 与 (m,·,·) 恒合法，所以 h_4…h_k 是任意长 k−3 的合法序列，共 m·U_{k−3}(m) 个（k=3 时用 U_0=1）。
  - k=1：此情形不存在，对应 U_{−2}=0。
- (iv) i≥3 不可能：三元组 (h_{i−2}, h_{i−1}, m) 中 h_{i−1} < m 使 b≠c，h_{i−2} < m 使 a < max(b,c)。∎

### 引理 1.2（二项式基与多项式性）【已证明】[c5a-lemma1-Gm]
U_k(m) = Σ_{q=0}^{k} N(k,q)·C(m+1,q)（m≥0）。因此 U_k 是 m 的次数 ≤ k 的多项式，下文对任意整数 m 都用这个多项式取值。

**证明。** 合法性只依赖相邻值之间的大小关系（b=c、a≥b、a≥c 都在严格增映射下保持）。一个值域为 S ⊆ {0..m}、|S|=q 的合法序列，经保序重标号后一一对应于值域恰为 {1..q} 的合法词。选 S 有 C(m+1,q) 种。q ≤ k 是因为值域大小不超过长度。∎

（附注：U_k(m) 也是允许行偏序集 P_k 的 zeta 多项式 Z(P_k, m+1)；比较 C(m+1,q) 基的系数可知 N(k,q) 等于 P_k 中长 q 的严格链 0̂=y_0<…<y_q=1̂ 的个数。§4.4 只用到这一点。）

### 引理 1.3（多项式延拓与负 m 的母函数）【已证明】[c5a-lemma1-Gm]
(a) 引理 1.1 作为 m 的多项式恒等式对所有整数 m 成立（U_{−1}≡1、U_{−2}≡0 视为常数多项式）。特别地，多项式值 U_k(−1)=0（k≥1）。
(b) 对一切整数 m，令 G_m(x) := Σ_k U_k(m)x^k（用多项式值），则 (1 − x − m x³)·G_m = G_{m−1} + m x²。

**证明。** (a) 引理 1.1 的两边都是 m 的多项式。当 m≥1 时所有自变量都 ≥0，两边都是组合数，恒等式成立。无穷多点相等，故作为多项式恒等。代入 m=0 并与组合值 U_k(0)=1、U_{k−1}(0)=1 比较，得 U_k(−1)=0（k≥2）；k=1 时 1 = U_1(−1) + U_0(0)，同样得 0。
(b) 把 (a) 按 k 写开：k=1 时 U_1(m) − U_0(m) = U_1(m−1)；k=2 时 U_2(m) − U_1(m) = U_2(m−1) + m；k≥3 时 U_k(m) − U_{k−1}(m) − m U_{k−3}(m) = U_k(m−1)。乘 x^k 求和，并加上 k=0 项 U_0(m) = 1 = U_0(m−1)，即得 (b)。∎

程序核对：(a) 在 k≤60、m∈[−25,60] 上逐点成立；(b) 在 m∈[−20,20]、系数 k≤57 上逐项成立。

### 引理 1.4（G_m 的有理形式）【已证明】[c5a-WP]
对 m≥0：G_m = W_m/P_m，W_m = 1 + x²Σ_{j=1}^m j P_{j−1}。m≥1 时 deg W_m = 3m < deg P_m = 3m+1；G_0 = 1/(1−x)。P_m 无平方因子。

**证明。**
- 由 1.3(b)：G_0 = G_{−1}/(1−x)，而 G_{−1} = Σ_k U_k(−1)x^k = 1（U_0≡1，k≥1 时为 0），所以 G_0 = 1/(1−x)。
- 归纳：设 G_{m−1} = W_{m−1}/P_{m−1}，则 G_m = (W_{m−1} + m x² P_{m−1})/(P_{m−1} b_m) = W_m/P_m。
- 次数：W_m 的最高次项来自 m x² P_{m−1}，次数为 2 + 1 + 3(m−1) = 3m；deg P_m = 1 + 3m。
- 无平方因子：i≥1 时 b_i(x) = x³ f_i(1/x)。f_i 与 f_i' = y(3y−2) 没有公共根，因为 f_i(0) = −i ≠ 0，f_i(2/3) = −4/27 − i ≠ 0；所以 b_i 有三个不同的根，而 b_0 是线性的。i≠j 时 b_i − b_j = (j−i)x³，公共根只能是 x=0，但 b(0)=1。∎

程序核对：W_m/P_m 的级数与 DP 在 m≤20、k≤60 上逐项相等；用精确 gcd 核对 P_m 无平方因子（m≤8）。

### 引理 1.5（N 的三角递推）【已证明】[c5a-Ntri]
对 k≥3、r≥0：N(k,r+1) = N(k−1,r) + N(k−1,r+1) + r·[N(k−3,r−1) + 2N(k−3,r) + N(k−3,r+1)]。

**证明。** 设 q = r+1 是最大值，它第一次出现在位置 1 或 2（理由同引理 1.1(iv)）。
- 位置 1：w_1 = q，w_2…w_k 是合法词，值域为 {1..q} 或 {1..q−1}，共 N(k−1,q) + N(k−1,q−1) 个。
- 位置 2：w_1 = a < q，有 q−1 种取法；k≥3 时必有 w_3 = q，词形为 (a, q, q, T)。T 是长 k−3 的任意合法词，其值域 S 须满足 {1..q−1}∖{a} ⊆ S ⊆ {1..q}。S 有四种取法，大小分别是 q−2、q−1、q−1、q，于是得到 N(k−3,q−2) + 2N(k−3,q−1) + N(k−3,q)。∎

程序核对：与由 DP 容斥得到的 N 比较，3≤k≤60 全部成立；N 本身另与 DFS 定义 `N_brute` 对照到 k≤7 [c5a-anchor]。

## 2. 固定 m、k → ∞

### 引理 2.1（三次方程的根）【已证明】[c5a-roots]
对 j≥1：
- (a) f_j(y) = y³ − y² − j 恰有一个实根 ρ_j，且 ρ_j > 1；另两根 σ_j, σ̄_j 共轭，|σ_j|² = j/ρ_j = ρ_j(ρ_j − 1) < ρ_j²。
- (b) ρ_j 关于 j 严格递增（ρ_0 := 1 与之相容）。
- (c) 对 m≥1，|σ_m|² = m/ρ_m < ρ_{m−1}²。
- (d) |σ_j| 关于 j 严格递增。

**证明。**
- (a) f_j 在 (−∞,0] 上递增到 f_j(0) = −j < 0，在 [0,2/3] 上递减，在 [2/3,∞) 上递增到 +∞，所以只有一个实根；f_j(1) = −j < 0 推出 ρ_j > 1。三根之积为 j，所以 |σ_j|² = j/ρ_j，再用 j = ρ_j³ − ρ_j² 即得后两式。
- (b) g(y) = y³ − y² 在 [1,∞) 上严格递增，而 ρ_j = g^{−1}(j)。
- (c) 只需证 m < ρ_m ρ_{m−1}²。由 ρ_m > ρ_{m−1} 得 ρ_m ρ_{m−1}² > ρ_{m−1}³ = ρ_{m−1}² + (m−1) ≥ 1 + (m−1) = m。这对 m=1（ρ_0 = 1）同样成立。
- (d) |σ_j|² = ρ_j² − ρ_j，而 y² − y 在 y>1/2 上递增。∎

（程序：对 j≤30 用 Sturm 序列精确确认 f_j 只有一个实根且在 (1,∞) 内；不等式另做 decimal 抽查。）

### 定理 2.2（谱分解 / Binet 型精确公式）【已证明】[c5a-binet] [c5a-filter]
对 m≥0、k≥0：

  **U_k(m) = Σ_{j=0}^{m} ((−1)^{m−j}/(m−j)!) · Σ_{σ∈Z_j} γ_j(σ)·σ^{k+3(m−j)}**，

其中 γ_0(1) = 1，j≥1 时对 f_j 的每个根 σ：

  γ_j(σ) = σ·(σ^{3j+1}/j! − e_{j−1}(σ³))/(3σ − 2)
      = [σ^{3j+3}/j! + Σ_{i=0}^{j−1}(j−i)σ^{3i+1}/i!]/(σ² + 3j)
      = g̃_j(σ)/f_j'(σ)，g̃_j(y) := y^{3j+2}/j! + Σ_{i=0}^{j−1}(j−i)y^{3i}/i!。

j=0 项就是 (−1)^m/m!。因为 Σ_{σ∈Z_j} P(σ)/f_j'(σ) = [y²](P(y) mod f_j(y))（Lagrange 插值恒等式，f_j 无重根时成立；j=4、18 时 f_j 可约，但仍无重根），内层和是有理数：

  Σ_{σ∈Z_j} γ_j(σ)σ^n = [y²]( g̃_j(y)·y^n mod (y³−y²−j) )。

由于 [y²](y^n mod f_j) = c_j(n−2) := [x^{n−2}] 1/(1−x−jx³)（完全齐次对称多项式），定理也可以写成只含 c_j 的形式：

  U_k(m) = (1/m!)Σ_{j=0}^{m}(−1)^{m−j}C(m,j)c_j(k+3m) + Σ_{j=1}^{m}Σ_{i=0}^{j−1} [(−1)^{m−j}(j−i)/((m−j)!·i!)]·c_j(k+3(m−j+i)−2)。

上式中 c_0 ≡ 1，n<0 时 c_j(n)=0。第一部分恰好就是提示词 (C4) 中 [x^k]1/P_m 的有限差分公式，所以定理 2.2 与 (C4) 实质上是同一组公式，只是按极点重新组织。例如 m=1 给出 R_k = U_k(1) = c_1(k+3) + c_1(k−2) − 1。

**证明。**
1. 由引理 1.4，G_m = W_m/P_m 是真分式，极点都是单极点，位于 x_σ = 1/σ（σ ∈ ∪_{j≤m} Z_j；b_j(x) = x³f_j(1/x)，b_0 的根是 x=1）。所以 G_m = Σ_σ α_m(σ)/(1 − σx)，即 U_k(m) = Σ_σ α_m(σ)σ^k 对一切 k≥0 成立（真分式没有多项式部分）。
2. 旧极点（σ ∈ Z_j，j<m）：G_m = (G_{m−1} + m x²)/b_m。b_m(x_σ) = b_j(x_σ) − (m−j)x_σ³ = −(m−j)σ^{−3} ≠ 0，所以 m x²/b_m 在 x_σ 解析；若 G_{m−1} = α/(1−σx) + (解析)，则 G_{m−1}/b_m = α/(b_m(x_σ)(1−σx)) + (解析)，因为 (1/b_m(x) − 1/b_m(x_σ))/(1−σx) 在 x_σ 解析。于是 α_m(σ) = α_{m−1}(σ)·(−σ³)/(m−j)，迭代得 α_m(σ) = α_j(σ)·(−σ³)^{m−j}/(m−j)!。对 σ=1（j=0），b_i(1) = −i，同样适用。
3. 新极点（σ ∈ Z_m）：N(x) := G_{m−1}(x) + m x² 是有理函数，在 x_σ 解析（P_{m−1} 与 b_m 互素）。b_m'(x) = −1 − 3m x²。比较 −α x_σ/(x − x_σ) 与 N(x_σ)/(b_m'(x_σ)(x−x_σ)) 得
   α_m(σ) = N(x_σ)/(x_σ(1 + 3m x_σ²))。
   又 N = W_m/P_{m−1}，而 b_i(x_σ) = 1 − x_σ − i x_σ³ = (m−i)x_σ³（用 1 − x_σ = m x_σ³），所以
   P_{j−1}(x_σ) = m^{\underline j}σ^{−3j}，P_{m−1}(x_σ) = m!σ^{−3m}，W_m(x_σ) = 1 + Σ_{j=1}^{m} j·m^{\underline j}·σ^{−3j−2}。
   整理得 α_m(σ) = σ^{3m+1}W_m(1/σ)/(m!(1 + 3mσ^{−2})) = [σ^{3m+3}/m! + Σ_{i<m}(m−i)σ^{3i+1}/i!]/(σ² + 3m)（令 i = m − j）。这就是 γ_m(σ)。j=0 时 G_0 = 1/(1−x)，α_0(1) = 1。
4. 三种形式等价：σ² + 3m = 3σ³ − 2σ² = σ·f_m'(σ) = σ²(3σ−2)，这给出第三种形式。第一种形式来自代数恒等式 g̃_m(y) ≡ y²(y^{3m+1}/m! − e_{m−1}(y³)) (mod f_m)：令 u = y³ = y² + m，则 Σ_{i<m}(m−i)u^i/i! = (u − y²)e_{m−1}(u) − u·e_{m−2}(u) = u^m/(m−1)! − y²e_{m−1}(u)，从而 y²u^m/m! + Σ_{i<m}(m−i)u^i/i! = u^{m+1}/m! − y²e_{m−1}(u)。程序在商环里对 j≤20 精确核对了这一恒等式 [c5a-cm-form]。
5. Lagrange 恒等式：把 R = P mod f 在 f 的三个不同根处做 Lagrange 插值，比较 y² 的系数即得。∎

### 推论 2.3（主项、次项与误差率）【已证明】proof-only（数值见 [c5a-asym-m1..8]）

## 3. 固定 k、m → ∞

### 定理 3.1（近对角线 N(k,k−d) 的多项式性与精确门槛）【已证明】[c5a-D0123] [c5a-Dgen]
对每个 d≥0，存在 2d 次多项式 p_d，首项系数为 2/(2^d d!)，使得

  N(k,k−d) = p_d(k) 对一切 k ≥ 2d+2 成立，并且 p_d(2d+1) − N(2d+1, d+1) = (−1)^d (d+1)! ≠ 0，

所以门槛 2d+2 是精确的。d≤3 时的显式形式：
- p_0 = 2，即 N(k,k) = 2（k≥2）；
- p_1 = k² − k − 4（k≥4）；
- p_2 = (k⁴ − 10k³ + 43k² − 98k + 164)/4（k≥6）；
- p_3 = (k⁶ − 27k⁵ + 331k⁴ − 2225k³ + 8560k² − 17392k + 11088)/24（k≥8）。

**证明。** 把引理 1.5 改写成 D(k,d) = N(k,k−d) 的形式（取 r+1 = k−d）：

  D(k,d) = D(k−1,d) + D(k−1,d−1) + (k−d−1)·[D(k−3,d−1) + 2D(k−3,d−2) + D(k−3,d−3)]，

其中 e<0 时 D(·,e)=0。对 d 归纳。
- d=0：D(k,0) = D(k−1,0)（其余项为 0，因为 N(n,q)=0 当 q>n），而 D(2,0) = N(2,2) = 2（(1,2) 与 (2,1)），所以 p_0 = 2 对 k≥2 成立；D(1,0) = N(1,1) = 1，故缺口 δ_0 := p_0(1) − D(1,0) = 1。
- 归纳步：设 e<d 时结论成立。当 k ≥ 2d+3 时，右端各项 D(k−1,d−1)、D(k−3,d−1)、D(k−3,d−2)、D(k−3,d−3) 的自变量分别满足 k−1 ≥ 2d+2 ≥ 2(d−1)+2、k−3 ≥ 2d = 2(d−1)+2 等，都处在多项式成立区。所以存在多项式 Δ_d 使 D(k,d) − D(k−1,d) = Δ_d(k)（k≥2d+3），其中

  Δ_d(k) = p_{d−1}(k−1) + (k−d−1)[p_{d−1}(k−3) + 2p_{d−2}(k−3) + p_{d−3}(k−3)]。

  Δ_d 的次数是 2d−1，首项系数 = lc(p_{d−1})。令 p_d(k) := D(2d+2,d) + Σ_{i=2d+3}^{k} Δ_d(i)，这是 2d 次多项式，lc(p_d) = lc(p_{d−1})/(2d) = 2/(2^d d!)，并且对 k≥2d+2 有 D(k,d) = p_d(k)。
- 缺口：在 k = 2d+2 处，真实增量与 Δ_d(2d+2) 只差在 D(2d−1,d−1) 这一项（2d−1 < 2(d−1)+2），其余项都已在多项式区。所以 p_d(2d+1) − D(2d+1,d) = (真实增量 − Δ_d(2d+2)) = (d+1)[D(2d−1,d−1) − p_{d−1}(2d−1)] = −(d+1)δ_{d−1}，即 δ_d = −(d+1)δ_{d−1}，δ_d = (−1)^d(d+1)!·δ_0 = (−1)^d(d+1)!。∎

程序核对：
- d≤3 时，用精确多项式运算验证 p_d(k) − p_d(k−1) ≡ Δ_d(k)，并验证基值 p_d(2d+2) = D(2d+2,d)。
- 数据：k≤60 全部相符；缺口 −2、6、−24（d=1,2,3）与 (−1)^d(d+1)! 一致。
- d≤11：用 2d+1 个点插值，[2d+2, 60] 上全部吻合；次数、首项系数、缺口 (−1)^d(d+1)! 都核对通过。

### 定理 3.2（m 的次首项系数）【已证明】[c5a-mcoef] [c5a-mcoef-gen]
记 B_d(k) := (k−d)!·[m^{k−d}]U_k(m)。对一切 k≥d：

  **B_d(k) = Σ_{e=0}^{d} (−1)^{d−e} N(k,k−e) · ẽ_{d−e}(k−e)**，

其中 ẽ_0 = 1，ẽ_1(n) = (n−3)/2，ẽ_2(n) = (n−2)(3n−13)/24，ẽ_3(n) = (n−3)(n²−7n+8)/48。一般地 ẽ_j(n) := e_j(−1,0,1,…,n−2)/n^{\underline j} 是 j 次多项式。

因此 k ≥ 2d+2 时 B_d(k) = b_d(k) := Σ_e(−1)^{d−e}p_e(k)ẽ_{d−e}(k−e)，这是 2d 次多项式，首项 1/(2^{d−1}d!)；并且 B_d(2d+1) − b_d(2d+1) = (−1)^{d+1}(d+1)!，所以门槛精确。显式形式：
- **[m^k]U_k = 2/k!**（k≥2）；
- **[m^{k−1}]U_k = (k²−2k−1)/(k−1)!**（k≥4；k=3 时 U_3 = (m³+6m²+8m+3)/3，次首项是 2，而公式给出 1）；
- **[m^{k−2}]U_k = (3k⁴−36k³+162k²−313k+422)/(12·(k−2)!)**（k≥6）；
- **[m^{k−3}]U_k = (k⁶−30k⁵+379k⁴−2533k³+9570k²−19331k+13380)/(24·(k−3)!)**（k≥8）。

**证明。**
- C(m+1,n) = (1/n!)∏_{i=−1}^{n−2}(m − i)，所以 [m^{n−j}]C(m+1,n) = (−1)^j e_j(−1,…,n−2)/n!。
- 记 e_j(n) := e_j(−1,…,n−2)。它满足 e_j(n) = e_j(n−1) + (n−2)e_{j−1}(n−1)（n≥1），e_j(0) = [j=0]。归纳可知 e_j(n) 是 n 的 2j 次多项式，且对一切 n≥0 等于集合定义的值。n<j 时只有不到 j 个数，故 e_j(n)=0，于是 n^{\underline j} 整除 e_j(n)，商 ẽ_j 是 j 次多项式。ẽ_1、ẽ_2、ẽ_3 的显式形式靠多项式比较得出：e_j(n) = n^{\underline j}ẽ_j(n) 两边都是 2j 次多项式，程序在 n=0..69 上逐点核对。
- 由引理 1.2，[m^{k−d}]U_k = Σ_{e=0}^{d} N(k,k−e)·(−1)^{d−e}e_{d−e}(k−e)/(k−e)!（只有 q = k−e、e≤d 的项能贡献 m^{k−d}）。乘以 (k−d)!，并用 (k−d)!·(k−e)^{\underline{d−e}}/(k−e)! = 1，即得上面的恒等式。
- 当 k ≥ 2d+2 时，所有 N(k,k−e)（e≤d）都等于 p_e(k)（定理 3.1），得到 b_d。次数为 max_e(2e + d − e) = 2d，只有 e=d 一项达到，首项 = lc(p_d) = 1/(2^{d−1}d!)。在 k = 2d+1 处，只有 e=d 一项偏离多项式，偏差为 N(2d+1,d+1) − p_d(2d+1) = −δ_d。
- d≤3 的显式形式由 p_0..p_3 与 ẽ 精确多项式运算得到（`code/c5a/sym_deriv.py`）。∎

程序核对：

## 4. h_k(t) 的结构

### 4.1 基本事实【已证明】[c5a-h-def] [c5a-h-01]
1. h_k(t) = Σ_{q=1}^{k} N(k,q) t^{q−1}(1−t)^{k−q}（k≥1），h_0 = 1。证明：对引理 1.2 用 Σ_m C(m+1,q)t^m = t^{q−1}/(1−t)^{q+1}（q≥1）。由此 deg h_k ≤ k−1（k≥1）。

### 引理 4.2（互反引理：h 的高次系数 ↔ 负整数处的值）【已证明】[c5a-h-deg-lead]
设 f 是次数 ≤ d 的多项式，Σ_{m≥0}f(m)t^m = h(t)/(1−t)^{d+1}，g := deg h。则对 j≥1：

  f(−j) = (−1)^d Σ_{i=d−j+1}^{g} h_i C(i+j−1, d)。

特别地，f(−1) = … = f(−(d−g)) = 0，且 f(−(d−g+1)) = (−1)^d h_g ≠ 0；f(−(d−g+2)) = (−1)^d[h_{g−1} + (d+1)h_g]。

**证明。** 展开得 f(m) = Σ_i h_i C(m−i+d, d)。当 0≤m<i≤d 时 C(m−i+d,d) 的乘积因子里含 0，所以两边作为多项式恒等。在 m=−j 处，C(d−i−j, d) 的因子从 1−i−j 走到 d−i−j：当 i ≤ d−j 时含 0；当 i > d−j 时全为负，等于 (−1)^d C(i+j−1, d)。代入 j = d−g+1 与 d−g+2 即得后两式。∎

程序核对：对 h_k、j≤25、k≤60，右端与 U_k(−j) 的多项式值精确相等。

### 定理 4.3（负整数处的值：G_{−j} 是多项式）【已证明】[c5a-Gneg]
对 j≥1，G_{−j}(x) := Σ_k U_k(−j)x^k 是多项式：

  G_{−1} = 1，G_{−j−1} = (1 − x + jx³)·G_{−j} + jx²，

所以 G_{−j} = ∏_{i=1}^{j−1}(1−x+ix³) + x²Σ_{i=1}^{j−1} i·∏_{l=i+1}^{j−1}(1−x+lx³)，次数为 3j−3（j≥1）。记 G_{−j} = Σ_k g_{j,k}x^k，最高六个系数（j≥2；下标为负的忽略）是

  g_{j,3j−3} = (j−1)!，g_{j,3j−4} = (j−1)!，g_{j,3j−5} = −c(j,2)，
  g_{j,3j−6} = (j−1)!，g_{j,3j−7} = c(j,2)+c(j,3)，g_{j,3j−8} = (j−1)! − c(j,2) − c(j,3)。

**证明。**
- 递推：由引理 1.3(b) 取 m = −j 得 G_{−j−1} = b_{−j}G_{−j} + jx²，其中 b_{−j} = 1 − x + jx³；起点 G_{−1} = 1（引理 1.4 的证明中已得）。归纳可知它是多项式，次数每步加 3。
- 记 G_{−j} 的最高系数依次为 α_j, β_j, γ_j, δ_j, ε_j, ζ_j（对应 x^{3j−3}, …, x^{3j−8}）。比较 G_{−j−1} 的 x^{3j}, …, x^{3j−5} 系数：
  - α_{j+1} = jα_j；β_{j+1} = jβ_j；γ_{j+1} = jγ_j − α_j；
  - δ_{j+1} = jδ_j − β_j + α_j；ε_{j+1} = jε_j − γ_j + β_j；ζ_{j+1} = jζ_j − δ_j + γ_j。
  - x² 项 jx² 只在 j=2 时落在 ε_3 上；直接验算 G_{−3} = 1 − 2x + 4x² + 2x³ − 3x⁴ + 2x⁵ + 2x⁶ 即可。
- 起点：G_{−2} = 1 − x + x² + x³，即 α_2 = β_2 = 1，γ_2 = −1，δ_2 = 1。由此 α_j = β_j = (j−1)!；γ_{j+1}/j! = γ_j/(j−1)! − 1/j，得 γ_j = −(j−1)!H_{j−1} = −c(j,2)；δ_{j+1} = jδ_j，得 δ_j = (j−1)!。
- ε、ζ 的闭式用 c(n+1,k) = n·c(n,k) + c(n,k−1) 直接验证满足递推：c(j+1,2) + c(j+1,3) = j[c(j,2)+c(j,3)] + (j−1)! + c(j,2)，ζ 的情形同理。起点 ε_3 = 4 = c(3,2)+c(3,3)，ζ_3 = −2 = 2! − c(3,2) − c(3,3)。∎

程序核对：G_{−j} 与 DP 多项式在负整数处的值逐项相等（j≤21、k≤60）；次数与六个最高系数在 2≤j≤21 上全部成立。

### 定理 4.4（h_k 的次数、首项与第二首项）【已证明】[c5a-h-deg-lead]
对 k≥1：
- (a) U_k(−j) = 0 ⟺ 1 ≤ j ≤ s_k := ⌊(k+2)/3⌋（在 j≥1 范围内的第一段零点）；U_k(−s_k−1) ≠ 0。所以 U_k(m) 被 (m+1)(m+2)…(m+s_k) 整除，例如 U_4(m) = (m+1)(m+2)(m²+11m+6)/12。
- (b) **deg h_k = k − s_k = ⌊2k/3⌋。**
- (c) **首项系数**：k=3a 时为 (−1)^a·a!；k=3a+1 时为 (−1)^a·c(a+2,2)（c(a+2,2) = (a+1)!H_{a+1}）；k=3a+2 时为 (−1)^a·(a+1)!。符号是 (−1)^{⌊k/3⌋}。
- (d) **第二首项系数**（k≥3）：
  - k=3a：(−1)^{a+1}·2a·a!；
  - k=3a+1：(−1)^a·[c(a+3,2) + c(a+3,3) − (a+2)! − (3a+2)c(a+2,2)]；
  - k=3a+2：(−1)^a·[c(a+3,2) + c(a+3,3) − 3(a+1)(a+1)!]。

**证明。**
- (a) 由定理 4.3，U_k(−j) = g_{j,k} = 0 当 k > 3j−3，即 j ≤ (k+2)/3。取 j* = s_k + 1，则 k ∈ {3j*−5, 3j*−4, 3j*−3}，对应系数 −c(j*,2)、(j*−1)!、(j*−1)! 都非零（j*≥2）。
- (b)、(c)：用引理 4.2，取 d=k，g = k − s_k，h_g = (−1)^k U_k(−s_k−1) = (−1)^k g_{j*,k}。按 k mod 3 代入即得；例如 k=3a 时 j* = a+1，h_g = (−1)^{3a}·a!。
- (d)：h_{g−1} = (−1)^k U_k(−s_k−2) − (k+1)h_g，而 U_k(−s_k−2) = g_{j*+1,k}。k = 3(j*+1) − 6、−7、−8 分别对应 δ、ε、ζ，代入定理 4.3 化简。∎

程序核对：(a) 到 (d) 在 1≤k≤60 上全部成立（(d) 为 3≤k≤60）。例如 h_12 的首项 24 = 4!，第二首项 −192 = −2·4·4!。

### 4.6 [t¹] 与固定位置的系数【已证明；门槛数据为已验证】[c5a-h-t1] [c5a-h-fixed-i]
- **Σ_k h_{k,1} x^k = G_1 − 1/(1−x)² = x²(1−x+x²)/((1−x)²(1−x−x³))**。这里 G_1 = (1+x²−x³)/((1−x)(1−x−x³))，即 W_1 = 1 + x²P_0 = 1 + x² − x³。因为 (1−x+x²)/(1−x) = 1 + x²/(1−x)，而 1/((1−x)(1−x−x³)) 的系数全正，所以 h_{k,1} = R_k − k − 1 > 0（k≥2）。前几项为 1, 2, 4, 8, 14, 23, 37, 58, 89, …（k=2,3,…）。
- 一般地 Σ_k h_{k,i}x^k = Σ_{r=0}^{i} (−1)^r (x^{r−1}/r!)·(d/dx)^r[x·G_{i−r}(x)]，是有理函数。
- **固定 i≥1 时 h_{k,i} = c_iρ_i^k(1+o(1))，因而最终为正**。证明：h_{k,i} = Σ_{r≤i}(−1)^r C(k+1,r)U_k(i−r)，各项为 O(k^r ρ_{i−r}^k)，而 ρ_0 < ρ_1 < … < ρ_i（引理 2.1(b)），所以 r=0 项占优，再用推论 2.3。

### 4.7 t=1 处的各阶导数与 N 的关系【已证明】[c5a-h-deriv]

### 4.8 二元母函数 H(z,t) = Σ_k h_k(t)z^k【已证明】[c5a-H-pde]
- H(z,t) = (1−t)·F(z(1−t), t)，其中 F(x,t) = Σ U_k(m)x^k t^m。证明：f_k = h_k/(1−t)^{k+1}。
- H 满足一阶线性 PDE：

  **(1−z)H − t(1−t)z³[(1−t)∂_tH + H + z∂_zH] = 1 + t z²**。

  由 4.1-5 的递推乘 z^k 求和得到，用到 Σ_n(n+1)h_n z^n = H + z∂_zH，以及初值 h_0, h_1, h_2。它的特征线是 z(1−t) = 常数，换回 x = z(1−t) 正是 F 的 PDE（提示词 (C5)），所以 H 的显式解归结为 F 的显式解（属 C-3，本子任务不重复）。
- **对固定 t∈(0,1)，Σ_k h_k(t)z^k 的收敛半径为 0**（只能作形式幂级数理解）。证明：h_k(t) = (1−t)^{k+1}Σ_m U_k(m)t^m ≥ (1−t)^{k+1}t^m U_k(m)，而对每个 m 有 U_k(m) ≥ (c_m/2)ρ_m^k（k 充分大）。因为 ρ_m→∞，对任意 z≠0 都能选 m 使 ρ_m(1−t)|z| > 1，于是通项不趋于 0。

程序：PDE 在 z^k（k≤60）的系数上逐项成立。

### 4.9 实根性【部分已证明，主体已验证】[c5a-h-real]
- 【已证明】h_k 在 [0,1] 上没有根：t∈[0,1) 时 h_k(t) = (1−t)^{k+1}Σ_m U_k(m)t^m > 0，而 h_k(1) = 2。

- 等价表述（证明见 4.1-4，用实 Möbius 变换 z = t/(1−t)）：h_k 实根 ⟺ n_k(z) = Σ_q N(k,q)z^{q−1} 实根。n_k 系数为正，所以其根全为负，N(k,·) 是对数凹的。程序直接验证 N(k,·) 对数凹（k≤60）。
- 推论（在已验证范围内）：由 Descartes 符号法则，系数变号次数 = 大于 1 的根的个数（k≤60 逐一相符）。根的分布：k=60 时 20 个负根（其中 13 个在 (−1,0)）、20 个大于 1 的根。最接近 0 的负根约为 −1/h_{k,1}（k=36 时为 −4.8·10⁻⁷）；正根从右侧聚向 1；最大根随 k 近似线性增长（k=36 时约为 40.6），最小根约为 −20.6。

## 5. 草稿与提示词的问题（含反例或理由）

- h_{k,i} 的**转正门槛**（2,8,16,24,33,41,50,59，间隔约 8.4）：要严格证明某个具体 k 之后恒正，需要显式误差界（复根项的系数界）。已知 h_{k,i} 的 g.f. 是有理函数，所以原则上可做，但没有完成。
- h_k(−1)：在 §4.11 的搜索空间里没有找到递推；增长似乎是超指数，但无法证明。也没有找到组合解释。
- 中间符号模式（周期约 3 的块结构）：没有给出公式。
- H(z,t) 的显式（积分 / ₁F₁）形式：本文只给出 PDE 与 H = (1−t)F(z(1−t),t)，显式解交给 C-3。
- 所有极点的系数：b_m 复根的 γ_m(σ) 是否非零没有一般证明。主定理不需要这一点，因为次大极点已在实根 ρ_{m−1}。
