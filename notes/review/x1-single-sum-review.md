## 2. 逐条 verdict

### 2.1 c2a-S（定理 S，【已证明】）→ **confirmed**

陈述：对每个 m≥1，不存在整数 c、d、k_0 与一列与 k 无关的复数 A(s)，使得对 k≥k_0 有 U_k(m) = Σ_s A(s)·C(k+c−2s, m+s+d)。二项式约定为 C(a,b)=0，除非 0≤b≤a。

逐步重推：
- **(1) 母函数。** 记 e := m+d，只有 s≥−e 的项可能非零。令 N := k+c−3s−e，则 Σ_{k∈Z} C(k+c−2s, s+e)x^k = x^{3s+e−c}(1−x)^{−(s+e+1)}。各项的赋值 → ∞，所以 Φ 在 C((x)) 中收敛，并且对每个 k，[x^k]Φ 正好是右边的有限和。G_m−Φ 在 k≥k_0 时系数为 0，而 Φ 的赋值 ≥ −2e−c，所以 L := G_m−Φ 是 Laurent 多项式。利用 (1−x)^{−1} = u x^{−3} 得 Φ = x^g Ã(u)，其中 g = −2e−c−3，Ã = u^{e+1}Σ A(s)u^s ∈ uC[[u]]。**Laurent 修正项、x^g 因子和负幂都处理得严格。**
- **(2) Ã ∈ C(u)。** x 是 T³+uT−u 的根，该多项式首一，在 u 处满足 Eisenstein 判别法，所以 [C(x):C(u)] = 3，基为 1、x、x²。在 C((x)) 中，α+βx+γx²（系数属于 C((u))）的三项赋值模 3 分别为 0、1、2，所以三者线性无关。R := x^{−g}(G_m−L) ∈ C(x) 的坐标 r_i 属于 C(u)，而 R = Ã(u)，由坐标唯一性得 Ã = r_0。这里用到 C(u) → C((u)) → C((x)) 与 C(u) → C(x) → C((x)) 两条嵌入一致，两者都是延拓 u ↦ x³/(1−x) 的连续域同态，所以成立。
- **(3) 留数。** b_1 = −(x³+x−1) 没有有理根，所以不可约、三根互异。在根 ξ 处有 1−ξ = ξ³，b_w(ξ) = (1−w)ξ³。于是 P_m 在 ξ 处是单零点，且 P_m′(ξ) = b_1′(ξ)·ξ^{3m}·(−1)^{m−1}(m−1)!。又 W_m(ξ) = 1+ξ⁵ = ξ(1+ξ) ≠ 0（因为 b_1(0)=1、b_1(−1)=3）。u−1 = −b_1/(1−x)，所以 u′(ξ) = −b_1′(ξ)/ξ³ ≠ 0，u−1 是 ξ 处的局部坐标。比较极点阶得 p = 1，且 ρ_i·u′(ξ_i)·ξ_i^{−g} = κ 对三个根相同。我独立算得 ρ·u′ = (−1)^m(1+ξ)ξ^{−3m−2}/(m−1)!，与原文一致。
- **(4) 矛盾。** θ := (1+ξ)ξ^{−M} 在三个嵌入下的值全相等，所以它的特征多项式是 (X−θ)³ ∈ Q[X]，从而 θ ∈ Q，θ³ = N(1+ξ)·N(ξ)^{−M}。由 f = x³+x−1 得 N(ξ) = −f(0) = 1，N(1+ξ) = −f(−1) = 3。于是 θ³ = 3，与 θ ∈ Q 矛盾。

独立核对：

### 2.3 c2a-Sprime（命题 S′，【已证明】）→ **confirmed**

逐步重推：
- Σ_k C(k+c−αs, βs+d)x^k = x^{d−c}(1−x)^{−(d+1)}v^s，其中 v = x^{α+β}/(1−x)^β。
- α≥1 时，T^{α+β} − v(1−T)^β 首一（因为 β<α+β），且在 v 处满足 Eisenstein，所以 A ∈ C(v)。
- v′ = x^{D−1}(1−x)^{−β−1}((α+β)−αx)，只在 x=0 与 x=(α+β)/α≥1 处为零，所以 v′(ξ) ≠ 0。
- G_m 在 ξ 处有单极点，所以 A 在 v_0 = v(ξ) 处有极点。于是纤维中任何满足 v′(η)≠0、η∉{0,1} 的点 η 都必须是 P_m 的根。
- (i) D 为偶数时，x^D − v_0(1−x)^β 在 0 处取负值、在 −∞ 处取 +∞，所以有负根；而当 x<0 时 b_w(x) > 0，矛盾。
- (ii) v = x³ 时，b_w(ωξ) = (1−w) + (w−ω)ξ。若它为零，则 ξ ∈ Q(ω)，与 ξ 是三次无理数矛盾。
- α+β=1 时单和平凡存在，这一说明也正确。

数值佐证 `r5.Sprime_linsys`：U 取 m=1,2，形状 (1,1)、(2,0)、(2,2)、(1,3)、(3,0)，c∈[−12,12]，d∈[−6,10]，k_0∈{0,15}，共 8500 个方程组，全部无解。

### 2.4 c2a-shapes-odd（【未完成】：α+β 为奇数的形状如 (1,2)、(2,3)）→ **minor_gap**（作者说的障碍并不存在，至少这两个可以简单证明）

### 2.7 c2a-G（定理 G，【已证明】）→ **confirmed**

逐步重推：
- 由 P_m = T(m)(ρ(m)−1) 且 P_m ≠ 0 得 ρ(m) ≠ 1，令 y = 1/(ρ−1) ∈ K(m)，则 T = y·P_m。
- 代入得 y(m+1)·r(m) − y(m) = 1，其中 r(m) = 1−x−(m+1)x³。该式对无穷多个 m 成立，所以是 K(m) 中的恒等式。
- 设 y = A/B 互素。若 B(β)=0，则 A(β)B(β+1)=0，从而 B(β+1)=0；归纳得到无穷多个根，所以 B 是常数。
- 若 y 是多项式，左边次数为 deg y+1 ≥ 1，首项系数为 −x³·lc(y)；右边次数为 0，矛盾。

证明完整。原文已说明它只排除了超几何闭式，不推出定理 S，表述恰当。

### 2.8 c2b-T6E（定理 6 的 E 部分，2≤m≤30，【已证明（计算机辅助）】）→ **confirmed**（可加强到所有 m≥2）

框架逐步重推：
- x^N(V+L) = u^{d+1}F(u)，其中 N = c+2d+3。
- {1,x,x²} 是基。乘 x 的矩阵行列式为 u，所以 x^N 的坐标是 u 的 Laurent 多项式，在 1/i 处正则。L 的坐标同样正则。
- V 的坐标在 u=1/i 处至多一阶极点。留数在 K_i 中特化为 ν_i；c2b 的 ν_i 恰好等于 −i·θ_i。
- 条件是 x^N ν_i ∈ Q；若 ν_i ≠ 0，则 N(ν_i) = γ³i^N，所以去掉 i 的素因子后必须是立方。
- K_i 是域当且仅当 i ≠ q²(q−1)。

各步都正确。

- 证书数值：我用独立代码重算了 m≤6 的 11 个证书值（如 E m=2：17；U m=2：103/2；E m=4，i=3：−63801/8 等），全部吻合（`r1.c2b_cert_values`）。
- **加强：** 按 §0 第 2 条的闭式，纤维 i=2 对所有 m≥2 都给出阻碍，因为 v_17(N(θ_E)) ≡ 1 (mod 3)。`r1.uniform_E_fiber2` 核对了 m=2..34，`r1.theta_closed_form_E` 核对了闭式对所有域 i≤m≤34 成立。另一条初等证明由 `r1.E_alt_proof` 核对。
