## 1. 发现的问题（按严重程度）

### 1.1 陈述可以加强；「搜索在定理范围内」这句依赖加强后的版本（陈述不准，次要）

- **位置**：定理 14.1 的「存在 k_0、q_0 使……对一切 k≥k_0、q≥q_0」；第 11 行「notes/13 §5 搜索的 6 种形状……都在定理范围内」；注 14.2 第二条。
- **问题**：证明只用到一件事：对每个 q≥q_0，F^T_q 与 Σ_kX(k,q)x^k 只差一个 Laurent 多项式 L_q。因为 L̂ 的 V^n 系数只涉及 q≤n+f−e 的有限多个 L_q，门槛 k_0 依赖 q 也完全不影响证明。
  - 定理的字面陈述要求在整个象限上成立（门槛 k_0 一致）。
  - notes/13 §5 的搜索方程取在 {1≤q≤k} 上，这不是象限。一个只在 q≤k 上成立的骨架型式子，不受字面陈述管辖（它在 q>k 时不必等于 0），却被「k_0 依赖 q」的版本覆盖（取 k_0(q)=q）。
  - 搜索的 6 种形状都满足 a≤−1；搜索用的系数族（s≤7、0≤p≤2s+2，有限支撑）是定理系数族的子族。这两点没有问题。
- **建议**：把定理改成「对每个 q≥q_0，对一切 k≥k_0(q)（门槛可以依赖 q）」。注 14.2 里「对 k_0、q_0 也没有要求」可以补半句「k_0 甚至可以依赖 q」，并据此说明 §5 搜索的区域 1≤q≤k 也被覆盖。

### 1.5 专门复核了的几处（都没有问题）

- **引理 14.3**：方程组的系数与右边都在 C(U) 中。前 N 个方程在 C(U) 上的解集是非空仿射子空间，随 N 增大而递减；每次真包含都使维数下降，所以链会稳定，交集非空。C(x)∩C((U))=C(U) 由坐标唯一性得到：C(U)→C(x)→C((x)) 与 C(U)→C((U))→C((x)) 两条嵌入相容。论证严密。
- **主部引理**允许分歧点（ν>1），所以情形 C 里 ζ 是分歧点也没有问题。
- **「ρ 项的计算」**：g_p 是有限个 c·x^αV^β(1+x^bV)^{−γ}（γ≥1）之和，在 (ζ,0) 附近解析。对 n 求和得到的正是 V 的有理函数（分母是 (1+ζ^bV) 的幂），b 为负时也成立。
- **几个边界情形**：
  - q_0+e=0 时 𝓛 为空，没有修正项。
  - p+f<0 的项乘的是 0，「不妨设」成立。
  - (1−x) 的负幂和 x=1 处的极点都不影响证明，因为留数只在 η_t、ξ、ζ 处取，这些点都不是 0 或 1。
- **情形 B**：b_2 的实根 0.589755、复根模 0.920766，并且 |η_2|²=1/(2η_1)。b≠1 时 |λ_1|≠|λ_2|。解析延拓在 C 去掉有限个点之后的连通区域上进行，本性奇点论证成立。
- **情形 C**：纤维乘积 ∏w_i=(−1)^{r+1}ξ^{−3(r−3)} 我手推了一遍。纤维点都不是 0 或 1，U′(ξ)≠0。r=2、4..10 的数值佐证也一致。
