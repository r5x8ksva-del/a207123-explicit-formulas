### 3.1 次大极点为什么是 ρ_{m−1}、系数为什么恰为 −c_{m−1}ρ_{m−1}³、|σ_m|<ρ_{m−1}
- 极点：P_m 无平方因子，G_m=W_m/P_m 是真分式，所以 U_k(m)=Σ_σ α_m(σ)σ^k（σ ∈ {1} ∪ Z_1 ∪ … ∪ Z_m）。系数可能为 0，但只会让余项更小。
- 模长排序：ρ_j=g^{−1}(j)，g=y³−y² 在 [1,∞) 上严格增，所以 ρ_0<ρ_1<…<ρ_m。三根之积为 j，所以 |σ_j|² = j/ρ_j = ρ_j²−ρ_j < ρ_j²，并且关于 j 递增。**|σ_m|<ρ_{m−1}** 等价于 m<ρ_mρ_{m−1}²，而 ρ_mρ_{m−1}² > ρ_{m−1}³ = ρ_{m−1}²+(m−1) ≥ m。我逐步核过这条不等式链，m=1（ρ_0=1）也成立。因此 ρ_m 是唯一最大，ρ_{m−1} 是唯一次大（|σ_m|、|σ_{m−1}|、ρ_{m−2} 等都严格更小）。
- 系数：对 σ∈Z_{m−1}，b_m(1/σ) = b_{m−1}(1/σ) − σ^{−3} = −σ^{−3} ≠ 0。由 G_m=(G_{m−1}+mx²)/b_m，在 1/σ 处的主部系数除以 b_m(1/σ)，所以 α_m(ρ_{m−1}) = −ρ_{m−1}³·α_{m−1}(ρ_{m−1}) = −c_{m−1}ρ_{m−1}³。它非零，因为 c_{m−1}>0：x_{m−1} 落在 G_{m−2} 的收敛圆内，而 G_{m−2} 的系数非负、常数项为 1。m=1 时 c_0=α_0(1)=1，得 R_k = c_1ρ_1^k − 1 + O(0.826^k)。
- 数值旁证（`s3`）：j≤2000 时模长排序全部成立。去掉两项主项后，余项除以 (c_{m−2}/2)ρ_{m−2}^{k+6} 在 m=3..8、k=700 时等于 1（误差 <10⁻¹¹），说明第三极点（m≥3 时为 ρ_{m−2}）的系数公式 α_j(σ)(−σ³)^{m−j}/(m−j)! 也对。m=2 的第三项是复根对，余项/|σ_2|^k 有界且振荡（用 260 位精度重算，k≤1000）。
- 1−θ_m：(1−θ_m)·3m 在 m=8, 10², 10³, 10⁴, 10⁵ 时为 0.842, 0.926, 0.966, 0.984, 0.993，与 (1/(3m))(1+O(m^{−1/3})) 相符。更精确地，(1−θ_m)(3m+ρ_m²−1) → 1（m=10⁵ 时为 1.00000002）。

### 3.2 c5a 闭式与主 Agent 闭式等价：代数证明
设 ρ 是 f_m(y)=y³−y²−m 的任一根（三个根都适用），m≥1，记 u=ρ³=ρ²+m，e_n(u)=Σ_{i≤n}u^i/i!，e_{−1}=0。
1. 主 Agent 的式子乘开（令 i=m−j）：
   M = [ρ^{3m+3}/m! + Σ_{i=0}^{m−1}(m−i)ρ^{3i+1}/i!]/(ρ²+3m)。
2. 分母：ρ²+3m = ρ²+3(u−ρ²) = 3ρ³−2ρ² = ρ²(3ρ−2)。
3. 分子 = ρ·[ρ²u^m/m! + Σ_{i<m}(m−i)u^i/i!]，而
   Σ_{i<m}(m−i)u^i/i! = m·e_{m−1}(u) − u·e_{m−2}(u) = (u−ρ²)e_{m−1}(u) − u·e_{m−2}(u) = u^m/(m−1)! − ρ²e_{m−1}(u)。
   所以方括号 = (ρ²+m)u^m/m! − ρ²e_{m−1}(u) = u^{m+1}/m! − ρ²e_{m−1}(u) = ρ²[ρ^{3m+1}/m! − e_{m−1}(u)]。
4. 于是 M = ρ³[ρ^{3m+1}/m! − e_{m−1}(ρ³)]/(ρ²(3ρ−2)) = ρ(ρ^{3m+1}/m! − Σ_{i<m}ρ^{3i}/i!)/(3ρ−2)，正是 c5a 的闭式。∎

这个恒等式在 Q[y]/(f_m) 中成立；两条闭式与残数式 (G_{m−1}(x_m)+mx_m²)/(x_m(1+3mx_m²)) 三者相同。程序核对（`s2`）：商环中精确相等（1≤m≤60）。ρ 为整数的 m=4, 18, 48, 100 三式精确一致。decimal 110 位下残数式（G_{m−1}=W_{m−1}/P_{m−1} 直接求值）与闭式在 1≤m≤40 上相差 <10⁻⁸⁰，并且 c_m>0。主 Agent 的 m=1 式 c_1=(ρ⁶+ρ)/(ρ²+3) 与 c5a 的 (10+15ρ+17ρ²)/31 我也手算核过：(10+15ρ+17ρ²)(ρ²+3) ≡ 31(2+2ρ+3ρ²) ≡ 31(ρ⁶+ρ)。**结论：两种闭式等价，没有反例。**
