## 2. 证明

### 2.0 约定与基本事实

全部推导都在形式幂级数环里进行，不涉及收敛。

- 对 F ∈ Q[[z]]，令 f_q := q!·[z^q]F，即 F = Σ_{q≥0} f_q z^q/q!，称 f_q 为 F 的 **e.g.f. 系数**。θ := z·d/dz。
- u := Σ_{n≥1} z^n（即 z/(1−z)），L := Σ_{n≥1} z^n/n（这正是 −ln(1−z) 在 Q[[z]] 中的定义，不需要另外讨论对数）。c(q,i) 由 L^i/i! = Σ_q c(q,i)z^q/q! 定义。因为 L ∈ zQ[[z]]，q < i 时 c(q,i) = 0，并且 c(q,0) = [q=0]。

基本事实：

- **(F1)** θ 把 z^q 乘以 q。所以对 p ∈ Q[t]，p(θ)F 的 e.g.f. 系数是 p(q)f_q。
- **(F2)** θ 是导子：θ(FG) = θF·G + F·θG。这由 d/dz 的 Leibniz 法则得到。
- **(F3)** θ 在 zQ[[z]]（常数项为 0 的级数）上是单射。
- **(F4)** θL = u，θu = u + u²。
  - 第一式：θL = Σ n·z^n/n = u。
  - 第二式：θu = Σ_{n≥1} n z^n。另一方面 1 + u = Σ_{n≥0} z^n = (1−z)^{−1}，所以 u + u² = u(1+u) = z(1−z)^{−2} = Σ n z^n。
- **(F5)** q ≥ 0、i ≥ 1 时 c(q+1,i) = q·c(q,i) + c(q,i−1)。
  - 证：L′ = Σ_{n≥1} z^{n−1} = (1−z)^{−1}，所以 (1−z)·(L^i/i!)′ = L^{i−1}/(i−1)!。F′ 的 e.g.f. 系数是 f_{q+1}，zF′ 的是 q·f_q，比较两边 z^q/q! 的系数即得。
  - 推论：q ≥ 1 时 c(q,1) = (q−1)!。

### 2.1 第一步：反转递推与一阶 ODE

**(R)** R_1 = 1，R_2 = 1 + 2y²；q ≥ 3 时
  R_q = (y² + 2(q−1))·R_{q−1} + (q−1)(y³ − y² − (q−2))·R_{q−2}。

推导：x ↦ y^{−1} 是环同态 Q[x] → Q[y, y^{−1}]。把它作用到 Num 的递推上，两边乘 y^{3q−2}，再用 y^{3q−2} = y³·y^{3(q−1)−2} = y⁶·y^{3(q−2)−2}，得到

  y^{3q−2}(y^{−1} + 2(q−1)y^{−3})·Num_{q−1}(y^{−1}) = (y² + 2(q−1))·R_{q−1}，
  y^{3q−2}(q−1)y^{−3}(1 − y^{−1} − (q−2)y^{−3})·Num_{q−2}(y^{−1}) = (q−1)(y³ − y² − (q−2))·R_{q−2}。

初值：R_1 = y·y^{−1} = 1，R_2 = y⁴(2y^{−2} + y^{−4}) = 1 + 2y²。因为 deg Num_q = 3q−2，R_q ∈ Z[y] 的次数 ≤ 3q−2，并且对一切 j ≥ 0 有 [y^j]R_q = a_{q,j}。

**引理 1.** 在 Q[y][[z]] 中，A := Σ_{q≥1} R_q z^q/q! 满足
  (1−z)²·∂_zA = (1 − z + y²z) + (y²(1−z) + y³z)·A。　　(★)

*证.* 令 α_0 := α_{−1} := 0，α_q := R_q/q!。两边 z^n（n ≥ 0）的系数分别是：
- 左边：(n+1)α_{n+1} − 2nα_n + (n−1)α_{n−1}；
- 右边：[n=0] + (y²−1)[n=1] + y²(α_n − α_{n−1}) + y³α_{n−1}。

逐个 n 看：
- n = 0：α_1 = 1。
- n = 1：2α_2 − 2 = (y²−1) + y²，即 α_2 = (1+2y²)/2。
- n ≥ 2：两边乘 n!，得 R_{n+1} = (y²+2n)R_n + n(y³ − y² − (n−1))R_{n−1}，正是 (R) 在 q = n+1 处的形式。

所以 (★) 与「(R) 加初值」等价，而 (R) 成立。∎

（(★) 与 r-c4ii §4.3 的一阶 ODE 完全相同。我是在读 r-c4ii 之前独立推出的。）

### 2.2 第二步：按 y 的次数拆开

对 F = Σ_q F_q(y)z^q ∈ Q[y][[z]]，令 [y^j]F := Σ_q ([y^j]F_q)z^q ∈ Q[[z]]，即逐个 z 系数取 y^j 的系数。这个映射是 Q-线性的，与 ∂_z 交换，并满足 [y^j](g·F) = g·[y^j]F（g ∈ Q[z]）和 [y^j](y^kF) = [y^{j−k}]F（j < k 时为 0）。

令 A_j := [y^j]A = Σ_{q≥1} a_{q,j}z^q/q!。它属于 zQ[[z]]。

**引理 2.** A_0 = L，A_1 = 0，A_2 = L²/2 + u − L；并且对 j ≥ 3，
  θA_j = u·A_{j−2} + u²·A_{j−3}。　　(★★)

*证.* 对 (★) 取 [y^j]（负下标的 A 记为 0）：
  (1−z)²A_j′ = [j=0](1−z) + [j=2]z + (1−z)A_{j−2} + zA_{j−3}。
(1−z)² 的常数项为 1，在 Q[[z]] 中可逆。两边乘 z(1−z)^{−2}，并用 z(1−z)^{−1} = u、z²(1−z)^{−2} = u²，得到
  θA_j = [j=0]u + [j=2]u² + uA_{j−2} + u²A_{j−3}。

逐个 j 看：
- j = 0：θA_0 = u = θL。
- j = 1：θA_1 = 0。
- j = 2：θA_2 = u² + uL。另一方面，由 (F2)(F4)，θ(L²/2 + u − L) = Lu + (u+u²) − u = u² + uL。

这些式子两边的级数都在 zQ[[z]] 中，由 (F3) 得到前三个结论。j ≥ 3 时就是 (★★)。∎

### 2.3 第三步：多项式模型

- Q[U,Λ] 是两个未定元的多项式环。D 是其上唯一满足 DU = U + U²、DΛ = U 的导子。显式地，
    D(U^aΛ^i) = a·U^aΛ^i + a·U^{a+1}Λ^i + i·U^{a+1}Λ^{i−1}。
- ev : Q[U,Λ] → Q[[z]] 是 U ↦ u、Λ ↦ L 的 Q-代数同态。
- **(F6)** ev∘D = θ∘ev。
  - 证：两边都是满足 δ(FG) = δ(F)ev(G) + ev(F)δ(G) 的 Q-线性映射。对左边，这来自 D 的 Leibniz 法则和 ev 是同态；对右边，来自 (F2)。
  - 两者在 1、U、Λ 上相等：分别是 0、u+u²、u，用 (F4)。对单项式的次数归纳，它们在每个单项式上相等，再由线性处处相等。
- **(F7)** 若 F 无常数项，则 ev(F) ∈ zQ[[z]]，因为 u, L ∈ zQ[[z]]。
- **权重**：wt(Λ^i) := i；a ≥ 1 时 wt(U^aΛ^i) := i+1。W_k 是权重 ≤ k 的单项式张成的子空间，W_0 = Q。显然 W_k ⊆ W_{k+1}，且 W_k 中单项式的 Λ-次数都 ≤ k。这个权重就是 R2 的指标 ι。

**引理 3（D 的右逆）.** 对 a ≥ 1、i ≥ 0 递归定义（外层对 a 归纳，a 固定时对 i 归纳）：
  G_{1,i} := Λ^{i+1}/(i+1)，　G_{a+1,i} := (U^aΛ^i − a·G_{a,i} − i·G_{a+1,i−1})/a（i = 0 时没有最后一项）。
则：
- (i) D G_{a,i} = U^aΛ^i；
- (ii) G_{a,i} 无常数项；
- (iii) G_{a,i} ∈ W_{i+1}；
- (iv) G_{2,i} − UΛ^i + Λ^{i+1}/(i+1) ∈ W_i；
- (v) G_{a,i} 关于 U 的次数 ≤ a−1。

*证.*
- (i)：a = 1 时 D(Λ^{i+1}) = (i+1)Λ^iU。归纳步：D G_{a+1,i} = [D(U^aΛ^i) − aU^aΛ^i − iU^{a+1}Λ^{i−1}]/a = U^{a+1}Λ^i，代入 D 的显式式即得。
- (ii)(iii)(v)：沿同一归纳逐项检查。U^aΛ^i（a ≥ 1）无常数项，权重 i+1，U-次数 a。由归纳假设，G_{a,i} 与 G_{a+1,i−1} 无常数项，权重分别 ≤ i+1 与 ≤ i，U-次数分别 ≤ a−1 与 ≤ a。
- (iv)：a = 1 的递归式就是 G_{2,i} = UΛ^i − G_{1,i} − i·G_{2,i−1}，而由 (iii)，G_{2,i−1} ∈ W_i。∎

把 U^aΛ^i ↦ G_{a,i} 线性延拓，得到 D^{−1} : U·Q[U,Λ] → Q[U,Λ]。由引理 3：
- D∘D^{−1} = id；
- D^{−1}(S) 无常数项；
- 若 S 的每个单项式都含 U 且 Λ-次数 ≤ k，则 D^{−1}(S) ∈ W_{k+1}。

**定义.** P_0 := Λ，P_1 := 0，P_2 := Λ²/2 + U − Λ；j ≥ 3 时 P_j := D^{−1}(U·P_{j−2} + U²·P_{j−3})。括号里每个单项式都含 U，所以定义合法。

**引理 4.** 对一切 j ≥ 0，ev(P_j) = A_j。
*证.* j ≤ 2 时就是引理 2。设 j ≥ 3，且结论对小于 j 的下标成立。由引理 3(ii) 与 (F7)，ev(P_j) ∈ zQ[[z]]。再由 (F6)、归纳假设和 (★★)：
  θ·ev(P_j) = ev(DP_j) = ev(UP_{j−2} + U²P_{j−3}) = uA_{j−2} + u²A_{j−3} = θA_j。
由 (F3)，ev(P_j) = A_j。∎

**引理 5.** P_j ∈ W_{⌊j/2⌋+1}，且 P_j 无常数项。
*证.* j ≤ 2 直接看。j ≥ 3 时，P_{j−2} ∈ W_{⌊j/2⌋}，P_{j−3} ∈ W_{⌊(j−1)/2⌋} ⊆ W_{⌊j/2⌋}。所以 UP_{j−2} + U²P_{j−3} 的每个单项式都含 U，Λ-次数 ≤ ⌊j/2⌋。由引理 3 后面的说明，P_j ∈ W_{⌊j/2⌋+1} 且无常数项。∎

### 2.4 第四步：从权重到 Stirling 表示

- 令 N_k := {Σ_{i=0}^k p_i(D)Λ^i : p_i ∈ Q[t]}。因为 D(p(D)Λ^i) = (t·p)(D)Λ^i，N_k 在 D 下封闭；并且 N_{k−1} ⊆ N_k。
- 对 a ≥ 1，令 g_{a,i}(t) := t·C(t−1, a−1)/(i+1) = t(t−1)⋯(t−a+1)/((a−1)!·(i+1))。

**引理 6.** 对 a ≥ 1、i ≥ 0，U^aΛ^i − g_{a,i}(D)Λ^{i+1} ∈ N_i。因此 W_k ⊆ N_k。

*证.* 对 a 归纳；a 固定时对 i 归纳。
- a = 1：UΛ^i = D(Λ^{i+1})/(i+1) = g_{1,i}(D)Λ^{i+1}，差为 0。
- a → a+1：由 D 的显式式，
    U^{a+1}Λ^i = (1/a)(D − a)(U^aΛ^i) − (i/a)·U^{a+1}Λ^{i−1}。
  - 由归纳假设，U^aΛ^i = g_{a,i}(D)Λ^{i+1} + n，n ∈ N_i。于是 (1/a)(D−a)(U^aΛ^i) = [(t−a)g_{a,i}(t)/a](D)Λ^{i+1} + (1/a)(D−a)n，后一项在 N_i 中，而 (t−a)g_{a,i}(t)/a = g_{a+1,i}(t)。
  - i ≥ 1 时，内层归纳假设给出 U^{a+1}Λ^{i−1} ∈ g_{a+1,i−1}(D)Λ^i + N_{i−1} ⊆ N_i。
  - 合起来就是 (a+1, i) 的结论。
- 最后：Λ^i ∈ N_i；a ≥ 1 时 U^aΛ^i ∈ N_{i+1}，而它的权重是 i+1。所以权重 ≤ k 的单项式都在 N_k 中。∎

**定理 A（存在性）.** 设 j ≥ 0，K := ⌊j/2⌋+1。
- 存在 p_{j,0}, …, p_{j,K} ∈ Q[t]，使 P_j = Σ_{i=0}^K p_{j,i}(D)Λ^i，并且 p_{j,0}(0) = 0。
- 令 π_{j,i} := i!·p_{j,i}（1 ≤ i ≤ K）。则对一切 q ≥ 1，a_{q,j} = Σ_{i=1}^K π_{j,i}(q)·c(q,i)。

*证.*
- 由引理 5、6，P_j ∈ W_K ⊆ N_K，所以分解存在。
- p_{j,0}(0) = 0：因为 D(1) = 0，p_{j,0}(D)·1 = p_{j,0}(0) 是常数。而 P_j 无常数项；i ≥ 1 时 D^dΛ^i 也无常数项（Λ^i 没有常数项，D 把无常数项的多项式映成含 U 的多项式）。比较常数项即得。
- 用 ev，由 (F6) 和引理 4：A_j = Σ_{i=1}^K p_{j,i}(θ)L^i = Σ_{i=1}^K π_{j,i}(θ)·(L^i/i!)。
- 由 (F1) 和 c 的定义，比较两边 z^q/q! 的系数即得结论。∎

### 2.5 第五步：唯一性

对 q ≥ 1、k ≥ 0 令 E_k(q) := c(q,k+1)/(q−1)!，另记 E_{−1} := 0。由 (F5)：E_0 ≡ 1；对 q ≥ 1、k ≥ 0 有 E_k(q+1) = E_k(q) + E_{k−1}(q)/q；E_1(q) = H_{q−1}。

**引理 U.** 设 K ≥ 0，ρ_0, …, ρ_K ∈ Q(t)，整数 q_0 ≥ 1 大于这些有理函数的全部正整数极点。若对一切整数 q ≥ q_0 有 Σ_{k=0}^K ρ_k(q)E_k(q) = 0，则 ρ_0 = … = ρ_K = 0。

*证.* 对 K 归纳。
- K = 0：ρ_0 在无穷多个整数处为 0，所以 ρ_0 = 0。
- K ≥ 1：设 ρ_K ≠ 0。把 q_0 增大到超过 ρ_K 的零点，除以 ρ_K，得到 E_K + Σ_{k<K} r_kE_k = 0（q ≥ q_0），其中 r_k := ρ_k/ρ_K。把 q 换成 q+1，用 E_k(q+1) = E_k(q) + E_{k−1}(q)/q 展开，再减去原式：
    E_{K−1}(q)/q + Σ_{k<K}(r_k(q+1) − r_k(q))E_k(q) + Σ_{1≤k<K} r_k(q+1)E_{k−1}(q)/q = 0　（q ≥ q_0）。
  这是 E_0, …, E_{K−1} 之间的一个有理函数系数关系。最后一个和只含 E_{K−2} 及以下，所以 E_{K−1} 的系数是 1/t + r(t+1) − r(t)，其中 r := r_{K−1}。由归纳假设这个系数恒为 0，即
    r(t+1) − r(t) = −1/t。
  这不可能，理由有两个，任取其一：
  - (分析) 对整数 N > N_1 ≥ q_0，有 r(N) = r(N_1) − Σ_{q=N_1}^{N−1} 1/q。这个和 ≥ ln(N/N_1) → ∞，又 ≤ 1 + ln N。所以 r(N) → −∞，同时 |r(N)| ≤ C + ln N。但对 r = f/g：若 deg f ≤ deg g，r(N) 有界；若 deg f > deg g，N 充分大时 |r(N)| ≥ cN（c > 0）。两种情形都矛盾。
  - (代数) 在 C(t) 中把 r 写成部分分式（部分分式分解唯一）。r(t+1) − r(t) 的多项式部分仍是多项式；每个单极点项 c_α/(t−α) 贡献 c_α/(t−(α−1)) − c_α/(t−α)；高阶极点项不贡献单极点项。所以 r(t+1) − r(t) 的全部单极点系数之和为 0，而 −1/t 的这个和是 −1。矛盾。
- 所以 ρ_K = 0，再由归纳假设其余 ρ_k 都为 0。∎

**推论 U.**
- (1) 设 π_i, π̃_i ∈ Q(q)。若对一切 q ≥ q_0（q_0 ≥ 1）有 Σ_{i=0}^K π_i(q)c(q,i) = Σ_{i=0}^K π̃_i(q)c(q,i)，则 π_i = π̃_i（1 ≤ i ≤ K）；π_0 与 π̃_0 不受任何约束。
  - 证：q ≥ 1 时 c(q,0) = 0，c(q,i) = (q−1)!·E_{i−1}(q)，用引理 U。
- (2) ev 是单射，即 u = z/(1−z) 与 L = −ln(1−z) 在 Q 上代数无关。因此 P_j 的分解 Σ p_{j,i}(D)Λ^i 也唯一（i = 0 项只有 p_{j,0}(0) = 0 有意义）。
  - 证：设 ev(F) = 0。由引理 6，F ∈ W_k ⊆ N_k，写成 F = Σ p_i(D)Λ^i。ev(F) 在 q ≥ 1 处的 e.g.f. 系数是 Σ_{i≥1} i!·p_i(q)c(q,i) = 0，由 (1) 得 p_i = 0（i ≥ 1）。于是 F = p_0(0)，再由 ev(F) = 0 得 F = 0。∎

所以 π_{j,i}（1 ≤ i ≤ K_j）由 a_{q,j}（只需充分大的 q）唯一决定，而 π_{j,0} 完全自由。系数必须限制为多项式（或有理函数），唯一性才有意义：允许任意函数时显然不唯一，例如可以把一切都放进 π_{j,1}(q) := a_{q,j}/(q−1)!。

### 2.6 第六步：子断言

对 P ∈ W_{k+1}（k ≥ 0）定义**顶层符号**
  σ_{k+1}(P)(t) := (k+1)!·( [Λ^{k+1}]P + Σ_{a≥1} [U^aΛ^k]P·g_{a,k}(t) ) ∈ Q[t]。

权重 ≤ k 的单项式都在 W_k ⊆ N_k 中；权重为 k+1 的单项式只有 Λ^{k+1} 与 U^aΛ^k（a ≥ 1）。所以由引理 6，
  P − (σ_{k+1}(P)(D)/(k+1)!)·Λ^{k+1} ∈ N_k。

取 P = P_j，k+1 = K_j，就得到 P_j 的一个分解，其 Λ^{K_j} 分量为 σ_{K_j}(P_j)/K_j!。由推论 U，π_{j,K_j} = σ_{K_j}(P_j)。

**引理 7.** 对 m ≥ 0，P_{2m} − Λ^{m+1}/(m+1)! ∈ W_m。
*证.*
- m = 0：P_0 = Λ。m = 1：P_2 − Λ²/2 = U − Λ ∈ W_1。
- m ≥ 2：由归纳假设，P_{2m−2} = Λ^m/m! + Y，Y ∈ W_{m−1}；由引理 5，P_{2m−3} ∈ W_{m−1}。于是
    UP_{2m−2} + U²P_{2m−3} = UΛ^m/m! + S，　S := UY + U²P_{2m−3}。
  S 的单项式都含 U，Λ-次数 ≤ m−1，所以 D^{−1}S ∈ W_m。而 D^{−1}(UΛ^m/m!) = G_{1,m}/m! = Λ^{m+1}/(m+1)!。∎

**引理 8.** 对 m ≥ 0，P_{2m+1} − ( −(m/(m+1)!)·Λ^{m+1} + [m≥1]·UΛ^m/m! ) ∈ W_m。
*证.*
- m = 0：P_1 = 0。
- m ≥ 1：由归纳假设（取 m−1），P_{2m−1} = β·Λ^m + [m≥2]·UΛ^{m−1}/(m−1)! + X，其中 β := −(m−1)/m!，X ∈ W_{m−1}。由引理 7（取 m−1），P_{2m−2} = Λ^m/m! + Y，Y ∈ W_{m−1}。于是
    UP_{2m−1} + U²P_{2m−2} = β·UΛ^m + (1/m!)·U²Λ^m + S，　S := [m≥2]·U²Λ^{m−1}/(m−1)! + UX + U²Y。
  S 的单项式都含 U，Λ-次数 ≤ m−1，所以 D^{−1}S ∈ W_m。
- 再算两个主项：D^{−1}(UΛ^m) = Λ^{m+1}/(m+1)；由引理 3(iv)，D^{−1}(U²Λ^m) = G_{2,m} ≡ UΛ^m − Λ^{m+1}/(m+1)（mod W_m）。合计
    P_{2m+1} ≡ (β − 1/m!)/(m+1)·Λ^{m+1} + UΛ^m/m! = −(m/(m+1)!)·Λ^{m+1} + UΛ^m/m!　（mod W_m）。∎

**定理 B.**
- (a) m ≥ 0 时 π_{2m,m+1} ≡ 1。由引理 7，[Λ^{m+1}]P_{2m} = 1/(m+1)!，且一切 [U^aΛ^m]P_{2m} = 0（这些单项式的权重是 m+1），所以 σ_{m+1}(P_{2m}) = 1。
- (b) m ≥ 1 时 π_{2m+1,m+1}(q) = q − m。由引理 8，并用 g_{1,m}(t) = t/(m+1)：
    σ_{m+1}(P_{2m+1}) = (m+1)!·(−m/(m+1)! + (1/m!)·t/(m+1)) = t − m。
  m = 0 时 P_1 = 0，π_{1,1} = 0，不是 q。所以 (b) 必须要求 m ≥ 1。
- (c) 由引理 2，A_1 = 0，所以对一切 q ≥ 1 有 a_{q,1} = 0。
- 由 (a)(b)，j ≠ 1 时 π_{j,K_j} ≠ 0，所以求和上限 ⌊j/2⌋+1 是精确的。∎

- **表述上的小问题（不影响结论）。**
  - (i) 子断言计算里的「−y[y^{2m}](ΦI)」应理解为 −yΦI 对 y^{2m+1} 系数的贡献，即 −[y^{2m}](ΦI)。

  - (iii) 「对乘积次可加」指次可加：ι(FG) ≤ ι(F) + ι(G)，例如 ι(u·u) = 1 < 2。用法正确。
- **结论**：R2 是一份正确的证明，补上唯一性的一段论证就完整了。它与本文在「后半段（权重 → Stirling 表示）」上是同一个想法；在「前半段（多项式结构的来源、顶层的计算）」和「唯一性」上是两条独立的路线。
