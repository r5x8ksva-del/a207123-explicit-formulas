## 4. 复核者给出的新证明（供下一位复核者逐句检查）

记号同 c4.md：b_i = 1 − x − ix³，P_m = ∏_{i≤m}b_i，W_m = 1 + x²Σ_{j=1}^m jP_{j−1}（W_{−1} = 1）；(n)_t 为下降阶乘。

### 4.1 定理 R1：对一切 q ≥ 1，gcd(Num_q, P_{q−1}) = 1

**引理 R1（同余）。** 对 0 ≤ i ≤ q−1：
  Num_q ≡ W_i·S_{q,i}  (mod b_i)，  S_{q,i}(x) := Σ_{t=0}^{q−1−i} C(q,t)·(q−1−i)_t·x^{3t}；
  W_i ≡ 1 + Σ_{l=1}^{i} l·(i)_l·x^{3l+2}  (mod b_i)。

*证明.* 由容斥式 C4-20：Num_q = Σ_{j=0}^{q}(−1)^{q−j}C(q,j)W_{j−1}∏_{v=j}^{q−1}b_v。因为 b_v = b_i + (i−v)x³，模 b_i 有 b_v ≡ (i−v)x³。
- j ≤ i 时乘积含 v = i，这一项为 0。
- j ≥ i+1 时，∏_{v=j}^{q−1}(i−v)x³ = (−1)^{q−j}x^{3(q−j)}(q−1−i)!/(j−1−i)!。又 W_{j−1} − W_i = x²Σ_{l=i+1}^{j−1}lP_{l−1}，而 l−1 ≥ i 时 P_{l−1} 含 b_i，所以 W_{j−1} ≡ W_i。
- 两个符号 (−1)^{q−j}·(−1)^{q−j} = +1，**恰好抵消**。令 t = q−j 即得第一式。

第二式：P_{l−1} ≡ ∏_{v<l}(i−v)x³ = (i)_l x^{3l}。∎
（r3-Num-cong、r3-W-cong：q ≤ 40、全部 i < q 精确带余除法核对。）

**引理 R2.** 对 b_i 的每个复根 ξ 和每个 q ≥ i+1，S_{q,i}(ξ) ≠ 0。

**引理 R3.** 对每个 i ≥ 0 和 b_i 的每个根 ξ，W_i(ξ) ≠ 0。

### 4.2 定理 R2（C4-28 的一般证明）

令 u := z/(1−z)，L := −ln(1−z)，θ := z·d/dz，A_j(z) := [y^j]A = Σ_q a_{q,j}z^q/q!。

1. **闭式改写。** 由 C4-29，Φ = (1−z)^{y³−y²}e^{y³u} = exp(y²L + y³(u−L))，I = ∫_0^u exp(−y²ℓ + y³(ℓ−w))dw，其中 ℓ = ln(1+w)。
2. **A_j ∈ Q[u,L]。**
   - [y^n]Φ = Σ_{2a+3b=n} L^a(u−L)^b/(a!b!) ∈ Q[u,L]。
   - [y^m]I = ∫_0^u P_m dw，P_m = Σ_{2a+3b=m}(−ℓ)^a(ℓ−w)^b/(a!b!) ∈ Q[w,ℓ]。由 d/dw[(1+w)^{s+1}ℓ^r] = (s+1)(1+w)^sℓ^r + r(1+w)^sℓ^{r−1} 归纳，(1+w)^sℓ^r 的形式原函数落在 span{(1+w)^{s+1}ℓ^{r′} : r′ ≤ r} ⊕ Q 中。代入 w = u，有 1+u = 1/(1−z)、ℓ(u) = L（形式恒等式）。所以 [y^m]I ∈ Q[u,L]。
   - A_j = [y^{j+2}]Φ + [y^{j+1}]Φ − Σ_{n+m=j−1}[y^n]Φ·[y^m]I。
3. **指标界。** 定义 ι(u^aL^b) := b + [a ≥ 1]，对乘积次可加。
   - [y^n]Φ 中 u^kL^{a+b−k} 的指标 ≤ a+b ≤ ⌊n/2⌋。
   - [y^m]I 的指标 ≤（P_m 的 ℓ-次数）+ 1 ≤ ⌊m/2⌋ + 1。
   
   所以 ι(A_j) ≤ ⌊j/2⌋ + 1。
4. **三角对应。** θ(u^aL^b) = a(u^a + u^{a+1})L^b + b·u^{a+1}L^{b−1}，θ 不增加指标。对 d ≥ 1，θ^dL^i 的首项（先比 u-次数，再比 L-次数）是 i(d−1)!·u^dL^{i−1}，其指标为 i；θ^0L^i = L^i。这些首项与全部单项式 u^aL^b 一一对应。于是任一 ι ≤ c 的 F ∈ Q[u,L] 都可以逐步消去首项，写成 i ≤ c 的 θ^dL^i 的有理组合。字典序在 N² 上是良序，消元必然终止。

### 4.3 一阶 ODE 与闭式的简短证明（对 C4-29 的改进）
