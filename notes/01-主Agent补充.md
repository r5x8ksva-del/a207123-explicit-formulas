# 主 Agent 补充推导（第一轮工作流运行期间）

## c_m 的闭式（主 Agent 推导，已做数值检查，正式核对见 verify_all）

记 ρ = ρ_m（y³ = y² + m 的唯一实根），x_m = 1/ρ。因为 b_v(x_m) = 1 − x_m − v x_m³ = (m − v) x_m³（用 1 − x_m = m x_m³），所以

- P_{j−1}(x_m) = ∏_{v=0}^{j−1} (m − v) x_m³ = (m)_j · x_m^{3j}（(m)_j 为下降阶乘），特别地 P_{m−1}(x_m) = m!·x_m^{3m}；
- W_m(x_m) = 1 + Σ_{j=1}^{m} j·(m)_j·x_m^{3j+2}；
- P_m'(x_m) = b_m'(x_m)·P_{m−1}(x_m) = −(1 + 3m x_m²)·m!·x_m^{3m}。

G_m = W_m/P_m 在 x_m 处是单极点，故 U_k(m) ~ c_m ρ^k，

  c_m = −W_m(x_m) / (x_m·P_m'(x_m)) = ρ^{3m+3} / ( m!·(ρ² + 3m) ) · ( 1 + Σ_{j=1}^{m} j·m!/(m−j)!·ρ^{−3j−2} )。

检查：
- m = 1：c_1 = (ρ⁶ + ρ)/(ρ² + 3) ≈ 2.20961；R_k ≈ c_1 ρ^k − 1（x = 1 处的极点贡献 −1）：R_9 ≈ 67.92、R_10 ≈ 100.0，与 68、100 吻合。
- m = 4：ρ = 2，括号 = 1 + 4/32 + 24/256 + 72/2048 + 96/16384 = 645/512，c_4 = (2^15/(24·16))·(645/512) = 645/6 = 107.5。
  数值：U_k(4)/2^k − 645/6 在 k = 100, 200, 300, 400 时分别为 −0.161, −1.39e−4, −1.20e−7, −1.03e−10（衰减比约 ρ_3/2 ≈ 0.932）。

## 块分解给出的 W_m 与 c_m 之间的联系

W_m(x_m) 的每一项 j·(m)_j·x_m^{3j+2} 正好对应「以截断块 E_j 结尾」的那一族序列在 x_m 处的贡献；常数 1 对应不以上升结尾的序列。
