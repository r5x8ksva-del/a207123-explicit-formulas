## 0. 记号与约定

- 合法：词 w = (w_1,…,w_k) 的每个相邻三元组 (a,b,c) 满足 good(a,b,c)：b = c 或 a ≥ max(b,c)。
- N(k,q)：长度 k、值域恰为 {1,…,q} 的合法词个数（core 用 {0,…,q−1}，平移等价）。N(0,0) = 1；越界（k < 0、q < 0、q > k）取 0。
- D(k,d) := N(k, k−d)（d = k − q 称为「超额」）。d < 0 时 D ≡ 0。
- e_d(k) := D(k,d) − p_d(k)（缺陷）。p_d := 0（d < 0）。
- b_i(x) := 1 − x − i·x³，P_m := ∏_{i=0}^{m} b_i，P_{−1} := 1；G_m := Σ_k U_k(m)x^k，G_{−1} := 1；F_q := Σ_k N(k,q)x^k（F_0 = 1，F_{−1} := 0）；Num_q := P_{q−1}F_q。
- c(n,i)：第一类无符号 Stirling 数；S(n,i)：第二类 Stirling 数；⟨⟨n,k⟩⟩：二阶 Euler 数（⟨⟨n,k⟩⟩ = (k+1)⟨⟨n−1,k⟩⟩ + (2n−1−k)⟨⟨n−1,k−1⟩⟩）；H_n、H_n^{(2)}：调和数。
- C⁺(n,r)：n 元集合的 r 元子集数（n < 0 时为 0）；C(n,r)：多项式二项式 n(n−1)…(n−r+1)/r!。

## 1. 基本引理（独立自证，不依赖草稿）

### 1.1 序不变性
若 φ 严格增，则 b = c ⇔ φ(b) = φ(c)，a ≥ max(b,c) ⇔ φ(a) ≥ max(φ(b),φ(c))。所以合法性只依赖相对大小；值域为某个 q 元集合 V 的合法词个数恒为 N(k,q)。因而 U_k(m) = Σ_q C(m+1,q)·N(k,q)，二项式反演得 N(k,q) = Σ_{i=0}^{q} (−1)^{q−i}C(q,i)·U_k(i−1)（U_k(−1) := [k=0]）。

### 1.2 引理 A（最大值首次出现的位置）
设 w 合法，M = max w，i = M 首次出现的位置。则 i ∈ {1,2}；若 i = 2 且 k ≥ 3，则 w_3 = M。
证明：若 i ≥ 3，看 (w_{i−2}, w_{i−1}, M)：w_{i−1} < M 故 b ≠ c；w_{i−2} < M = max(b,c) 故 a ≥ max 不成立，矛盾。若 i = 2、k ≥ 3，看 (w_1, M, w_3)：w_1 < M 使 a ≥ max 不成立，只能 b = c 即 w_3 = M。∎

### 1.3 定理 1.3（N 三角递推）【已证明】[c4-N-rec-dp, c4-N-dfs]
对 k ≥ 3、q ≥ 1：
  N(k,q) = N(k−1,q−1) + N(k−1,q) + (q−1)·[N(k−3,q−2) + 2N(k−3,q−1) + N(k−3,q)]，
初值 N(0,q) = [q=0]，N(1,q) = [q=1]，N(2,1) = 1，N(2,2) = 2。
证明：对值域恰为 {1..q} 的合法词按 q 的首次位置 i 分类（引理 A：i ∈ {1,2}）。
- i = 1：w = q·w′。w′ 的三元组都是 w 的三元组，故 w′ 合法；反之任取元素 ≤ q 的合法 w′，前缀 q 后新增三元组 (q, w′_1, w′_2) 满足 a = q ≥ max，合法。满射 ⇔ val(w′) ⊇ {1..q−1}，即 val(w′) = {1..q} 或 {1..q−1}：贡献 N(k−1,q) + N(k−1,q−1)。
- i = 2（k ≥ 3）：w = (a, q, q, w″)，1 ≤ a ≤ q−1，w″ 长 k−3 合法；反之新增三元组 (a,q,q)（b = c）、(q,q,w″_1)、(q,w″_1,w″_2)（a = q）都合法。满射 ⇔ val(w″) ⊇ {1..q−1}∖{a}，val(w″) 为 {1..q}、{1..q}∖{a}、{1..q−1}、{1..q−1}∖{a} 之一（大小 q, q−1, q−1, q−2）：贡献 (q−1)[N(k−3,q) + 2N(k−3,q−1) + N(k−3,q−2)]。
- i ≥ 3 不可能。∎
注：k = 2 时 i = 2 的词 (1,2) 不被公式计入（公式给 N(2,2) = 1，真值 2）——这正是 §4.1 的「边界缺陷」[q=2]x²。

### 1.4 定理 1.4（块分解，唯一因子分解）【已证明】[c4-pattern-brute 里的 decompose 断言]
块：S 块 [v]；T 块 [a,v,v]（a < v）；E 块 [a,v]（a < v）；v 称为块的层。
**定理**：词 w 合法 ⇔ w = κ_1κ_2⋯κ_r 或 w = κ_1⋯κ_r·ε，其中 κ_i 为 S 块或 T 块，层弱降 v(κ_1) ≥ ⋯ ≥ v(κ_r)，ε 为 E 块且 v(ε) ≤ 所有 v(κ_i)（r ≥ 0）。表示唯一，且可贪心求得：令 M = 剩余后缀 u 的最大值，若 u_1 = M 取 S 块 [M]；否则若 |u| = 2 取 E 块 u；否则取 T 块 (u_1,M,M)。
证明。(⇐) 从右往左归纳：设 w = κ·u，κ 为层 v 的 S/T 块，u 为（已知合法的）块词，其所有元素 ≤ v（后续层 ≤ v，a 值小于各自的层）。w 的三元组：κ 内部（T 块 (a,v,v)，b = c）；跨界的 (v,u_1,u_2)（S 块）或 (v,v,u_1)、(v,u_1,u_2)（T 块），首项都是 v ≥ max。单独的 E 块长度 2，无三元组。
(⇒) 对长度归纳：M = max w，由引理 A，首块为 [M]（i = 1）、或 w 本身是 E 块 [w_1,M]（i = 2、k = 2）、或 T 块 [w_1,M,M]（i = 2、k ≥ 3）；去掉首块后的后缀合法、元素 ≤ M，其首块层 = 其最大值 ≤ M，归纳即得层弱降、E 块（若有）层 ≤ 前面所有层。
唯一性：任一表示中首块的层等于 max w（层弱降且 a 值小于层）。若 w_1 = max w，首块不能是 T/E（它们首元素 a < 层），故为 [M]；若 w_1 < max w，首块是层 M 的 T 块或 E 块，而 E 块只能在末尾，故 |w| = 2 时为 E，否则为 T。逐块归纳。∎

**推论 1.5（G_m 与 W_m）**【已证明】[c4-Wm]：值 ⊆ {0..m} 的合法词 = B_m^*·(值 ⊆ {0..m−1} 的合法词 ∪ E_m)，B_m = {[m]} ∪ {[a,m,m]: a < m}（母函数 x + m x³），E_m = {[a,m]}（母函数 m x²），表示唯一。故 b_m G_m = G_{m−1} + m x²，W_m := P_mG_m = W_{m−1} + m x²P_{m−1}，W_{−1} = 1，即 W_m = 1 + x²Σ_{j=1}^{m} j·P_{j−1}。

## 2. D(k,d) 的多项式性

### 2.1 D 的递推【已证明】[c4-D-rec]
在定理 1.3 中取 q = k − d（需 k ≥ 3、k − d ≥ 1），逐项改写 N(k−1,q−1) = D(k−1,d)，N(k−1,q) = D(k−1,d−1)，N(k−3,q−2) = D(k−3,d−1)，N(k−3,q−1) = D(k−3,d−2)，N(k−3,q) = D(k−3,d−3)：
  D(k,d) = D(k−1,d) + D(k−1,d−1) + (k−d−1)·[D(k−3,d−1) + 2D(k−3,d−2) + D(k−3,d−3)]。（†）

### 2.2 d = 0, 1【已证明】[c4-D0, c4-D1]
- d = 0：（†）右边除 D(k−1,0) 外全为 0（d′ < 0 时 D ≡ 0），故 D(k,0) = D(k−1,0)（k ≥ 3），D(2,0) = N(2,2) = 2 ⇒ D(k,0) = 2（k ≥ 2）；D(1,0) = 1、D(0,0) = 1 是例外。
- d = 1：k ≥ 3 时 D(k,1) = D(k−1,1) + D(k−1,0) + (k−2)D(k−3,0)。k ≥ 5 时 D(k−1,0) = D(k−3,0) = 2，故 D(k,1) − D(k−1,1) = 2k − 2 = (k²−k−4) − ((k−1)²−(k−1)−4)；基点 D(4,1) = N(4,3) = 8 = 4²−4−4。所以 D(k,1) = k²−k−4（k ≥ 4）。例外：D(3,1) = 4（多项式值 2），D(2,1) = 1（多项式值 −2）。

### 2.3 定理 2（一切 d：门槛、次数、首项、缺陷）【已证明】
对每个 d ≥ 0，存在唯一多项式 p_d ∈ Q[k] 使 D(k,d) = p_d(k) 对一切 k ≥ 2d+2 成立；deg p_d = 2d，首项系数 c_d = 2/(2^d·d!)；并且
  e_d(2d+1) = (−1)^{d+1}(d+1)!，  e_d(2d) = (−1)^{d+1}(d+2)!/2。
特别地门槛 2d+2 对每个 d 都精确（2d+1 永远是例外）。

证明（对 d 归纳）。d = 0 见 2.2：p_0 = 2，e_0(1) = 1 − 2 = −1 = (−1)^1·1!，e_0(0) = 1 − 2 = −1 = (−1)^1·2!/2。设 d ≥ 1 且结论对一切 0 ≤ d′ < d 成立（d′ < 0 时 D ≡ 0 = p_{d′}，e_{d′} ≡ 0）。令
  R_d(k) := p_{d−1}(k−1) + (k−d−1)·[p_{d−1}(k−3) + 2p_{d−2}(k−3) + p_{d−3}(k−3)]。
(a) k ≥ 2d+3 时（†）适用（k ≥ 3，k−d ≥ 1），且 k−1 ≥ 2(d−1)+2、k−3 ≥ 2d = 2(d−1)+2 ≥ 2(d−2)+2 ≥ 2(d−3)+2，右边各 D 都已在多项式区：D(k,d) − D(k−1,d) = R_d(k)。
(b) 令 p_d(k) := D(2d+2,d) + Σ_{j=2d+3}^{k} R_d(j)（Faulhaber：对整数 k ≥ 2d+2 是 k 的多项式，取其多项式延拓）。由 (a) 对 k 归纳得 D(k,d) = p_d(k)（k ≥ 2d+2）；唯一性因多项式在无穷多点相等。
(c) p_d(k) − p_d(k−1) = R_d(k) 作为多项式恒等（在无穷多 k 上成立）。R_d 的最高次项只来自 (k−d−1)p_{d−1}(k−3)：次数 2d−1、首项 c_{d−1}（其余项次数 ≤ 2d−2）。故 deg p_d = 2d，2d·c_d = c_{d−1}，c_d = c_0/(2^d d!) = 2/(2^d d!)。
(d) 把（†）减去 (c) 的恒等式：凡（†）适用之处
  e_d(k) − e_d(k−1) = e_{d−1}(k−1) + (k−d−1)[e_{d−1}(k−3) + 2e_{d−2}(k−3) + e_{d−3}(k−3)]。（‡）
  取 k = 2d+2（≥ 4，k−d = d+2）：e_d(2d+2) = 0，e_{d−1}(2d+1) = 0，e_{d−2}(2d−1) = 0（2d−1 ≥ 2(d−2)+2），e_{d−3}(2d−1) = 0，故 e_d(2d+1) = −(d+1)·e_{d−1}(2(d−1)+1) = −(d+1)·(−1)^d d! = (−1)^{d+1}(d+1)!。
  取 k = 2d+1（≥ 3，k−d = d+1）：e_{d−1}(2d) = 0，e_{d−2}(2d−2) = 0，e_{d−3}(2d−2) = 0，故 e_d(2d) = e_d(2d+1) − d·e_{d−1}(2d−2) = (−1)^{d+1}(d+1)! − d(−1)^d(d+1)!/2 = (−1)^{d+1}(d+2)!/2。∎

（数值核对：[c4-pd-degree-lead]、[c4-pd-threshold]、[c4-defect-closed]，d ≤ 12、k ≤ 60。）

### 2.4 门槛如何由 p_{d−1}, p_{d−2}, p_{d−3} 的门槛决定
记 K_d 为 D(·,d) 的精确门槛。（†）在 k 处右边四项分别要求 k−1 ≥ K_{d−1}、k−3 ≥ K_{d−1}、k−3 ≥ K_{d−2}、k−3 ≥ K_{d−3}，即「差分步」从 B_d := max(K_{d−1}, K_{d−2}, K_{d−3}) + 3 起成立；于是 D(·,d) 从 B_d − 1 起是多项式，K_d ≤ B_d − 1。由于 K 递增，B_d = K_{d−1} + 3，起决定作用的是 (k−d−1)·D(k−3,d−1) 这一项（k−3 的平移）。而 (‡) 给出 e_d(B_d − 2) = −(d+1)e_{d−1}(K_{d−1} − 1) ≠ 0，所以 K_d = B_d − 1 = K_{d−1} + 2 精确，K_0 = 2 ⇒ K_d = 2d+2。

### 2.5 计算机辅助证明：d ≤ 12 的显式 p_d【已证明（计算机辅助）】[c4-pd-identity, c4-pd-table, c4-pd-threshold, c4-pd-exceptions]

### 2.6 命题 2.6（次首项系数）【已证明】[c4-pd-second]

## 3. 组合解释：模式展开

### 3.1 定义
设 w 是合法满射词（值域 {1..q}），按定理 1.4 分块。μ(x) := x 在 w 中出现的次数。w 的每次出现恰好属于下列之一：某个 S 块、某个 T 块的 a 或两个 v 之一、E 块的 a 或 v。称值 x **平凡**，若 μ(x) = 1 且这唯一一次出现是 S 块 [x]；否则称 x **特殊**。
Pat(d)：所有满足「值域为 {1..σ}（某个 σ ≥ 0）、所有值都特殊、长度 σ + d」的合法满射词（称为**模式**）。σ(w′) := 值的个数；β(w′) := 若 w′ 以 E 块结尾则为该 E 块的层，否则为 0。M(d;σ,β) := #{w′ ∈ Pat(d) : σ(w′) = σ, β(w′) = β}。

### 3.2 定理 3（模式展开）【已证明】[c4-pattern-expansion, c4-pattern-poly, c4-pattern-brute, c4-pattern-props]
(1) Pat(d) 有限：σ ≤ 2d+2，长度 ≤ 3d+2，β ∈ {0} ∪ {2,…,d+2}。
(2) 对一切 k ≥ d（q := k − d ≥ 0）：
  D(k,d) = Σ_{w′∈Pat(d)} C⁺(q − β(w′), σ(w′) − β(w′)) = Σ_{σ,β} M(d;σ,β)·C⁺(k−d−β, σ−β)。

证明。
(1) 设 w′ ∈ Pat(d) 有 t 个 T 块、ε ∈ {0,1} 个 E 块。A_2 := {x : μ(x) ≥ 2}，A_1 := {x : μ(x) = 1}。A_1 中的值都特殊，故每个都是某个 a 值或 E 块的层：|A_1| ≤ (t + ε) + ε。超额 d = Σ_x(μ(x)−1) ≥ |A_2|；又同一层 v 上若有 t_v 个 T 块则 μ(v) ≥ 2t_v，μ(v) − 1 ≥ t_v，求和得 d ≥ t。于是 σ = |A_1| + |A_2| ≤ t + 2ε + |A_2| ≤ 2d + 2。若 ε = 1：所有块的层 ≥ E 层 v_E，比 v_E 小的值不是任何块的层，又都出现，故都是 a 值；不同 a 值至多 t + 1 个，所以 β − 1 = #{值 < v_E} ≤ t + 1 ≤ d + 1。E 块的 a < v_E 要求 v_E ≥ 2，故 β ≠ 1。
(2) 约化映射 Φ：对满射合法 w（值域 {1..q}，超额 d），设特殊值集 S = {s_1 < ⋯ < s_σ}。删去所有平凡值的 S 块，并把 s_i 改记为 i，得 w′ := Φ(w)。删块后仍是层弱降的块词、E 块仍在末尾且层 ≤ 其余各层、a 值仍小于层，所以由定理 1.4 (⇐) w′ 合法，且（唯一性）其块恰为剩下的块；特殊值的出现次数与角色不变，故 w′ 的值全部特殊；长度 k − (q − σ)，超额 (k − q + σ) − σ = d。所以 w′ ∈ Pat(d)。
  另外：平凡值 x 是 S 块的层，所以 x ≥ v_E；而 v_E 本身特殊，x ≠ v_E，故 x > v_E = s_β。于是 {1,…,s_β} ⊆ S，即 s_i = i（i ≤ β）。
  逆映射 Ψ：给定 w′ ∈ Pat(d) 与 S = {s_1<⋯<s_σ} ⊆ {1..q} 且 s_i = i（i ≤ β(w′)），把 w′ 中 i 改为 s_i，再对每个 x ∉ S 插入 S 块 [x]：放在所有层 > x 的块之后、所有层 < x 的块之前（没有块的层等于 x，位置唯一；因 x > s_β，它在 E 块之前）。结果是合法块词（定理 1.4），值域 {1..q}，其中 x ∉ S 都平凡、S 中的值都特殊（角色继承自 w′），超额 d。
  由分块唯一性与插入位置唯一性，Φ∘Ψ 与 Ψ∘Φ 都是恒等。对固定 w′，满足条件的 S 个数为：β = 0 时 C⁺(q,σ)；β ≥ 2 时 s_1..s_β 固定为 1..β，其余 σ−β 个从 {β+1..q} 中选：C⁺(q−β, σ−β)（q < β 时为 0）。求和即得。∎

### 3.3 推论
**推论 3.3a（门槛与首项的组合证明）**：q ≥ d+2 时所有 q − β ≥ 0，C⁺ = C，于是 D(k,d) = Σ M(d;σ,β)·C(k−d−β, σ−β) 是 k 的多项式（即 p_d，[c4-pattern-poly]）。各项次数 σ − β ≤ 2d（ε = 0 时 σ ≤ t + |A_2| ≤ 2d；ε = 1 时 β ≥ 2、σ ≤ 2d+2），等号只在两族取到：
- ε = 0、σ = 2d：必须 t = |A_2| = d、每个 T 层只有一个 T 块且 μ = 2、a 值互不相同且只出现一次、没有 S 块。即把 {1..2d} 配成 d 对（对内小者为 a、大者为层），层按降序排列：(2d−1)!! 个。
- ε = 1、β = 2、σ = 2d+2：E 块 = [1,2]，其余 {3..2d+2} 同上配对：(2d−1)!! 个。
故首项系数 = 2(2d−1)!!/(2d)! = 2/(2^d d!)（与定理 2 一致；对比 S(k,k−d) 只有前一族，首项 1/(2^d d!)）。[c4-pattern-props]
**推论 3.3b（缺陷公式）**：对 0 ≤ q ≤ d+1，e_d(k) = −Σ_{w′: β(w′) > q} C(q−β, σ−β)（多项式二项式，q−β < 0 时 C(q−β,r) = (−1)^r C(r−q+β−1, r)）。q = d+1 时只有 β = d+2 的模式参与；这类模式必须 t = d、σ = 2d+2、σ−β = d，结构是：v_E = d+2，{1..d+1} 双射地分给 d 个 T 块与 E 块作 a 值，T 层为 {d+3..2d+2}——共 (d+1)! 个。所以 e_d(2d+1) = −(−1)^d(d+1)!，这是定理 2 中缺陷闭式的第二个（组合）证明。[c4-pattern-props 核对 β=d+2 的计数]
**例（d = 1）**：Pat(1) 共 7 个：β=0：(1,1)，(1,2,2)；β=2：(2,1,2)，(3,3,1,2)，(3,4,4,1,2)；β=3：(1,4,4,2,3)，(2,4,4,1,3)。所以 N(k,k−1) = C(q,1)+C(q,2)+C⁺(q−2,0)+C⁺(q−2,1)+C⁺(q−2,2)+2C⁺(q−3,1)（q = k−1，对一切 k ≥ 1 成立），q ≥ 3 时化为 q²+q−4 = k²−k−4。
**例（d = 2）**：N(k,k−2) = [C(q,1)+4C(q,2)+3C(q,3)+3C(q,4)] + [C⁺(q−2,0)+4C⁺(q−2,1)+5C⁺(q−2,2)+3C⁺(q−2,3)+3C⁺(q−2,4)] + [2C⁺(q−3,0)+6C⁺(q−3,1)+4C⁺(q−3,2)+6C⁺(q−3,3)] + 6C⁺(q−4,2)，q = k−2。抽查 k=6（q=4）：43+14+8+0 = 65 = N(6,4)；k=5（q=3）：18+5+2+0 = 25 = N(5,3)，而多项式值多出 6C(−1,2) = 6，正是 e_2(5) = −6。

### 3.4 M(d;σ,β) 的计算：按值自上而下的转移 DP（M 的递推）【已证明（构造）+ 已验证】[c4-pattern-brute, c4-pattern-expansion]
由定理 1.4，模式就是：对 x = σ, σ−1, …, 1 依次写下层为 x 的块（若干 S、T 块任意次序，可再接一个 E 块，且一旦放了 E 块，更低的值不能再作层），每个 T/E 块的 a 值是某个更小的值。DP 状态 (p, e, closed, β)：p = 尚未分配 a 值的 T/E 块数（它们位置不同、可区分），e = 已用超额。处理值 x 时：选 j ∈ [0,p] 个待分配块取 a = x（C(p,j) 种）；若未 closed，再选 s 个 S 块、t 个 T 块（C(s+t,s) 种次序）以及 ε ∈ {0,1}（是否在层 x 末尾放 E 块）。要求 μ(x) = s+2t+ε+j ≥ 1（满射）且 (s,t,ε,j) ≠ (1,0,0,0)（x 特殊）；更新 p ← p−j+t+ε，e ← e+μ(x)−1，closed ← closed ∨ ε，β ← x（若 ε = 1）。结束时要求 p = 0、e = d。这正好一一编码 Pat(d)（每个 a 值函数恰被生成一次）。DP 结果与「按定义 DFS 枚举合法满射词 + 贪心分块 + 平凡值判定」的暴力计数对 d ≤ 3 一致（核对模块内），d = 4 也一致（4990 个，46 秒，`logs/c4_explore9b_d4.log`）。

### 3.5 与 S(k,k−d) 的类比
- 经典：S(k,k−d) = Σ_{j=0}^{d−1} ⟨⟨d,j⟩⟩·C(k+d−1−j, 2d)（GKP (6.43)），对一切 k ≥ 0 成立、系数非负、无例外【已验证 d ≤ 8，k ≤ 60】[c4-stirling-analog]。等价地 S(k,k−d) = Σ_j S₂(d+j,j)·C(k,d+j)（S₂ = 每块至少 2 个元素的划分数）——这是「先选出非单元素块覆盖的 d+j 个元素」，与定理 3「先选出特殊值」完全同构；区别在于我们的模式里 E 块把最小的 β 个值钉死在底部（C(q−β, ·) 的平移），Stirling 情形没有这种钉死，所以没有例外。
- **定理 3.5（无「二阶 Euler 型」非负展开）**【已证明（计算机辅助），1 ≤ d ≤ 8】[c4-hstar-neg]：对任意整数 c，p_d(k) = Σ_{j=0}^{2d} h_j·C(k+c−j, 2d) 中总有 h_j < 0。
  证明：令 s := 2d − c，f(k) := p_d(k+s)，则 Σ_{k≥0} f(k)x^k = H(x)/(1−x)^{2d+1}，h_j = Σ_{i=0}^{j}(−1)^i C(2d+1,i)·f(j−i)，并且 f(k) = Σ_j h_j C(k−j+2d,2d) 对一切 k ≥ 0 成立，从而作为多项式成立，换回 k−s 即上式。h_1 = p_d(s+1) − (2d+1)p_d(s) 作为 s 的多项式是 2d 次、首项 −2d·c_d < 0。Fujiwara 根界给出 |s| > 2·max_i ⌈r_i^{1/i}⌉（r_i = |a_{n−i}/a_n|，r_n 取 |a_0/(2a_n)|）时 h_1 无根且与首项同号（偶次），即 h_1 < 0；界内的整数 s 逐个精确计算 h_0..h_{2d}，没有一个全部 ≥ 0。∎ d = 1 可手算：h_0 ≥ 0、h_1 ≥ 0 只在 s = 3 同时成立，而那时 h_2 = s²−3s−2 = −2 < 0。
  同时，完整序列分子 Q_d(x) := (1−x)^{2d+1}Σ_k D(k,d)x^k 是 ≤ 4d+2 次多项式且有负系数（d=1：x²+x³−x⁴+3x⁵−2x⁶），这是 Σ_k S(k,k−d)x^k = x^{d+1}Σ_j⟨⟨d,j⟩⟩x^j/(1−x)^{2d+1} 的直接对应物，也不非负。
- **命题 3.6（基点 2d+2 的 Newton 系数为正整数，一切 d）**【已证明】[c4-newton-pos]：记 N_K[f]_i := Δ^i f(K)。由 (c)，Δp_d(2d+2+n) = p_{d−1}(2d+2+n) + (d+2+n)[p_{d−1}(2d+n) + 2p_{d−2}(2d+n) + p_{d−3}(2d+n)]。归纳假设 p_{d′} 在基点 2d′+2 的 Newton 系数为正；基点右移 s ≥ 0 保持非负性（C(n+s,i) = Σ_l C(s,i−l)C(n,l)），而 p_{d−1}(2d+2+n)、p_{d−1}(2d+n)、p_{d−2}(2d+n)、p_{d−3}(2d+n) 分别是右移 2、0、2、4；乘 (α+n)（α = d+2 > 0）把系数 f_l 变为 f_l(α+l) + l·f_{l−1}，保持正性并把次数加一。因此 N_{2d+2}[p_d]_i > 0（1 ≤ i ≤ 2d），而 N_{2d+2}[p_d]_0 = D(2d+2,d) > 0（例如词 (d+2, d+1, …, 1, 1, …, 1) 合法满射）。系数是整数，因为 p_d 在整数点取整数值。∎

## 4. (C7) 分子 Num_q

### 4.1 F_q 的一阶递推（含边界缺陷）【已证明】[c4-F-rec]

5. **高次系数一般 j 的结构**：j ≤ 8 已证；一般 j 只能从 e.g.f. 的 y 展开给出「L、(1−z)^{−1}、z 的多项式」的形式，系数提取时 z^a 因子导致 c(q−1,·) 等下移项，未能证明系数总是 q 的多项式。
6. **Num_q 正系数的组合解释**：定理 4.6 的正项递推暗示存在，但没有找到；容斥式本身是交错的。
7. **「k ∈ [d+1, 2d+1] 全是例外」**：只对 k = 2d, 2d+1 一般证明；缺陷公式（推论 3.3b）里各项符号不一，无法一般地排除巧合为 0。
8. **基点 2d+1 的 Newton 系数正性、p_d(2d+1+m) 单项式系数正性**：仅验证 d ≤ 12。前者对奇数 d 需要 D(2d+1,d) > (d+1)!，后者更强，均未证。

## 6. 对草稿与提示词的复核意见

- 草稿 §3「D(k,d) = D(k−1,d) + D(k−1,d−1) + (k−d−1)[…]」：正确，但应注明适用范围 k ≥ 3 且 k − d ≥ 1（来自三角递推的 k ≥ 3、q ≥ 1）。
- 草稿「首项 2/(2^d d!)（是 S(k,k−d) 首项的 2 倍）」「成立门槛的粗估 k ≥ 2d+2（待精确化）」：都正确，且门槛对每个 d 都恰好是 2d+2（定理 2），2d+1 永远是例外，缺陷为 (−1)^{d+1}(d+1)!。
- 提示词 (C7) 与草稿「最低次项 2x^q」：对 q = 1 不成立（Num_1 = x，最低项系数 1）；应写成 q ≥ 2。次数 3q−2 与首项 (q−1)! 对 q = 1 也成立。
- 提示词 (C3)「N(k,k−1) = k²−k−4 在 k=4..14 成立；k=3 时 N=4」：正确，现已对一切 k ≥ 4 证明；另一例外是 k = 2（N(2,1) = 1，多项式值 −2）。
- 三角递推在 k = 2 时不成立（N(2,2) 公式给 1、真值 2），这正是 (C7) 推导里必须补的边界缺陷 [q=2]x²；草稿与提示词都没有写出这一项，但它们给的 Num_2 = 2x²+x⁴ 已经隐含了它。
- 未发现草稿或提示词的实质性错误。
