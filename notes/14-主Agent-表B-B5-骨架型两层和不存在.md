# 表 B 的 B5（续）：骨架型两层和不存在（2026-10-08）

目的：notes/13 §5 在一族「骨架型」双和里做过程序搜索（6 种形状、1440 组参数），没有找到 N^E 或 N 的公式，但那只是计算证据。这一族正是 N^c 的正项双和（报告 T2.8(2) 的 R 式）所在的类。本文对整族给出证明：

**定理 14.1（骨架型两层和）**：设 a≤−1，b、c、d、e、f、s_0 为整数，A(p,s)∈C（p∈Z，s≥s_0）。称三角 T(k,q) 有**骨架型表示**，若存在 q_0 与门槛 k_0(q)（可以依赖 q）使
  T(k,q) = Σ_{s≥s_0} Σ_{p∈Z} A(p,s)·C(q+e, p+f)·C(k+as+bp+c, s+q+d)　对一切 q≥q_0、k≥k_0(q)。
（二项式按报告的约定：除非 0≤r≤n，否则 C(n,r)=0。每个 (k,q) 处只有有限多项非零，见引理 14.1。）则：
(i) N 与 N^E 都没有骨架型表示（对一切 a≤−1 与其余参数）。
(ii) 若 N^c 有骨架型表示，则 (a,b)=(−2,1)、e=0 且 3(d+1)=d−c+f。R 式 N^c(k,q)=Σ_sΣ_pC(q,p)R(p,s)C(k−2s+p−1, s+q−1)（(a,b,c,d,e,f)=(−2,1,−1,−1,0,0)，A=R）满足这些条件。

所以在「Stirling×二项式」这条路上，N 与 N^E 没有与 N^c 的 R 式同型的两层公式；notes/13 §5 搜索的 6 种形状 (a,b)∈{(−2,1),(−2,0),(−1,1),(−1,0),(−3,1),(−2,2)} 都在定理范围内（那里的方程取在 1≤q≤k 上，相当于 k_0(q)=q；那里的系数族 s≤7、0≤p≤2s+2 是这里系数族的子族）。障碍的来源：q 方向的容斥让 b_2 根处的留数按 q 形成指数型级数 e^{−2V/(1+V)}，而 N^E、N 的留数元 W̃_2−1、W̃_2 的范数是 17/8、103/16，其中 17、103 的指数为 1，不是 3 的倍数，所以与 e^{−2V/(1+V)} 相乘的常数不可能在三个共轭根处相同；N^c 的留数元是 1，没有这个阻碍。

**范围**：a≥0 的形状不在定理内（a=0 时 U=x/(1−x)，C(x)=C(U)，引理 14.3 没有约束；a≥1 时 U 的 x-赋值 ≤0，引理 14.1 的级数一般不收敛）。q 方向换成别的核（例如两个二项式之积、q 的 Stirling 数）、或以 r-Stirling 数、c_i 为原子的两层公式，都没有讨论，所以 B5 仍是开放问题。

## 1. 生成函数

**引理 14.1（行母函数）**：记 U:=x^{1−a}/(1−x)（x-赋值 1−a≥2），ψ_p(U):=Σ_{s≥s_0}A(p,s)U^s∈C((U))；不妨设 p+f<0 时 A(p,s)=0（这些项乘的是 C(q+e,p+f)=0）。若 q+d+s_0≥0，则第 q 行 X(k,q):=Σ_{s,p}A(p,s)C(q+e,p+f)C(k+as+bp+c, s+q+d) 满足
  Σ_k X(k,q)x^k = (x/(1−x))^q·x^{d−c}(1−x)^{−(d+1)}·Σ_p C(q+e,p+f)·x^{−bp}·ψ_p(U)。
每个 (k,q) 处只有有限多项非零：p 只取 0≤p+f≤q+e，s 由 s≥s_0 与 s+q+d≤k+as+bp+c（即 (1−a)s≤k+bp+c−q−d）夹住。
证明：r:=s+q+d≥0 时 [x^k]x^n(1−x)^{−(r+1)}=C(k−n+r, r)；取 n=(1−a)s+q+d−c−bp，k−n+r=k+as+bp+c。∎

不妨设 q_0≥max(1, −e, −d−s_0, −d−1)（表示对 q≥q_0 成立，对更大的 q_0 也成立）。于是 q≥q_0 时行母函数公式成立，且 F^T_q = Σ_kX(k,q)x^k − L_q(x)，L_q 是 Laurent 多项式（只差 k<k_0(q) 的有限多项；行母函数的 x-赋值有下界）。下面只用到「对每个 q≥q_0，L_q 是 Laurent 多项式」，所以门槛依赖 q 不影响证明。

**引理 14.2（二元母函数）**：引入变量 z，令 Z:=xz/(1−x)、V:=x^{−b}Z/(1−Z)=x^{1−b}z/(1−x−xz)（z=x^{b−1}(1−x)V/(1+x^bV)，所以 z 与 V 的形式幂级数互相表示），
  P:=x^{d−c+b(f−e)}(1−x)^{−(d+1)}V^{f−e}(1+x^bV)^{e+1}，Ψ(U,V):=Σ_pψ_p(U)V^p，m:=q_0+e≥0。则
  Σ_{q≥q_0}(F^T_q+L_q)z^q = P·[Ψ(U,V) − Σ_{0≤p+f<m} ψ_p(U)·x^{−bp}E_p(x,V)]，
其中 E_p:=x^{−b(f−e)}V^{e−f}(1+x^bV)^{−(e+1)}·D_p(x^bV/(1+x^bV))，D_p(Z):=Σ_{q=p+f−e}^{q_0−1}C(q+e,p+f)Z^q。E_p 是 (x,V) 的有理函数，展开成 V 的级数后系数是 x 的 Laurent 多项式。
证明：由引理 14.1，左边 = x^{d−c}(1−x)^{−(d+1)}Σ_px^{−bp}ψ_p(U)·Σ_{q≥q_0}C(q+e,p+f)Z^q。对 n:=p+f≥0，Σ_{q≥−e}C(q+e,n)Z^q=Z^{n−e}(1−Z)^{−(n+1)}，从中减去 q<q_0 的有限和 D_p(Z)（只在 n<m 时非零）。又 Z/(1−Z)=x^bV、1/(1−Z)=1+x^bV，所以 Z^{n−e}(1−Z)^{−(n+1)}=(x^bV)^{n−e}(1+x^bV)^{e+1}，对 p 求和得 P·Ψ。
换元的合法性：上面各式先在 C((x))((z)) 中成立（e>0 时 Z^{−e} 带来 z 的负幂，但阶有下界）。z=V·ε，ε:=x^{b−1}(1−x)(1+x^bV)^{−1}∈C((x))[[V]] 的常数项不为零，是单位，所以 z↦Vε 给出 C((x))((z)) 到 C((x))((V)) 的保阶同构；第 p 项的 V-阶是 p+f−e，随 p 增大趋于无穷，所以对 p 的求和在 C((x))((V)) 中收敛。∎
（`check_b5_skel.py` 的 b5s-bivar 用 N^c 的 R 式端到端核对了这个恒等式：只用 q≥1 的行、以及假装只用 q≥3 的行（低 p=0,1,2 有修正项），两边逐项相同；去掉修正项就不成立。）

记 H(x,V):=[Σ_{q≥q_0}F^T_qz^q]/P、L̂(x,V):=[Σ_{q≥q_0}L_qz^q]/P，都看成 V 的级数（z 换成 V）。z^q/P=x^{q(b−1)−(d−c)−b(f−e)}(1−x)^{q+d+1}V^{q+e−f}(1+x^bV)^{−(q+e+1)}，q≥q_0≥−d−1 时 (1−x) 的指数非负。所以 H 的 V^n 系数 h_n 是有限多个 F^T_q（q≤n+f−e）乘以 x 的整数幂与 (1−x) 的非负整数幂的组合：它是有理函数，极点只在 0 与 b_v（v≥0，b_0=1−x）的根，并且在每个 b_v 的根处至多单极点（F^T_q 的分母整除 P_{q−1}（T1.8），P_{q−1} 无重根：不同的 b_v 没有公共根，b_v（v≥1）的判别式 −v(27v+4)≠0）。L̂ 的系数是 Laurent 多项式。引理 14.2 即

## 2. 有理化

**引理 14.3**：存在 ρ_p∈C(U)（p∈𝓛）与 Ψ̂(U,V)=Σ_nψ̂_n(U)V^n（ψ̂_n∈C(U)），使 H+L̂ = Ψ̂(U,V) − Σ_{p∈𝓛}ρ_p(U)x^{−bp}E_p(x,V)。
证明：r:=1−a≥2。x 满足 x^r+Ux−U=0，它在 U 处 Eisenstein，所以 1,x,…,x^{r−1} 是 C((U))(x)=C((x)) 在 C((U)) 上的基，也是 C(x) 在 C(U) 上的基（notes/06 §2(2) 的论证；C(x)∩C((U))=C(U)）。对 (★) 取第 1,…,r−1 个坐标（Ψ 只有第 0 个坐标）：对每个 n 与 1≤i≤r−1，
  Σ_{p∈𝓛} ψ_p(U)·coord_i([V^n](x^{−bp}E_p)) = −coord_i([V^n](H+L̂))。
系数与右边都在 C(U) 中，未知数只有有限多个（|𝓛| 个）。这个方程组在 C((U)) 上有解 (ψ_p)，所以在 C(U) 上有解 (ρ_p)：取前 N 个方程，C(U) 上的解集是非空的仿射子空间（有限方程组在扩域上可解则在原域上可解），随 N 增大递减，维数有限，故稳定，交集非空。于是 Θ:=Σ_p(ψ_p−ρ_p)x^{−bp}E_p 的第 1,…,r−1 个坐标全为零，Θ∈C((U))((V))。令 Ψ̂:=Ψ−Θ，则 H+L̂=Ψ̂−Σρ_px^{−bp}E_p，且 ψ̂_n=[V^n](H+L̂+Σρ_px^{−bp}E_p)∈C(x)∩C((U))=C(U)。∎

## 4. 定理 14.1 的证明

**主部引理（留数的拉回）**：设 φ∈C(U)，U_0∈C，ζ 是 U(x)−U_0 的零点，重数为 ν_ζ。则
  Res_{U=U_0}φ = (1/ν_ζ)·Res_{x=ζ}[φ(U(x))·U′(x)]。
（在 ζ 附近取局部坐标 t 使 U−U_0=t^{ν_ζ}，则 φ(U)dU=φ(U_0+t^{ν})·νt^{ν−1}dt，两边比较 t^{−1} 的系数；微分的留数与坐标无关。）特别地：g 在 ζ 解析时 Res_{x=ζ}[gU′]=0；g 在 ζ 至多单极点时 Res_{x=ζ}[gU′]=U′(ζ)Res_{x=ζ}g。下面对各项的每个 V^n 系数乘以 U′(x) 后取 Res_{x=ζ}。
**ρ 项的计算**：设 ζ 不是 0，g_p:=x^{−bp}E_p(x,V)。Res_{x=ζ}[ρ_p(U(x))·[V^n]g_p·U′] 是 ρ_p(U(x)) 在 ζ 的有限多个负幂系数与 [V^n]g_p·U′ 在 ζ 的 Taylor 系数的双线性组合；对 n 求和，Σ_nV^n[(x−ζ)^j]([V^n]g_p) 就是 g_p(x,V) 关于 x 在 ζ 的 Taylor 系数（g_p 是 (x,V) 的有理函数，乘以 V 的适当幂后在 (ζ,0) 附近解析，两种展开次序一致），它是 V 的有理函数。所以每个 ρ 项对 n 求和后给出 V 的有理函数。
