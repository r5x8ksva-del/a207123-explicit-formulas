## 1. 陈述

记 b_v=1−x−v·x³，P_m=∏_{v=0}^{m}b_v，W_m=1+x²Σ_{j=1}^{m} j·P_{j−1}（T1.3）。以上升结尾的合法序列数 E(k,m) 的母函数是

  E_m(x) := Σ_k E(k,m)x^k = (W_m−1)/P_m = x²·Σ_{j=1}^{m} j / ∏_{v=j}^{m} b_v.

（T2.2 的块分解：以截断块 E_j 结尾的部分；`rv4-t26ii-a` 用自写 DP 核对到 m≤6、k≤30。）

**定理 T2.6(ii)**。设 m≥2，u:=x³/(1−x)。不存在整数 g 与 Ã∈C((u))，使 E_m(x)−x^g·Ã(u) 是 x 的 Laurent 多项式。特别地，不存在整数 c、d、k_0 与一列与 k 无关的复数 A(s)，使 E(k,m)=Σ_s A(s)·C(k+c−2s, m+s+d) 对一切 k≥k_0 成立。

（m=1 时结论不成立：E_1 = x²/b_1 = x^{−1}·u/(1−u) 本身就是 u 型。）

## 2. 证明

**第 1 步（u 型单和 ⇒ 母函数形状）**。与定理 S 相同：Σ_k C(k+c−2s, n)x^k = x^{n−c+2s}/(1−x)^{n+1}，把 1/(1−x)=u·x^{−3} 代入，n=m+s+d 时得 x^g·u^{s+m+d+1}，g=−2(m+d)−c−3 与 s 无关；k<k_0 的部分只差有限多项。所以 E_m = x^g·Ã(u)+（Laurent 多项式），Ã(u)=Σ_s A(s)u^{s+m+d+1}∈C[[u]]。

**第 2 步（Ã 是有理函数）**。x 满足 T³+uT−u=0（由 x³=u(1−x)），这在素元 u 处是 Eisenstein 多项式，故在 C((u)) 上不可约，[C((u))(x):C((u))]=3，1、x、x² 在 C((u)) 上线性无关。x^g·Ã = E_m − L ∈ C(x)=C(u)(x)，所以 Ã = x^{−g}(E_m−L) ∈ C(x)∩C((u))；C(x) 中元素写成 a+bx+cx²（a,b,c∈C(u)），属于 C((u)) 当且仅当 b=c=0，故 Ã∈C(u)。

**第 3 步（纤维 u=1/i 上的留数）**。b_i(x)=0 ⇔ 1−x=i·x³ ⇔ u=1/i，所以 b_i 的三个根恰好组成纤维 u=1/i；不同的 i 对应不同的纤维，P_m 的根两两不同，E_m 的极点都是单极点。设 1≤i≤m，η 是 b_i 的根。
- 在 η 处 1−η=iη³，所以 **b_v(η)=(i−v)η³**（`rv4-t26ii-b`）。
- b_i′(x)=−1−3ix²，用 iη³=1−η：η·b_i′(η)=−η−3(1−η)=2η−3，即 **b_i′(η)=(2η−3)/η**（同上）。
- u′(x)=x²(3−2x)/(1−x)²，故 u′(η)=(3−2η)/(i²η⁴)。

E_m 里含 1/b_i 的项是 j≤i 的项。于是

  Res_η E_m = η²·Σ_{j=1}^{i} j / (b_i′(η)·∏_{v=j, v≠i}^{m} b_v(η)),
  ∏_{v=j, v≠i}^{m} b_v(η) = η^{3(m−j)}·(i−j)!·(−1)^{m−i}(m−i)!.

再记 W̃_i:=1+Σ_{j=1}^{i} j·i^{\underline j}·x^{3j+2}（i^{\underline j}=i!/(i−j)!），则 Σ_{j=1}^{i} j·η^{3j}/(i−j)! = (W̃_i(η)−1)/(i!·η²)。代入、并用 (3−2η)/b_i′(η)=−η，得到

  **Res_η E_m · u′(η) = (−1)^{m−i+1}·(W̃_i(η)−1)·η^{−3m−3} / ((m−i)!·i!·i²).**

（`rv4-t26ii-c`：在 Q[x]/(b_i) 中对 1≤i≤8、i≤m≤40 共 292 组精确成立。）

**第 4 步（与 Ã 比较，得到有理性）**。在 η 附近 u 是局部坐标（u′(η)≠0，因为 η≠3/2），E_m−L 在 η 有单极点，所以 Ã 在 u=1/i 至多有单极点，且 Res_η E_m = η^g·Res_{u=1/i}Ã / u′(η)。于是

  R(η) := Res_η E_m · u′(η) · η^{−g} = Res_{u=1/i} Ã

对 b_i 的三个根取同一个值。R 是 Q(x) 中的有理函数在 η 处的值；当 b_i 在 Q 上不可约时，三根是共轭，R 在三根处的值是互相共轭的代数数，全部相等就意味着 R(η)∈Q。

**第 5 步（取 i=2，m≥2）**。b_2=1−x−2x³ 没有有理根（候选 ±1、±1/2 都不是根），所以在 Q 上不可约（`rv4-t26ii-e1`）。W̃_2−1=2x⁵+4x⁸，用 2η³=1−η 得 2+4η³=4−2η，故 W̃_2(η)−1=η⁵(4−2η)（`rv4-t26ii-d2`）。由第 3、4 步，

  θ := (4−2η)·η^{n} ∈ Q，n := 2−3m−g.

在 K_2=Q(η) 中 N(η)=1/2、N(4−2η)=68（`rv4-t26ii-d1`），所以 N(θ)=68·2^{−n}=17·2^{2−n}。而 θ∈Q 时 N(θ)=θ³，其 17-进赋值是 3 的倍数；这里却是 1（`rv4-t26ii-d4` 对 |n|≤60 逐个核对，一般 n 由上式直接可见）。矛盾。∎

**另一条更初等的路线**（x1 也给出过）：先用纤维 u=1（i=1）：W̃_1−1=x⁵，条件变成 ξ^{5−3m−3−g}∈Q，ξ 是 b_1 的根；若指数 n≠0 而 ξ^n∈Q，则三个共轭的 |ξ_j|^n 应相等；但实根的模约 0.682，两个复根的模约 1.211（三根之积为 1），不相等，所以指数必须为 0，即 g=2−3m。再用纤维 u=1/2：此时 n=0，θ=4−2η∈Q，与 η∉Q 矛盾。
