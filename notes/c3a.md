## 阶段性结论

1. **【已证明 + 已验证 k≤40, m≤20】** 在 Q(x)[[t]] 中
   Σ_m t^m/P_m = ₁F₁(1; 1−λ; −t/x³)/(1−x)，λ = (1−x)/x³。逐项就是 i − λ = −b_i/x³；每个 t^m 系数 1/P_m 是分母常数项为 1 的整系数有理函数，所以恒等式实际落在 Z[[x,t]] 里（Pochhammer 符号 (1−λ)_n 与 (−t/x³)^n 的系数各自在 x=0 有 3n 阶极点，逐项相消）。组合意义：[x^k t^m] = 「{0..m}^k 中不以上升结尾的合法序列数」。Kummer 变换 ₁F₁(1;1−λ;a) = e^a ₁F₁(−λ;1−λ;−a) 与下不完全 Gamma 形式 Σ t^m/P_m = −x^{−3}e^a·a^λγ(−λ,a) 都在 Q(x)[[t]] 中成立，但其中单个因子（如 e^{−t/x³}）不在 Q[[x]][[t]] 里。
2. **【已证明 + 已验证 k≤60, m≤30】** 草稿 §3 的形式 Laplace 表示成立：F = (1/(1−x))·ℒ_s[exp((t/x³)(e^{us}−1))·(1 + x²te^{us}/(1−te^{us})²)]，u = x³/(1−x)，ℒ_s[s^N] = N!。更一般地（**一般原理**，已证明）：对任意 A∈Q[[x]]、A(0)=1 和任意右端 γ(x,t)，方程 (A−t)Y − x³tY_t = γ 在 Q[[x,t]] 中的唯一解是 Y = A^{−1}ℒ_s[exp((t/x³)(e^{vs}−1))·γ(x, te^{vs})]，v = x³/A。证明只用三件事：[s^N]被积式的 (x,t) 阶 ≥ N（良定义）、形式分部积分 ℒ[f′] = ℒ[f] − f(0)、算子恒等式 (A−t)Ψ − x³tΨ_t = A(Ψ − Ψ_s)。
3. **【已证明 + 已验证】** 整张表的「₁F₁ 和式」与「Kummer 形式」：F = Σ_{j≥0} c_j (t^j/b_j)·₁F₁(1; j+1−λ; −t/x³)（c_0 = 1，c_j = jx²），第 j 项（j≥1）恰是「以上升到值 j 结尾」的序列的母函数；F = x^{−3}e^{a}Σ_n φ_n a^n/(λ−n)，a = −t/x³，φ(τ) = e^{−τ}(1 − x⁵τ/(1+x³τ)²)。
   **有限闭式（Humbert / 合流 Appell 函数 Φ_1）**：F = (1/(1−x))·[₁F₁(1;1−λ;a) + x²((1−t)^{−2}Φ_1(1,2;1−λ;−t/(1−t),a) − (1−t)^{−1}Φ_1(1,1;1−λ;−t/(1−t),a))]，a = −t/x³（已验证 k≤40, m≤16）；一般地 (A−t)Y − x³tY_t = (1−t)^{−β} 的解是 (1/A)(1−t)^{−β}Φ_1(1,β;1−A/x³;−t/(1−t),−t/x³)。同样得到 𝒩 的 Φ_1 闭式（§6）。
4. **【已否定（草稿的解析版本）】** 草稿把收敛积分 I(x,t) = x^{−3}∫_0^∞exp((t(e^σ−1)−(1−x)σ)/x³)g(te^σ)dσ 写成「F =」。若把 F 理解为它在 t 方向的自然解析函数 S(x,t) := Σ_m t^m G_m(x)（|t|<1，G_m 取有理函数值），这**不成立**：严格反例 (x,t) = (3/5,−1/2) 处 I > 0 而 S ≤ −1057.81 < 0。精确关系（已证明）：I − S = x^{−3}K(x)e^{a}a^{λ}（一个齐次解），常数项部分 K = Γ(−λ) ≠ 0，即 Σ t^m/P_m = x^{−3}e^a[E_{λ+1}(a) − Γ(−λ)a^λ]，而 I 的常数项部分才是 x^{−3}e^aE_{λ+1}(a)。正确的解析陈述（已证明）：I 是 t∈(−∞,0) 上唯一在 t→−∞ 有界的解，且对固定 t<0 有渐近展开 I(x,t) ~ Σ_k f_k(t)x^k（x→0+，带显式误差界）；S 则是唯一在 t=0 解析的解，在 x_i（1−x−ix³ 的正根，x_i→0）处有单极点，留数 = Res_{x_i}G_i·t^i e^{−t/x_i³}。数值上两者在 |t| 小时只差 e^{−c/x³} 量级（例 (21/100,−1/20) 差 3.8×10^{−62}），|t| 大时差到天文数字（(21/100,−1/2)：S ≈ −9.73×10^{44}，I ≈ 0.7654，而 I 与渐近级数前 150 项相差 6×10^{−56}）。
5. **【已证明 + 已验证 k,q≤30】** N 的二元母函数 𝒩(x,y) = Σ N(k,q)x^k y^q：1 + tF(x,t) = 𝒩(x, t/(1−t))/(1−t)；PDE (1 − x(1+y) + x³(1−y²))𝒩 − x³y(1+y)²𝒩_y = 1 − x + x³ + x²y²，它与 (C3) 的三角递推**等价**（因此 (C3) 的递推由引理 1 推出，已证明）；显式表示有原生 Laplace 形式（A = 1−x+x³）、₁F₁ 形式和系数形式。
6. **【已证明 + 已验证 k≤30】** H(z,t) = Σ h_k(t)z^k = (1−t)F(z(1−t),t) = 1 + (𝒩(z(1−t), t/(1−t)) − 1)/t，满足 (1 − z − z³t(1−t))H − z⁴t(1−t)H_z − z³t(1−t)²H_t = 1 + z²t，取 z^k 系数即 (C6)。

## 0. 记号、环与核对来源

- 合法序列集 L_k(m) := {h ∈ {0..m}^k : 每个相邻三元组 (a,b,c) 满足 b = c 或 a ≥ max(b,c)}；U_k(m) = |L_k(m)|；L_0(m) = {()}；k≥1 时 L_k(−1) = ∅。
- F(x,t) = Σ_{k,m≥0} U_k(m)x^k t^m ∈ Z[[x,t]]；G_m(x) = Σ_k U_k(m)x^k；f_k(t) = Σ_m U_k(m)t^m。
- b_i := 1 − x − i x³；P_m := Π_{i=0}^m b_i（P_{−1} = 1）；λ := (1−x)/x³；u := x³/(1−x)；a := −t/x³；
  g(w) := 1 + x²w/(1−w)²；关键恒等式 **b_i = x³(λ − i) = (1−x)(1 − iu)**。
- 环：𝓟 := Q[[x,t]]（ord = 最低总次数）；R_Z := {p/q : p,q ∈ Z[x], q(0)=1} ⊂ Q(x) ∩ Z[[x]]（通过 Taylor 展开嵌入）。
  Q(x)[[t]] ⊃ R_Z[[t]] ⊂ Z[[x,t]]。λ 是 Q(x) 中的非常数元素，因而在 Q 上超越，特别地 λ ∉ Z。
- 定义层计数（核对时的「真值」）：`core.U_fast_table`（高度 DP，与 `core.U_multichain`、提示词表格互相锚定）；本模块的 `dp_stats`（同一三元组条件的细分 DP：不以上升结尾 / 以上升到 j 结尾，与 DFS `brute_stats` 锚定）；N(k,q) 用 `core.N_brute`（DFS 按满射词定义，k≤9）与 `core.N_from_U`（DP 表的二项式反演，其正确性见引理 6.1）。核对 id：**c3a-anchor**。

## 1. 引理 1、细分计数、PDE 与唯一性

**引理 1.1（三项递推）【已证明；已验证 k≤60, m≤41（c3a-pde-F）】** k≥1, m≥0：
U_k(m) = U_k(m−1) + U_{k−1}(m) + m·U_{k−3}(m)·[k≥3] + m·[k=2]
（等价于提示词的写法，约定 U_{−1} ≡ 1、U_{−2} ≡ 0）。

证明：按最大值 m 首次出现的位置 i 划分 L_k(m)。
- m 不出现：恰为 L_k(m−1)。
- i = 1：三元组 (m,b,c) 总合法（a = m ≥ max(b,c)），其余三元组只涉及 h_2..h_k，故 (h_2..h_k) ∈ L_{k−1}(m) 任意：U_{k−1}(m)。
- i = 2：h_1 = a < m（m 种），h_2 = m。k = 2 时无三元组：m 个。k ≥ 3 时 (a,m,h_3) 合法 ⇔ h_3 = m（因 a < m 使 a ≥ max 不成立）；之后 (m,m,h_4)、(m,h_4,h_5) 总合法，(h_4..h_k) ∈ L_{k−3}(m) 任意：m·U_{k−3}(m)。
- 3 ≤ i ≤ k：三元组 (h_{i−2}, h_{i−1}, m) 中 h_{i−1} < m 故 b ≠ c，h_{i−2} < m = max(b,c) 故 a ≥ max 不成立：不合法。∎

**命题 1.2（细分计数）【已证明；已验证 k≤40, m≤20（c3a-1f1-const, c3a-1f1-sum）】**
令 A_k(m) := #{h ∈ L_k(m) : k ≤ 1 或 h_{k−1} ≥ h_k}（不以上升结尾），
B^{(j)}_k(m) := #{h ∈ L_k(m) : k ≥ 2, h_{k−1} < h_k = j}（以上升到 j 结尾，1 ≤ j ≤ m）。则 U_k(m) = A_k(m) + Σ_{j=1}^m B^{(j)}_k(m)，且
  𝒜_m(x) := Σ_k A_k(m)x^k = 1/P_m，  ℬ^{(j)}_m(x) := Σ_k B^{(j)}_k(m)x^k = j x²/Π_{v=j}^m b_v，
因而 **G_m = 1/P_m + x² Σ_{j=1}^m j/Π_{v=j}^m b_v = W_m/P_m，W_m = 1 + x²Σ_{j=1}^m j P_{j−1}**。

证明：沿用引理 1.1 的划分，并跟踪「结尾类型」。在 i = 1（尾巴 h_2..h_k）和 i = 2、k≥3（尾巴 h_4..h_k）两种情形，若尾巴长度 ≥ 2，h 的最后两项就是尾巴的最后两项，结尾类型相同；若尾巴长度 ≤ 1，h 以 (m, h_k) 或 (m, m) 结尾，不是上升，而长度 ≤ 1 的尾巴按定义也计入「不以上升结尾」——两边一致。唯一的例外是 i = 2、k = 2：h = (a, m) 是上升到 m。于是对 k ≥ 1：
  A_k(m) = A_k(m−1) + A_{k−1}(m) + m A_{k−3}(m)[k≥3]，A_0 = 1，A_k(−1) = [k=0]；
  B^{(j)}_k(m) = B^{(j)}_k(m−1) + B^{(j)}_{k−1}(m) + m B^{(j)}_{k−3}(m)[k≥3] + j[k=2][m=j]，B^{(j)}_0 = 0，B^{(j)}_k(j−1) = 0。
乘 x^k 求和：b_m𝒜_m = 𝒜_{m−1}（𝒜_{−1} = 1），b_mℬ^{(j)}_m = ℬ^{(j)}_{m−1} + jx²[m=j]（ℬ^{(j)}_{j−1} = 0）。解得所述公式；最后 x²Σ_j j/Π_{v=j}^m b_v = x²Σ_j jP_{j−1}/P_m。∎

**定理 1.3（(C5) 的 PDE）【已证明；已验证 k≤60, m≤41（c3a-pde-F）】**
(1−x−t)F − x³t∂_tF = 1 + x²t/(1−t)²。
证明：左边 x^k t^m 系数为 U_k(m) − U_{k−1}(m) − U_k(m−1) − mU_{k−3}(m)（负下标项记 0）。k ≥ 1 时由引理 1.1 等于 m[k=2]（U_k(−1) = 0 与「记 0」一致）；k = 0 时为 U_0(m) − U_0(m−1) = [m=0]。右边系数 [k=m=0] + m[k=2]。∎

**定理 1.4（唯一性 / 可逆性）【已证明（proof-only）】** 设 A ∈ Q[[x]]，A(0) = 1，L_A[Y] := (A−t)Y − x³tY_t。则 L_A 是 𝓟 = Q[[x,t]] 上的双射（A ∈ Z[[x]] 时也是 Z[[x,t]] 上的双射）。
证明：L_A[Y] = γ 的 x^k t^m 系数式为 y_{k,m} = γ_{k,m} − Σ_{i≥1}A_i y_{k−i,m} + y_{k,m−1} + m y_{k−3,m}，右边只含 k+m 更小的系数，按 k+m 归纳唯一确定全部 y_{k,m}。∎
特别地 F 是 L_{1−x}[Y] = 1 + x²t/(1−t)² 的唯一形式幂级数解；形式环里齐次方程**没有**非零解（解析的齐次解 (−t)^λ e^{−t/x³} 不在 𝓟 中——第 5 节正是它区分了两种「解析 F」）。

## 2. 常数项部分：Σ_m t^m/P_m = ₁F₁(1;1−λ;−t/x³)/(1−x)

**约定。** 对 β ∈ Q(x) 且各 (β)_n := β(β+1)…(β+n−1) ≠ 0，₁F₁(α;β;z) := Σ_n (α)_n z^n/((β)_n n!) ∈ Q(x)[[z]]。β = j+1−λ 时 (β)_n 的每个因子 i − λ ≠ 0（λ ∉ Z），故良定义。代换 z ↦ a = −t/x³ 是连续 Q(x)-代数同态 Q(x)[[z]] → Q(x)[[t]]（Σc_nz^n ↦ Σc_n(−1)^n x^{−3n}t^n）。
由 i − λ = −b_i/x³ 得 **(\*)：(j+1−λ)_n = Π_{i=j+1}^{j+n}(i−λ) = (−1)^n x^{−3n} Π_{i=j+1}^{j+n} b_i**。

**定理 2.1【已证明；已验证 k≤40, m≤20（c3a-1f1-const），有理函数恒等式 n≤25（c3a-1f1-exact）】**
在 Q(x)[[t]] 中 Σ_{m≥0} t^m/P_m = ₁F₁(1; 1−λ; −t/x³)/(1−x)。
证明：右边 t^n 系数 = (1/(1−x))·(1)_n(−x^{−3})^n/((1−λ)_n n!) = (1/(1−x))·(−1)^n x^{−3n}/((−1)^n x^{−3n}Π_{i=1}^n b_i) = 1/(b_0Π_{i=1}^n b_i) = 1/P_n。∎
- **环**：1/P_n ∈ R_Z（P_n ∈ Z[x]，P_n(0)=1），所以恒等式落在 R_Z[[t]] ⊂ Z[[x,t]] 中；但 (1−λ)_n 与 z^n = (−t/x³)^n 在 Q((x)) 里各有 3n 阶极点，只有比值落在 Z[[x]]。
- **组合意义**（命题 1.2）：[x^k t^m] 右边 = A_k(m)。核对 c3a-1f1-const 正是把 Pochhammer 定义按 x 的 Laurent 级数展开（λ 取 x^{−3} − x^{−2}，逐因子 Laurent 求逆），确认负幂全部消去、非负幂等于 DP 的 A_k(m)。
- **Stirling 展开【已证明；已验证 k≤40, m≤20（c3a-1f1-stirling）】**：1/P_m = (1−x)^{−m−1}/Π_{i=1}^m(1−iu) = Σ_s S(m+s,m)x^{3s}(1−x)^{−m−s−1}，故 [x^k t^m] = Σ_s S(m+s,m)·C(k+m−2s, k−3s)（即提示词 (C4) 第一式；这里由经典的 Σ_N S(N,m)u^N = u^m/Π_{i=1}^m(1−iu) 直接得到）。

**定理 2.2（Kummer 变换）【已证明；已验证（c3a-kummer）】** 在 Q(x)[[t]] 中 ₁F₁(1;1−λ;a) = e^{a}·₁F₁(−λ;1−λ;−a)，e^{a} := Σ_n a^n/n! = Σ_n (−1)^n x^{−3n}t^n/n!。
证明：比较 a^n 系数，需证 Σ_{j=0}^n (−1)^j/((n−j)! j!)·λ/(λ−j) = 1/(1−λ)_n（右式 (−λ)_j/(1−λ)_j = λ/(λ−j)）。对 1/Π_{j=0}^n(λ−j) 做部分分式：系数 1/Π_{i≠j}(j−i) = (−1)^{n−j}/(j!(n−j)!)；乘 λ 得 1/Π_{j=1}^n(λ−j) = Σ_j (−1)^{n−j}λ/(j!(n−j)!(λ−j))。又 1/(1−λ)_n = (−1)^n/Π_{i=1}^n(λ−i)，(−1)^j = (−1)^n(−1)^{n−j}，即得。这是 Q(λ) 中的恒等式；λ ↦ (1−x)/x³ 是单的域同态 Q(λ) → Q(x)（像超越），再代换 a = −t/x³。∎
**注意**：e^{a} 的 t^n 系数 (−1)^n x^{−3n}/n!、₁F₁(−λ;1−λ;−a) 的 t^n 系数 (1−x)x^{−3n}/(n! b_n) 都在 x=0 有极点：Kummer 形式只在 Q(x)[[t]]（或 Q((x))[[t]]）中成立，不能逐因子放进 Q[[x,t]]。核对：Q(λ) 中的恒等式对 n ≤ 30 用「两边乘 Π_{j=0}^n(λ−j) 后为次数 ≤ n+1 的多项式，在 n+2 个随机有理点相等」精确证实；Kummer 形式的 Laurent 展开 = A_k(m)（k≤40, m≤20）。

**定理 2.3（下不完全 Gamma，形式版）【已证明；已验证 k≤40, m≤20（c3a-gamma）】**
形式地定义 a^λγ(−λ,a) := Σ_n (−a)^n/(n!(n−λ)) ∈ Q(x)[[t]]（来自 γ(s,a) = a^sΣ_n(−a)^n/(n!(s+n))）。则 ₁F₁(−λ;1−λ;−a) = −λ·a^λγ(−λ,a)，从而
  Σ_m t^m/P_m = −x^{−3}e^{a}·a^λγ(−λ,a) = x^{−3}e^{a}Σ_{n≥0}(−a)^n/(n!(λ−n))。
证明：(−λ)_n/(1−λ)_n = −λ/(n−λ)；再用定理 2.1、2.2 与 λ/(1−x) = x^{−3}。∎（用 Tricomi 的 γ*：a^λγ(−λ,a) = Γ(−λ)γ*(−λ,a)。解析意义见 §5.4。）

**命题 2.4（相邻关系）【已证明；已验证 k≤40, n≤20（c3a-1f1-shift）】** ₁F₁(1;−λ;a) = 1 + tΣ_m t^m/P_m（= 1 + tF 的常数项部分）。证明：[a^n]₁F₁(1;−λ;a) = 1/(−λ)_n = (1/(−λ))·1/(1−λ)_{n−1}（n≥1），a/(−λ) = t/(1−x)。∎

## 3. 形式 Laplace 表示

### 3.1 定义与基本性质

令 𝓜 := {Ψ = Σ_N Ψ_N s^N ∈ 𝓟[[s]] : ord(Ψ_N) → ∞}，定义 **ℒ_s(Ψ) := Σ_N N!·Ψ_N ∈ 𝓟**。ord(Ψ_N) → ∞ 等价于「每个单项式 x^k t^m 只在有限多个 Ψ_N 中出现」，所以和式逐系数是有限和（(x,t)-进收敛）。

**引理 3.1【已证明（proof-only）】** (a) 𝓜 是 𝓟-子模，对 ∂_s、∂_t 封闭，ℒ_s 是 𝓟-线性的；(b)（形式分部积分）ℒ_s[∂_sΨ] = ℒ_s[Ψ] − Ψ_0；(c) ℒ_s[∂_tΨ] = ∂_tℒ_s[Ψ]；(d) 若 σ 是 𝓟 的连续代数同态且 ord(σf) ≥ ord f（例如 x ↦ z(1−t) 或 t ↦ y/(1+y)），则 ℒ_s[σΨ] = σℒ_s[Ψ]（σ 作用在系数上）。
证明：(a) ord(fΨ_N) ≥ ord Ψ_N；(∂_sΨ)_N = (N+1)Ψ_{N+1}；ord ∂_tΨ_N ≥ ord Ψ_N − 1。线性由乘法的连续性。(b) Σ_N N!(N+1)Ψ_{N+1} = Σ_{N≥1}N!Ψ_N。(c) x^k t^m 系数两边都等于 (m+1)Σ_N N![x^k t^{m+1}]Ψ_N（有限和）。(d) σ 连续且 ord(σΨ_N) → ∞。∎

## 4. 整张表的 ₁F₁ 和式与 Kummer 形式

**定理 4.1【已证明；已验证 k≤40, m≤20（c3a-1f1-sum）】**
  F = Σ_{j≥0} c_j·(t^j/b_j)·₁F₁(1; j+1−λ; −t/x³)，c_0 = 1，c_j = j x²（j ≥ 1），

**定理 4.2（Kummer 形式）【已证明；已验证 k≤40, m≤20（c3a-kummer-F）】**

其中 φ(τ) := e^{−τ}g(−x³τ) = e^{−τ}(1 − x⁵τ/(1+x³τ)²) = Σ_n φ_nτ^n，φ_n = Σ_{i+j=n}(−1)^i/i!·c′_j，c′_0 = 1，c′_j = j x²(−x³)^j。
证明：对定理 4.1 每项用 Kummer：₁F₁(1;β;a) = e^a ₁F₁(β−1;β;−a)，β = j+1−λ，(β−1)_i/(β)_i = (j−λ)/(i+j−λ)；又 (j−λ)/b_j = −x^{−3}，t^j = (−x³)^ja^j。整理得 x^{−3}e^aΣ_{i,j}c_j(−x³)^j(−1)^i a^{i+j}/(i!(λ−i−j))，按 n = i+j 合并即是。每个 t 幂只涉及有限项。∎
（形式上即 F = −x^{−3}e^{a}a^{λ}·「∫_0^a τ^{−λ−1}φ(τ)dτ」按项积分 τ^{n−λ−1}。）

### 4.3 有限闭式：Humbert（合流 Appell）函数 Φ_1

Φ_1(α,β;γ;X,Y) := Σ_{m,n≥0} (α)_{m+n}(β)_m/((γ)_{m+n} m! n!)·X^mY^n（Humbert 的合流超几何函数，即 Appell F_1 的合流形式；这里只用上面这个级数定义和下面的 Euler 型积分，不依赖文献中的其他性质）。

**定理 4.3（右端 (1−t)^{−β} 的解）【已证明；已验证 A ∈ {1−x, 1−x+x³}，β ∈ {0,1,2,1/2,−3}，k≤24，t^N 的 N≤10（c3a-humbert-general）】**

## 5. 解析版本：收敛条件、两种「解析 F」、精确差值与渐近

固定实数 0 < x < 1（λ > 0）。凡涉及 S 时另设 λ ∉ Z_{≥0}（即 x 不是任何 b_i 的根）。

### 5.1 积分与收敛

  I(x,t) := x^{−3}∫_0^∞ exp((t(e^σ−1) − (1−x)σ)/x³)·g(te^σ) dσ = (1/(1−x))∫_0^∞ e^{−s}Ψ(s) ds（σ = us，Ψ 同推论 3.4）。

**命题 5.1（收敛）【已证明（proof-only）】** 对 x > 0：Re t < 0 时绝对收敛（|exp(t(e^σ−1)/x³)| = exp(Re t·(e^σ−1)/x³) 超指数衰减；Re w ≤ 0 时 |1−w| ≥ max(1,|w|)，故 |g(w)| ≤ 1 + x²）；t = 0 时收敛 ⇔ λ > 0（x<1）；Re t = 0、t ≠ 0 时 λ > 0 即绝对收敛；实数 t > 0 时发散（exp 超指数增长，且 0<t<1 时 g 在 σ = −ln t 有不可积的二阶极点）。
常数项部分（g ≡ 1）：u = e^σ 代换给出 **I_0(x,t) = x^{−3}e^{a}E_{λ+1}(a)**，E_p(a) := ∫_1^∞ e^{−au}u^{−p}du（a = −t/x³ > 0）——草稿这句话**作为关于积分的陈述是对的**。

### 5.2 I 满足 ODE，且是唯一在 −∞ 有界的解

**命题 5.2【已证明（proof-only）】** t ∈ (−∞,0) 上 I(x,·) ∈ C¹，(1−x−t)I − x³tI_t = g(t)，且 0 < I ≤ 1/(1−x)。在 (−∞,0) 上所有解为 I + C·h(t)，h(t) := (−t)^λ e^{−t/x³} → ∞（t→−∞），所以 **I 是唯一在 t→−∞ 有界的解**。
证明：J(σ,t) := exp(−λσ + (t/x³)(e^σ−1))g(te^σ)。直接求导得 t∂_tJ − ∂_σJ = (λ − t/x³)J，即 x³t∂_tJ = x³∂_σJ + (1−x−t)J。在 t∈[t_1,t_2]⊂(−∞,0) 上 |∂_tJ| 被 C(e^σ+1)e^{−λσ}exp(t_2(e^σ−1)/x³) 控制，可在积分号下求导：x³tI_t = x^{−3}∫_0^∞(x³∂_σJ + (1−x−t)J)dσ = [J]_0^∞ + (1−x−t)I = −g(t) + (1−x−t)I。实 w ≤ 0 时 g(w) ∈ [1−x²/4, 1]，故 0 < I ≤ x^{−3}∫e^{−λσ}dσ = 1/(1−x)。齐次方程 x³tE′ = (1−x−t)E 的解是 Ch(t)。∎

### 5.3 S := Σ_m t^m G_m(x)

**命题 5.3【已证明（proof-only）】** (a) G_m(x) 对 m 有界，S(x,t) 在 |t|<1 收敛（半径恰为 1：G_m → −1/x），满足同一 ODE；(b) S = x^{−3}e^{a}Σ_n φ_n(x)a^n/(λ−n)（右边在 |t|<1 收敛）；(c) S 是唯一在 t = 0 解析的解。
证明：(a) 取 m_0 := min{m > λ : x³(m+1−λ) ≥ 2}。m > λ 时 |b_m| = x³(m−λ)，由 G_m = G_{m−1}/b_m + mx²/b_m 得 m ≥ m_0+1 时 |G_m| ≤ c_1|G_{m−1}| + c_2，c_1 = 1/(x³(m_0+1−λ)) ≤ 1/2，c_2 = (m_0+1)/(x(m_0+1−λ))（m/(m−λ)、1/(m−λ) 关于 m 递减），归纳得 |G_m| ≤ B := max(max_{m_0≤m≤M}|G_m|, c_2/(1−c_1))（**尾项界引理**：|Σ_{m>M}t^mG_m| ≤ B|t|^{M+1}/(1−|t|)）。ODE 由 b_mG_m = G_{m−1} + mx² 逐项得到。
(b) φ(τ) 唯一的奇点是 τ = −1/x³（g(−x³τ) 的二阶极点），故 Σφ_na^n/(λ−n) 在 |a| < 1/x³ ⇔ |t| < 1 收敛；它与 S 在 t = 0 的 Taylor 系数相同：定理 4.2 的 t^m 系数属于 Q[x, x^{−1}, b_n^{−1}]，在我们的 x 处求值是环同态。(c) 其他解相差 Ch(t)，C ≠ 0 时在 t=0 不解析（λ ∉ Z）。∎

### 5.4 精确差值（核心）

**定理 5.4【已证明；数值证据见 5.7】** 对 0<x<1、λ ∉ Z_{≥0}、t ∈ (−1,0)：
  **I(x,t) − S(x,t) = x^{−3}K(x)·e^{a}a^{λ}**，K(x) := Σ_{n≥0}φ_n/(n−λ) + ∫_1^∞ τ^{−λ−1}φ(τ)dτ，
即 I = S + C(x)h(t)，C(x) = x^{−3−3λ}K(x)（e^aa^λ = x^{−3λ}h(t)）。K 是 Mellin 变换 ∫_0^∞τ^{−λ−1}φ(τ)dτ 关于 λ 的解析延拓（Prym 分解）。**常数项部分**（φ = e^{−τ}）K = Γ(−λ)，于是
  **Σ_m t^m/P_m(x) = x^{−3}e^{a}[E_{λ+1}(a) − Γ(−λ)a^{λ}] = −x^{−3}e^{a}a^{λ}γ(−λ,a)**，而 I_0 = x^{−3}e^{a}a^{λ}Γ(−λ,a)。
因 Γ 无零点，**I_0 ≠ Σ_m t^m/P_m 在每个这样的 (x,t) 都成立**。
证明：τ = ae^σ 代换：I = x^{−3}e^aa^λ∫_a^∞τ^{−λ−1}φ(τ)dτ（te^σ = tτ/a = −x³τ）。由命题 5.3(b)，S = −x^{−3}e^aa^λΣ_nφ_na^{n−λ}/(n−λ)。0<a<1/x³ 时在 [min(a,1),max(a,1)] ⊂ (0,1/x³) 上逐项积分：Σ_nφ_n(1−a^{n−λ})/(n−λ) = ∫_a^1τ^{−λ−1}φ dτ。相加即得 (I − S)/(x^{−3}e^aa^λ) = ∫_1^∞τ^{−λ−1}φ + Σφ_n/(n−λ) = K。常数项：Σ(−1)^n/(n!(n−λ)) + ∫_1^∞τ^{−λ−1}e^{−τ}dτ = Γ(−λ)（λ<0 时是 ∫_0^1+∫_1^∞ 的拆分，两边对 λ 解析，延拓到 −λ ∉ Z_{≤0}）；E_{λ+1}(a) = a^λΓ(−λ,a)，γ(−λ,a) := Γ(−λ) − Γ(−λ,a) = a^{−λ}Σ(−a)^n/(n!(n−λ))，与定理 2.3 的形式定义一致。∎

**定理 5.5（x→0+ 渐近，带显式误差界）【已证明；数值证据 c3a-num-asym】**
固定 t < 0，K ≥ 3，0 < x < 1：
  |I(x,t) − Σ_{k<K} f_k(t)x^k| ≤ (x^K/|t|)·sup_{τ≤t}|ρ_K(x,τ)|，ρ_K := f_{K−1} + τ(f′_{K−3} + x f′_{K−2} + x² f′_{K−1})，
其中 f_k = h_k/(1−t)^{k+1}（有理函数，见 §7）。所以 I(x,t) ~ Σ_k f_k(t)x^k：**积分 I 是形式级数 F 在 x 方向的一个解析「重求和」**。
证明：由定理 1.3 取 x^k 系数，(1−t)f_k = f_{k−1} + tf′_{k−3} + γ_k（γ_0 = 1，γ_2 = t/(1−t)²，其余 0）。令 Y_K := Σ_{k<K}f_kx^k，则 L[Y_K] − g = −x^Kρ_K（只剩 x 次数 ≥ K 的项：−xY_K 给出 −f_{K−1}x^K，−x³tY_K′ 给出 −t(f′_{K−3}x^K + f′_{K−2}x^{K+1} + f′_{K−1}x^{K+2})；K≥3 时 γ 不再贡献）。E := I − Y_K 满足 L[E] = x^Kρ_K，即 x³tE_t = (1−x−t)E − x^Kρ_K，亦即 (E/h)′ = −x^{K−3}ρ_K/(th)。取 E_p(t) := −h(t)∫_{−∞}^t x^{K−3}ρ_K(τ)/(τh(τ))dτ（τ→−∞ 时 1/h 超指数衰减，收敛）。对 τ < t < 0，h(t)/h(τ) = (|t|/|τ|)^λe^{(|t|−|τ|)/x³} ≤ e^{−(|τ|−|t|)/x³}，故 |E_p(t)| ≤ x^{K−3}sup|ρ_K|·(1/|t|)∫_{|t|}^∞e^{−(r−|t|)/x³}dr = x^K sup|ρ_K|/|t|。deg h_k ≤ k−1 ⇒ f_k、τf′_k 在 (−∞,t] 上有界，ρ_K 有界；I（命题 5.2）与 Y_K 也有界，故 E − E_p = Ch(t) 有界，只能 C = 0。∎

## 6. N 的二元母函数 𝒩(x,y) = Σ_{k,q} N(k,q)x^k y^q

**引理 6.1（二项式基）【已证明；DFS(k≤9) 与 DP 反演一致（c3a-N-def）】** 对 k≥0、m≥−1：U_k(m) = Σ_q N(k,q)C(m+1,q)，N(k,q) := 值域恰为 {1..q} 的合法词个数（N(0,0)=1）；q>k 时 N(k,q) = 0；反演 N(k,q) = Σ_{i=0}^q(−1)^{q−i}C(q,i)U_k(i−1)。
证明：h ∈ L_k(m) 的取值集合 V（|V| = q）与保序双射 ι: V → {1..q}；三元组条件只依赖 =、≥ 关系，ι 保持，故 h ↦ (V, ι∘h) 是到「q 元子集 × 满射合法词」的双射。m = −1 时 C(0,q) = [q=0]，与 U_k(−1) = [k=0] = N(k,0) 一致。∎

**定理 6.2（代换关系）【已证明；已验证 N 用 DFS（k≤9）、n≤41（c3a-N-subst）】**
  **1 + tF(x,t) = 𝒩(x, t/(1−t))/(1−t)**，等价地 𝒩(x,y) = 1/(1+y) + y·F(x, y/(1+y))/(1+y)²。
证明：[x^k](1+tF) = Σ_{m≥−1}U_k(m)t^{m+1} = Σ_q N(k,q)Σ_{n≥0}C(n,q)t^n = Σ_q N(k,q)t^q/(1−t)^{q+1}。y = t/(1−t) 与 t = y/(1+y) 互为逆的连续自同构。∎

**定理 6.3（𝒩 的 PDE ⇔ 三角递推）【已证明；已验证 k,q≤30（c3a-N-pde, c3a-N-rec）】**
  **(1 − x(1+y) + x³(1−y²))𝒩 − x³y(1+y)²∂_y𝒩 = 1 − x + x³ + x²y²。**
其 x^k y^q 系数恰为 N(k,q) = N(k−1,q) + N(k−1,q−1) + (q−1)[N(k−3,q) + 2N(k−3,q−1) + N(k−3,q−2)] + [k=q=0] − [k=1,q=0] + [k=3,q=0] + [k=q=2]；k≥3、q≥1 时就是 (C3) 的三角递推。**因此 (C3) 的三角递推由引理 1.1 推出**（引理 1.1 ⇒ 定理 1.3 ⇒ 下面的推导）。
证明（PDE 由 F 推出）：Ñ := 1+tF。把定理 1.3 乘 t，用 t²F_t = tÑ_t − (Ñ−1)（不需要除以 t）得 **(A−t)Ñ − x³tÑ_t = A + x²t²/(1−t)²，A = 1−x+x³**。再代 t = y/(1+y)：Ñ = (1+y)𝒩，t∂_t = y(1+y)∂_y，t²/(1−t)² = y²，整理 𝒩 的系数 (1+y)(1−x+x³) − y − x³y(1+y) = 1 − x − xy + x³(1−y²) 即得。
证明（PDE 由三角递推推出，即题目要求的方向）：n_k(y) := Σ_qN(k,q)y^q，θ := y∂_y。k≥3 时递推等价于 n_k = (1+y)n_{k−1} + [y²(θ+1) + 2yθ + (θ−1)]n_{k−3} + N(k−3,0)，因为 Σ_{q≥1}(q−1)N(·,q−2)y^q = y²(θ+1)n、2Σ_{q≥1}(q−1)N(·,q−1)y^q = 2yθn、Σ_{q≥1}(q−1)N(·,q)y^q = (θ−1)n + N(·,0)。算子 = (1+y)²θ + y² − 1。对 k≥3 求和并代入 n_0 = 1、n_1 = y、n_2 = y + 2y²、N(k−3,0) = [k=3]：𝒩 − 1 − xy − x²(y+2y²) = x(1+y)(𝒩 − 1 − xy) + x³[(1+y)²θ + y² − 1]𝒩 + x³，移项即上式。反过来取系数即递推。∎

**定理 6.4（𝒩 的显式表示）【已证明；已验证 k,q≤30（c3a-N-lap）】**
(i) 原生 Laplace（定理 3.3，A = 1−x+x³，v = x³/A，γ = A + x²t²/(1−t)²）：
  Ñ = 1 + tF = A^{−1}ℒ_s[exp((t/x³)(e^{vs}−1))·(A + x²t²e^{2vs}/(1−te^{vs})²)]，𝒩(x,y) = Ñ(x, y/(1+y))/(1+y)；
  由引理 3.1(d) 可把代换放进 ℒ_s 里：𝒩(x,y) = (1/(A(1+y)))·ℒ_s[exp(y(e^{vs}−1)/((1+y)x³))·(A + x²y²e^{2vs}/(1 − y(e^{vs}−1))²)]（出现了有序集合划分的 EGF 1/(1−y(e^z−1))；这一行只是第一行在 t = y/(1+y) 下的改写——1 − te^{vs} = (1 − y(e^{vs}−1))/(1+y)——没有单独编程核对）。
(ii) ₁F₁ 形式：Ñ = ₁F₁(1;−λ;a) + x²Σ_{j≥1} j t^{j+1}/b_j·₁F₁(1; j+1−λ; a)，a = −t/x³（命题 2.4 + 定理 4.1）。
(iii) 系数形式：[y^q]𝒩 = Σ_k N(k,q)x^k = Σ_{i=0}^q(−1)^{q−i}C(q,i)G_{i−1}(x)，G_{−1} := 1（因 [t^n]Ñ = G_{n−1}，𝒩 = Σ_nG_{n−1}y^n(1+y)^{−n−1}）。
(iv) **Humbert 闭式【已证明；已验证 k≤40, q≤14（c3a-N-humbert）】**：Ñ 的右端 A + x²t²/(1−t)² = (A+x²) − 2x²(1−t)^{−1} + x²(1−t)^{−2}，A = 1−x+x³，λ_A = λ+1，1−λ_A = −λ；由定理 4.3 再代 t = y/(1+y)（−t/(1−t) = −y，(1−t)^{−β} = (1+y)^β）：
  **𝒩(x,y) = [ (A+x²)·₁F₁(1;−λ;ŷ) − 2x²(1+y)·Φ_1(1,1;−λ;−y,ŷ) + x²(1+y)²·Φ_1(1,2;−λ;−y,ŷ) ] / (A(1+y))，ŷ := −y/((1+y)x³)。**
核对：(i) 的第一行直接按 EGF 精确展开，得到的 Ñ 与 1 + tF（DP）逐项相同，再做 [y^q] = Σ_n Ñ_n(−1)^{q−n}C(q,n) 与 N 表（DP 反演 k,q≤30、DFS k≤9）逐项相同；(iv) 按 Φ_1 与 Pochhammer 的定义展开（Laurent 级数），与 N 表逐项相同。

## 7. H(z,t) = Σ_k h_k(t)z^k

**命题 7.1【已证明；已验证 k≤30（c3a-H-poly）】** h_k(t) := (1−t)^{k+1}f_k(t)。由引理 6.1 与 Σ_{m≥0}C(m+1,q)t^m = t^{q−1}/(1−t)^{q+1}（q≥1），k≥1 时 **h_k = Σ_{q=1}^k N(k,q)t^{q−1}(1−t)^{k−q}**，是次数 ≤ k−1 的整系数多项式（h_k(1) = N(k,k)），h_0 = 1。核对中 t^k..t^{40} 的系数全为 0。

**定理 7.2【已证明；已验证 k≤30（c3a-H-poly, c3a-H-rec）】**
  **H(z,t) = (1−t)·F(z(1−t), t) = 1 + (𝒩(z(1−t), t/(1−t)) − 1)/t。**
证明：(1−t)F(z(1−t),t) = Σ_k f_k(t)(1−t)^{k+1}z^k = H（x ↦ z(1−t) 是连续代换）。第二式：H − 1 = Σ_{k,q≥1}N(k,q)z^kt^{q−1}(1−t)^{k−q} = t^{−1}Σ_{k,q≥1}N(k,q)(z(1−t))^k(t/(1−t))^q，每项含 t^q（q≥1），除以 t 合法。∎

**定理 7.3（H 的 PDE）【已证明；已验证 k≤30，t 方向精确（c3a-H-pde）】**
  **(1 − z − z³t(1−t))H − z⁴t(1−t)∂_zH − z³t(1−t)²∂_tH = 1 + z²t。**
证明：F̂(z,t) := F(z(1−t),t) = H/(1−t)。链式法则：∂_zF̂ = (1−t)F_x，∂_tF̂ = −zF_x + F_t ⇒ F_t(z(1−t),t) = ∂_tF̂ + (z/(1−t))∂_zF̂。代入定理 1.3（x = z(1−t)，1 − x − t = (1−t)(1−z)，x²t/(1−t)² = z²t），再用 ∂_tF̂ = H_t/(1−t) + H/(1−t)²、∂_zF̂ = H_z/(1−t)，乘开即得。∎
取 z^k 系数：h_k = h_{k−1} + t(1−t)[(1−t)h′_{k−3} + (k−2)h_{k−3}]（k≥3），h_0 = h_1 = 1，h_2 = 1+t，即 (C6)。c3a-H-rec 用这个递推从 h_0 出发生成 h_k，并与 DP 的 (1−t)^{k+1}Σ_m U_k(m)t^m 逐项比较（这才是 H = (1−t)F(z(1−t),t) 的非平凡核对）。
显式表示：H = ((1−t)/(1−x))ℒ_s[Φ·g(te^{us})]|_{x=z(1−t)}（引理 3.1(d)），或定理 4.1/4.2 中代入 λ = (1−z(1−t))/(z³(1−t)³)、a = −t/(z³(1−t)³)。

## 9. 草稿 / 提示词中发现的问题

1. **（实质错误）草稿 §3「解析版本（t<0）：F = x^{−3}∫_0^∞ …dσ」**：若 F 指 S(x,t) = Σ_m t^mG_m(x)（任务说明里建议的比较对象），等式不成立。严格反例 (3/5,−1/2)：I > 0，S ≤ −1057.81。精确关系 I − S = x^{−3}K(x)e^aa^λ（定理 5.4）。正确的说法有两个：形式恒等式（推论 3.4）和「I 渐近于 F」（定理 5.5）。
2. **草稿「常数项部分 = x^{−3}e^aE_{λ+1}(a)」**：作为积分的常数项部分正确；但 Σ_m t^m/P_m = x^{−3}e^a[E_{λ+1}(a) − Γ(−λ)a^λ]，两者之差 x^{−3}Γ(−λ)e^aa^λ 永不为零（例：(3/10,−1/10) 处 3.5775×10^{−8}，(3/5,−1/2) 处 885.95）。
3. **任务说明「解析版本（t<0、x>0 小）」暗示 x 小时两者相等**：只在 |t| < W(1/e)(1−x) ≈ 0.2785(1−x) 且远离极点 x_i 时差值超越所有阶；|t| 稍大差值指数爆炸（(21/100,−1/2)：S ≈ −9.7×10^{44}，I ≈ 0.765）。另外 S(·,t) 在 x_i → 0 处有极点聚集，x→0+ 时 S 根本没有通常意义的渐近展开。
4. **（表述不足，非错误）草稿用「(e^{us}−1)/x³ 是 u 的幂级数」论证良定义**：真正需要的是 [s^N]被积式的 (x,t) 阶 ≥ N（引理 3.2）。
5. 提示词 (C5) 说「齐次解 t^λe^{−t/x³}」：解析上对；形式环 Q[[x,t]] 中齐次方程无非零解（定理 1.4），解释「为什么在形式幂级数意义下表述」时应强调这一点。
6. 复核未发现错误的部分：定理 2.1 的等式本身、推论 3.4 的形式表示、草稿 H(z,t) = (1−t)F(z(1−t),t)、(C3) 三角递推、(C6) 递推，均已证明并核对。

## 10. 失败或未完成的方向

- **只用一元 ₁F₁ / 不完全 Gamma 的有限闭式**：没有找到，也没有证明不可能。原因：t 方向的 ODE 右端有 t=1 的二阶极点，F = h(t)∫h^{−1}g 的被积式 τ^{−λ−1}e^{τ/x³}·τ/(1−τ)² 不是不完全 Gamma 型。转而得到的是推论 4.4 的 Humbert Φ_1 闭式（两个二元合流超几何函数 + 一个 ₁F₁）；Φ_1(1,β;γ;X,Y) = Σ_m (β)_m X^m ₁F₁(1+m;γ+m;Y)/(γ)_m 一般不再化成有限个 ₁F₁，我没有进一步尝试（例如化成 Whittaker 函数的积分）。
- **K(x) ≠ 0 的一般证明**（带 g 的整体）：未完成。常数项 K = Γ(−λ) ≠ 0 已证明；整体只有数值（四个 x 处 K/Γ(−λ) ≈ 1.2–1.5）。命题 5.6 的反例不依赖它。
- **严格意义的 Borel 可和性**（f_k 的 Gevrey-1/3 上界、Borel 变换的解析延拓）：未证明；定理 5.5 只给出渐近与误差界，f_k 的增长阶是数值猜想。
- **整体差值门槛**：常数项部分由 Stirling 严格得到，整体（含 K/Γ(−λ)）的门槛只是数值观察。
- D-finite 判定不属于本子方向，未做。

## 11. 我最不确定的地方

1. 「草稿解析版本错误」的判定依赖于把 F 理解为 S = Σ t^mG_m(x)。若草稿本意是「I 是 F 的 Borel–Laplace 和」，那么它在渐近意义下是对的（定理 5.5 已证明），只是不能写成等号。
2. 数值部分不是区间算术：求积误差只是逐级加密的估计；只有命题 5.6 的符号反例和 |S(21/100,−1/2)| > 10^{44} 是严格的。
3. 定理 5.4 的 K(x) 级数与尾积分在 λ 大时有严重抵消（x = 21/100 时 K ~ 5×10^{−129}），需要约 170 位才能算准；核对模块对这一点单独提高了精度。
