### C-5　渐近、h_k 结构与 OEIS

**T5.1（固定 m、k→∞：精确谱分解、主项、次项、精确误差率）【已证明】**
(1) Binet 型精确公式（对一切 k≥0）：U_k(m) = Σ_{j=0}^{m} ((−1)^{m−j}/(m−j)!)·Σ_{σ: σ³=σ²+j} γ_j(σ)·σ^{k+3(m−j)}，γ_0(1)=1，
  γ_j(σ) = σ(σ^{3j+1}/j! − Σ_{i<j}σ^{3i}/i!)/(3σ−2) = [σ^{3j+3}/j! + Σ_{i<j}(j−i)σ^{3i+1}/i!]/(σ²+3j)。
内层对 σ 的和是有理数，可写成序列 c_j(n)=[x^n]1/b_j 若干项的有理线性组合（这里的 c_j 是序列，不是 (2) 中的常数 c_m），与 T2.5(3) 是同一组公式。证明（notes/c5a.md 定理 2.2）：G_m 是真分式且极点全为单极点；旧极点（σ 来自 j<m）处的部分分式系数 α_m(σ)（G_m=Σ_σ α_m(σ)/(1−σx) 中 1/(1−σx) 的系数，不是留数）满足 α_m(σ)=α_{m−1}(σ)·(−σ³)/(m−j)，新极点用 b_i(x_σ)=(m−i)x_σ³ 直接算出。
(2) 主项与次项：m≥1 时 **U_k(m) = c_m ρ_m^k − c_{m−1}ρ_{m−1}^{k+3} + O(τ_m^k)**（c5a 推论 2.3），c_m=γ_m(ρ_m)>0 是部分分式中 1/(1−ρ_m x) 的系数（不是留数；在 x_m=1/ρ_m 处的留数是 −c_m x_m），τ_m=max(ρ_{m−2}, √(ρ_m(ρ_m−1)))<ρ_{m−1}（m≥2；τ_1=√(ρ_1(ρ_1−1))≈0.826）。所以相对误差 U_k(m)/(c_mρ_m^k)−1 = −κ_mθ_m^k(1+o(1))，κ_m:=c_{m−1}ρ_{m−1}³/c_m>0，**精确衰减率是 θ_m=ρ_{m−1}/ρ_m**（不能改进，因为次大极点系数 −c_{m−1}ρ_{m−1}³≠0），且误差最终为负；1−θ_m=(1/(3m))(1+O(m^{−1/3}))，主项要在 k≫3m 时才占优。关键不等式：记 σ_m 为 y³=y²+m 的一个非实根（ρ_m 是唯一实根），则 |σ_m|²=m/ρ_m<ρ_{m−1}²（因 ρ_mρ_{m−1}²>ρ_{m−1}³=ρ_{m−1}²+m−1≥m），且 |σ_j| 关于 j 递增。
(3) c_m 的三种等价闭式：c_m=(G_{m−1}(x_m)+m x_m²)/(x_m(1+3m x_m²)) = ρ(ρ^{3m+1}/m! − Σ_{i<m}ρ^{3i}/i!)/(3ρ−2) = ρ^{3m+3}/(m!(ρ²+3m))·(1+Σ_{j=1}^{m} j·m!/(m−j)!·ρ^{−3j−2})（ρ=ρ_m；后一式由主 Agent 用 P_{j−1}(x_m)=m^{\underline j}x_m^{3j} 得到，与前两式在 Q(ρ) 中相等，见 c5a 定理 2.2 证明第 3–4 步）。数值：c_1≈2.2096081318、c_2≈7.8411192294、c_3≈28.976857317；c_m∈Q(ρ_m)，例如 c_1=(10+15ρ+17ρ²)/31。
(4) ρ_m 为整数 ⇔ m=ρ²(ρ−1)（m=0,4,18,48,…），此时 c_m 有理：**c_4=215/2**（U_k(4)=(215/2)·2^k − c_3ρ_3^{k+3}+O(ρ_2^k)），**c_18=37105325714711350249401/6830759936000**；两者都另用「DP 数据乘精确零化多项式」独立得到。
(5)【已验证（数值）：decimal 90 位计算，核对 c5a.c5a-prompt-k40；这一小条不属于 T5.1 的已证明部分】提示词「m=2、3 在 k=40 时相差 <0.4%」只在「相邻比 U_41/U_40 与 ρ_m 比较」的解释下成立（实测 0.035%、0.28%，与 (2) 推出的理论值 κ_m(1−θ_m)θ_m^{40} 吻合到 0.3%、3%）；按 U_40^{1/40} 或 U_40/(c_mρ^40) 比较，误差为 5.3%/8.7% 或 0.26%/3.0%。
核对：c5a.c5a-roots（实根唯一用 Sturm 精确核对；ρ_j 单调与复根模长不等式为 decimal 数值核对，j≤30，一般证明见 T1.3(4) 与上文 (2) 的关键不等式）、c5a.c5a-binet（Lagrange 形式 m≤20、k≤60 精确相等）、c5a.c5a-filter（单独抽出 b_m 的极点分量，1≤m≤20）、c5a.c5a-cm-form、c5a.c5a-cm-repr（Q(ρ_m) 中的表示为精确计算；与闭式的比较为 decimal 数值，m≤8）、c5a.c5a-c4、c5a.c5a-c18、c5a.c5a-asym-m1..m8（decimal 90 位，数值；k=400 处实测率与 θ_m 相差 <1e−6）、c5a.c5a-prompt-k40（数值）、c0.c0-c4（数值收敛核对；c_4=215/2 的精确核对是 c5a.c5a-c4）、c0.c0-cm（数值）、c1.C2-cm（数值）。
