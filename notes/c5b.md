## 1. 预备定理

### 1.1 归约 (a)(b) 的简短独立证明

后面所有「OEIS 数据与 U 的乘积对照」都依赖这两条，所以这里重证一遍。

**(a)** 竖直方向禁 001、011，恰好就是禁止 (b_i, b_{i+2}) = (0,1)（中间一位任意），也就是每列都有 b_i ≥ b_{i+2}。所以矩阵合法，当且仅当每行都是允许行，并且奇数号行满足 r_1 ≥ r_3 ≥ …、偶数号行满足 r_2 ≥ r_4 ≥ …（逐分量）。两组之间没有约束，因此
a_k(n) = U_k(⌈n/2⌉)·U_k(⌊n/2⌋)，其中 U_k(m) 是长度为 m 的允许行多重链 r_1 ≥ … ≥ r_m 的个数，U_k(0) = 1。

**(b)** 不增的列形如 1^h 0^(m−h)，所以矩阵 ↔ 高度向量 h ∈ {0..m}^k，第 t 行为 ([t≤h_1], …, [t≤h_k])。对相邻高度 (a,b,c)：
- 某一行为 001 ⟺ 存在 t∈[1,m] 使 max(a,b) < t ≤ c ⟺ c > max(a,b)；
- 某一行为 010 ⟺ b > max(a,c)。

两者都不出现 ⟺ c ≤ max(a,b) 且 b ≤ max(a,c) ⟺ b = c 或 a ≥ max(b,c)。
证明这一步：⇐ 直接验证。⇒ 若 b<c，由 c ≤ max(a,b) 得 c ≤ a；若 b>c，由 b ≤ max(a,c) 得 b ≤ a；两种情形都有 a ≥ max(b,c)。□

核对：OEIS b 文件与 `a_direct`、`a_brute` 的直接计数一致 [c5b.col-direct, c5b.table, c5b.rows]。

### 1.2 定理 T1（二项式基）与 N 的链数解释

**T1【已证明】** 对 k≥1、m≥0：

  U_k(m) = Σ_{q=1}^{k} N(k,q)·C(m+1, q)，

其中 N(k,q) 是值域恰为 {0,…,q−1} 的长 k 合法词个数。因此 U_k 是 m 的 k 次多项式，首项系数为 N(k,k)/k!，且 N(k,k) ≥ 1；它在 m = −1 处为 0。下文的 U_k(−j) 都指这个多项式的值。

证明：按取值集合 V ⊆ {0..m}（|V| = q，1 ≤ q ≤ k）给合法序列分类。设 φ_V: {0..q−1} → V 是保序双射。条件「b=c 或 a≥max(b,c)」只用到等号和 ≥，严格增映射既保持它也反映它，所以 w ↦ φ_V∘w 是「值域恰为 {0..q−1} 的合法词」到「值域恰为 V 的合法序列」的双射。对 V 求和即得。严格递降词 (k−1,…,1,0) 合法（每个三元组都有 a > b > c），所以 N(k,k) ≥ 1。□

由此可反演：N(k,q) = Σ_i (−1)^(q−i) C(q,i) U_k(i−1)（即 `core.N_from_U`）。
【已验证】N 用 DFS 枚举，对 1≤k≤8、0≤m≤15 与高度 DP 一致；高度 DP 与多重链定义在 k≤6、m≤4 一致。[c5b.binom-basis]

**T1′【已证明】** 设 P_k 是允许行（长 k、不含 001、010）在逐分量序下的偏序集，0̂ = 0…0 和 1̂ = 1…1 都是允许行。则 N(k,q) = b_q(P_k)，即 P_k 中从 0̂ 到 1̂ 恰好 q 步的链 0̂ = y_0 < y_1 < … < y_q = 1̂ 的个数。因此 U_k(m) = Z(P_k, m+1)（zeta 多项式）。

证明：取 m = q−1，值域恰为 {0..q−1} 的合法词 w 对应多重链 r_t = [w ≥ t]（t = 1..q−1）。因为每个值都出现：取值为 t−1 的位置在 r_{t−1} 中是 1、在 r_t 中是 0，所以 r_{t−1} > r_t；取值为 0 的位置使 r_1 < 1̂；取值为 q−1 的位置使 r_{q−1} > 0̂。于是 1̂ > r_1 > … > r_{q−1} > 0̂ 是一条 q 步链。反过来，任一这样的链给出 w_i = #{t : (r_t)_i = 1}；链是递降的，所以 {t : (r_t)_i = 1} 是一个初始段。w 合法当且仅当各行都是允许行，这就是 (b)。□
【已验证】k≤7 时按链直接数与 N_brute 一致。[c5b.zeta3]

### 1.3 引理 1 的多项式形式与负整数零点

**引理 1【已证明，独立重证】** 对 k ≥ 1，作为 m 的多项式恒等：

  U_k(m) = U_k(m−1) + U_{k−1}(m) + m·U_{k−3}(m)，约定 U_0 ≡ U_{−1} ≡ 1，U_{−2} ≡ 0。

证明：先对 m ≥ 1 计数，按第一个等于 m 的位置 i 给 h ∈ {0..m}^k 分类。
- (i) m 没有出现：U_k(m−1)。
- (ii) i = 1：三元组 (m,·,·) 恒合法，其余约束只涉及 h_2..h_k，共 U_{k−1}(m) 个。
- (iii) i = 2：h_1 < m，有 m 种取法。k = 2 时没有三元组，共 m = m·U_{−1}。k ≥ 3 时，(h_1, m, h_3) 合法当且仅当 h_3 = m（另一种情形要求 h_1 ≥ m，不可能）；随后 (m,m,·) 和 (m,·,·) 恒合法，h_4..h_k 是任意长 k−3 的合法序列，共 m·U_{k−3}(m)。k = 1 时此情形不存在，对应 U_{−2} = 0。
- (iv) i ≥ 3：(h_{i−2}, h_{i−1}, m) 中 b = h_{i−1} < m = c，且 a = h_{i−2} < m = max(b,c)，不合法。

两边都是 m 的多项式（T1），在无穷多个 m 上相等，所以是多项式恒等式。□
【已验证】k ≤ 30、m ≤ 30 与高度 DP 一致。[c5b.negzeros]

**T2【已证明】** 对 k ≥ 1 和 1 ≤ j ≤ ⌊(k+2)/3⌋，有 U_k(−j) = 0，即 (m+1)(m+2)⋯(m+⌊(k+2)/3⌋) 整除 U_k(m)。此外 U_{3j}(−j−1) = j!，所以 k ≡ 0 (mod 3) 时这个界是精确的。

证明：j = 1 由 T1 得到。设对某个 j 已知「U_i(−j) = 0 对一切 i ≥ 3j−2」。在引理 1 中令 m = −j：
  U_k(−j−1) = U_k(−j) − U_{k−1}(−j) + j·U_{k−3}(−j)。
当 k ≥ 3j+1 时，k、k−1、k−3 都 ≥ 3j−2，右边为 0，所以 U_k(−j−1) = 0 对 k ≥ 3(j+1)−2 成立。再取 k = 3j：此时 U_{3j}(−j) = U_{3j−1}(−j) = 0，所以 U_{3j}(−j−1) = j·U_{3(j−1)}(−(j−1)−1)；由 U_0(−1) = 1 归纳得 j!。□

### 2.3 经验递推与 Barker 猜想全部成立

**T3（列）【已证明】** 对 k≥1，(a_k(n))_{n≥0} 被 (E²−1)^(2k+1) 零化（E 为移位算子）。因此，若某个 e 阶递推 a(n) = Σ_{i=1}^{e} c_i a(n−i) 在 n = e+1, …, e+4k+2 上成立，它就对一切 n ≥ e+1 成立。

证明：由 (a)，a_k(2j) = U_k(j)²，a_k(2j+1) = U_k(j)U_k(j+1)。由 T1，二者都是 j 的 ≤2k 次多项式。E² 在每个奇偶子列上就是 j 的平移，Δ^(2k+1) 零化 ≤2k 次多项式。

对第二句，令 t(n) = a(n) − Σ c_i a(n−i)（n ≥ e+1）。设 (E²−1)^(2k+1) = Σ_j p_j E^j，p_{4k+2} = 1，则对 n ≥ e+1 有 Σ_j p_j t(n+j) = 0，因为它是 a 的若干平移经同一零化子作用后的组合。所以 t 满足 4k+2 阶首一递推；若它在 4k+2 个连续位置上为 0，就恒为 0。□

**应用【已证明】** Hardin 在 A207118–A207122 中给出的 Empirical 递推（阶 12、16、20、24、28，即 4k）：
- 特征多项式恰为 (x−1)^(2k+1)(x+1)^(2k−1)（精确多项式比较）；

## 3. R_k 与 A038718

A038718 的定义是：{1..n} 上满足 P(1) = 1 且 |P⁻¹(i+1) − P⁻¹(i)| ∈ {1,2} 的置换个数，offset 1，数据为 1, 1, 2, 4, 6, 9, 14, …。

  - (α) 1→2，此后是 {2..n} 上从 2 出发的路：a(n−1)；
  - (β) 1→3→2，此时 2 的邻点只剩 4，必须走到 4，此后是 {4..n} 上从 4 出发的路：a(n−3)；
  - (γ) 1→3 但下一步不是 2：2 只能以后从 4 进入，进入后 1、3、4 都已访问，路走不下去，所以 2 是终点；中间是 {3..n} 上从 3 到 4 的 Hamilton 路，恰有 1 条。

  所以 a(n) = a(n−1) + a(n−3) + 1（n ≥ 4），a(1) = a(2) = 1，a(3) = 2。
  (γ) 用到的子引理：P_N² 中从 1 到 2 的 Hamilton 路唯一（N ≥ 2）。理由：N ≥ 3 时第一步必去 3（2 是终点）；N ≥ 4 时 2 必须从 4 进入，于是路为 1, 3, [从 3 到 4 的路], 2，对 N 归纳即得唯一性。这条唯一的路是之字形 1, 3, 5, …, 6, 4, 2。

- **自然双射【已证明】**：两边的分解逐项对应，得到递归双射。

  - 1w ↔ 1·(路(w) 平移 +1)；
  - 011w ↔ 1, 3, 2·(路(w) 平移 +3)（k = 2 时 01 ↔ 1, 3, 2, 4）。

  所以「平移 2」有组合意义：长 k 的允许行 ↔ k+2 个顶点上的路。

*(1) 合法 4 元组的类型引理。* 每个合法 (h1,h2,h3,h4) 恰好属于下列一类；反之每类中的元组都合法：
- SSSS：h1 ≥ h2 ≥ h3 ≥ h4；
- ST：h1 ≥ h3 = h4 > h2；
- TS：h2 = h3 > h1，且 h4 ≤ h3；
- SSE：h1 ≥ h2 ≥ h4 > h3。

证明，按 h2 与 h3 的大小分情形：
- h2 = h3：第一个三元组恒合法；第二个合法当且仅当 h4 ≤ h3。于是 h1 ≥ h2 时是 SSSS，h1 < h2 时是 TS。
- h2 > h3：第一个三元组要求 h1 ≥ h2；第二个要求 h4 = h3 或 h4 ≤ h2，即 h4 ≤ h2。于是 h4 ≤ h3 时是 SSSS，h3 < h4 ≤ h2 时是 SSE。
- h2 < h3：第一个三元组要求 h1 ≥ h3；第二个只能 h4 = h3（另一种情形要求 h2 ≥ h3，不可能）。这是 ST。

反方向可直接验证。□

**判断（解释性，不是定理）**：U_4 = A326247(m+2) 是「同一多项式的不同计数模型」。可以构造保持取值集合的双射 Φ，但它是按块型分段拼出来的。两边的模型类型也不同：一边是 P_4 的多重链，另一边在自然坐标下不是任何行偏序集的多重链；也没有 k=3 那种同链数的偏序集对应。再加上 k ≥ 5 时 OEIS 中没有任何对应（§6），而低次（≤4）、小系数的多项式序列在 OEIS 中本来就很多，我倾向于把它看作低次多项式层面的巧合。

## 6. k ≥ 5

- 【已验证】U_5、U_6、U_7 各取 m=0..7、1..8、2..9 三个 8 项窗口（逗号相邻搜索，所以「从 m=2 起」的窗口也覆盖任何包含这 8 个连续值的条目），共 9 次搜索，全部 No results。[c5b.k567-nohit]

- 「自然推广」在 k=4 就失效：
  - 单调 k 元组 2C(m+k,k) − (m+1)：m=1 时为 8，而 U_4(1) = 9；

  所以没有一个对 k 一致的已知模型。

## 8. 草稿 / 提示词 / OEIS 条目中的问题

1. **提示词**：「R_k … g.f. (1−x+x²)/((1−x)(1−x−x³))」若读作 Σ_k R_k x^k 是错的（x¹ 系数 1 ≠ R_1 = 2）。它是 A038718 按 OEIS 下标的 g.f.，等于 1 + x·ΣR_k x^k；Σ_{k≥0} R_k x^k = (1+x²−x³)/((1−x)(1−x−x³))。分母与「a(k+2)」都对。[c5b.R-gf]
2. **提示词沿用了 A326247 的名称**「2 边标号多重图」：条目实际数的是边的有序对（可相同），按无序多重集数 n=3 为 6 而非 9。U_4 = A326247(m+2) 这个数值恒等仍然成立。[c5b.A326247-def]
3. **草稿 §3 的 U_3 双射与「单调三元组」解释**：经独立证明正确，没有发现错误。[c5b.bij3]
4. **OEIS A077949（非草稿）**：注释「Number of compositions of n into parts 1 and two sorts of parts 2」与数据不符：按此注释 n=2 时是 3（1+1、2a、2b），数据 a(2) = 1。改成「two sorts of parts 3」则 n ≤ 14 全部相符。【已否定原注释，反例 n=2】只记录，不提交。[c5b.A077949-comment]
5. **OEIS A326247（非草稿）**：%t 里调用 `nesXQ` 而定义的是 `nestQ`（疑似笔误，未运行验证）；名称与实际计数对象不一致（见第 2 条）。
6. **OEIS A207069 / A207070（非草稿）**：名称中的竖直规则是「禁 001 与 101」，与 A207123 不同。A207123 的 %Y「Row 2 is A207069 / Row 3 is A207070」作为数列是对的（§2.2 已证），但这两个条目并不是按定义的「A207123 的行」；从 4 行起两个问题不同。
7. **OEIS A038718（非草稿）**：offset 1，但 g.f. 写成从 x⁰ 开始（OEIS 常见习惯），这正是第 1 条混淆的来源。

## 11. 我最不确定的三处

1. **「巧合 vs 结构」的界线**是解释性的。我用的判据是：(i) 同一多项式；(ii) 存在保持取值集合的双射；(iii) 两边是否都是行偏序集的多重链模型、链数是否相同；(iv) 能否延伸成对 k 的族。U_3 满足 (i)–(iii)，U_4 只满足 (i)(ii)。别人可能会把 Φ 也算作「结构」。
2. **OEIS 无结果的含义有限**：只说明 2026-10-04 的 OEIS 中没有条目在显示数据里按顺序相邻地含有这些项。变形版本（缩放、换偏移超过 2、交错、差分等）不在覆盖范围内。
3. **A326247 读作「有序对」**依据的是 %e 与 %t，与名称不符。若作者本意是无序多重图，那么数据与名称之间本身就有矛盾——但这不影响数值恒等 U_4(m) = A326247(m+2)。
