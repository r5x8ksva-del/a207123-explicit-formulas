═══ 1. 问题与定义（以此为准）═══
记 a_k(n) 为满足下列条件的 n×k 的 0/1 矩阵个数：
 · 行规则：每一行从左到右读，任意连续三个位置都不是 001，也不是 010；
 · 列规则：每一列从上到下读，任意连续三个位置都不是 001，也不是 011。
OEIS：k=3 是 A207118，k=4..7 是 A207119..A207122，二维表是 A207123。a_3(n)，n=1..6：6, 36, 102, 289, 612, 1296。

已证明并用程序核对的归约：
(a) 列规则 ⇔ 对每一列、每个 i 有 b_i ≥ b_{i+2}（被禁的三元组恰好是 b_i=0 且 b_{i+2}=1，中间任意）。所以奇数号行、偶数号行各自在逐分量序下构成非增链，互不干扰；而行规则只涉及单独一行。于是
    a_k(n) = U_k(⌈n/2⌉) · U_k(⌊n/2⌋)，
 其中 U_k(m) = 满足「每列从上到下单调不增 + 每行满足行规则」的 m×k 0/1 矩阵个数，U_k(0)=1。（这里的 m 是奇数号行或偶数号行的个数，不是矩阵总行数 n。）
(b) 单调不增的列形如 1…1 0…0（前 h 个是 1），所以这样的矩阵 ⇔ 高度向量 (h_1,…,h_k) ∈ {0,…,m}^k。行规则 ⇔ 对每个相邻三元组 (a,b,c) = (h_i,h_{i+1},h_{i+2})：b = c，或 a ≥ max(b,c)。
 [推导：第 r 行在这三列上的取值是 ([r≤a],[r≤b],[r≤c])；某一行等于 001 当且仅当 c > max(a,b)；某一行等于 010 当且仅当 b > max(a,c)；两者都不发生 ⇔ 上述条件（分情况即得）。]
(c) 等价地，U_k(m) 是「允许行」（长度 k、不含 001 和 010 的 0/1 串，共 R_k 个）按逐分量序构成的偏序集里长度为 m 的多重链个数（即该偏序集 zeta 多项式的取值）。

U_k(m) 的参考实现（请先跑通，并与第 2 节对照）：
    from collections import defaultdict
    def good(a,b,c): return b==c or (a>=b and a>=c)
    def U_list(m, K):                  # 返回 [U_0(m), …, U_K(m)]，要求 K>=2
        out=[1, m+1]
        cnt={(a,b):1 for a in range(m+1) for b in range(m+1)}
        out.append(sum(cnt.values()))
        for k in range(3, K+1):
            new=defaultdict(int)
            for (a,b),v in cnt.items():
                for c in range(m+1):
                    if good(a,b,c): new[(b,c)]+=v
            cnt=new; out.append(sum(cnt.values()))
        return out

═══ 3. 我已得到并核对的结构（请先独立证明再用）═══
引理 1（三项递推）。对 k≥1, m≥0：
    U_k(m) = U_k(m−1) + U_{k−1}(m) + m·U_{k−3}(m)，
 边界约定：U_0≡1，U_{−1}≡1，U_{−2}≡0，且 U_k(−1)=0（k≥1）。
 证明思路：按「最大可取值 m 第一次出现的位置 i」给高度序列分类。
  (i)   m 根本没出现：U_k(m−1)。
  (ii)  i=1：h_1=m；三元组 (m,·,·) 永远合法，其余 k−1 个是任意合法序列：U_{k−1}(m)。
  (iii) i=2：h_1<m（m 种取法），h_2=m；三元组 (h_1,m,h_3) 要合法只能 h_3=m；此后 (m,m,·)、(m,·,·) 自动合法，剩下 k−3 个是任意合法序列：m·U_{k−3}(m)（k=2 时用 U_{−1}=1，k=1 时用 U_{−2}=0）。
  (iv)  i≥3 不可能：三元组 (h_{i−2},h_{i−1},m) 的前两项都 <m，既不满足 a≥max(b,c)，也不满足 b=c。
 已核对：对高度序列 DP，k≤40、m≤12 全部成立；DP 本身与多重链定义对照到 k≤10、m≤12，与原题定义直接数 a_k(n) 对照到 k≤8、n≤13。

      x·P_m·G_m = 1 − P_m − x·Σ_{j=0}^{m−1} P_j，    P_m := Π_{i=0}^{m} (1 − x − i·x³)。
   所以 U_k(m) 对 k 是阶 ≤ 3m+1 的线性递推序列，分母的因子是 1−x 与三次式 1−x−i·x³（i=1..m）；R_k 的 g.f. 分母就是 (1−x)(1−x−x³)。增长率 ρ_m 应是 ρ³=ρ²+m 的最大实根（只做了数值趋近：m=1 吻合 6 位，m=2、3 在 k=40 时相差 <0.4% 且仍在收敛；未证）。
