# 表 B 的 B7（前半）：f_k(t) 的 Gevrey-1/3 增长（2026-10-07 证明）

目的：`猜想总表.md` 表 B 的 B7（F 在 x 方向 Borel 可和；f_k(t) 是 Gevrey-1/3 增长）原来卡在两块：一是 f_k 的 Gevrey-1/3 上界（只有 k=75、150 的数值），二是 Borel 变换沿正实轴的解析延拓。这里补上第一块，并给出 t∈(0,1) 时同阶的下界，说明阶 1/3 不能改进。第二块（Borel 可和、和等于积分 I）仍未做，见 §4。

## 1. 记号

f_k(t):=Σ_{m≥0}U_k(m)t^m（|t|<1），即 F(x,t)=Σ_k f_k(t)x^k 的系数。由 T1.7，f_k=h_k(t)/(1−t)^{k+1} 是只在 t=1 有极点的有理函数，且（引理 1 乘 t^m 求和）
  (1−t)f_k=f_{k−1}+t·f′_{k−3}　（k≥3），　f_0=1/(1−t)，f_1=1/(1−t)²，f_2=(1+t)/(1−t)³。

## 2. 上界

**定理 G1.** 设 0≤r<1，令 R=(1+r)/2，λ=max(2/(1−R), (2eR/(1−R))^{1/3})，M=(1+R)/(1−R)³。则对一切 k≥0 与 |t|≤r，
  |f_k(t)| ≤ M·λ^k·(2/(1−r))^{⌊k/3⌋}·⌊k/3⌋!。
特别地，在单位圆盘的任一紧子集上一致地有 |f_k(t)|≤C·A^k·Γ(1+k/3)，即 f_k 至多 Gevrey-1/3 增长（(k!)^{1/3} 与 Γ(1+k/3) 只差一个几何因子）。

证明（Nagumo 范数）。对圆盘 D_R={|t|<R} 上的解析函数 φ 与 p≥0，令 ‖φ‖_p:=sup_{|t|<R}|φ(t)|(R−|t|)^p。
- (N1) q≥p 时 ‖φ‖_q≤R^{q−p}‖φ‖_p≤‖φ‖_p（因 R−|t|≤R<1）。
- (N2)（Nagumo 引理）‖φ′‖_{p+1}≤e(p+1)‖φ‖_p。证：取 |t|<R，d=R−|t|。p=0 时由 Cauchy 估计 |φ′(t)|≤‖φ‖_0/ρ 对一切 ρ<d，故 |φ′(t)|d≤‖φ‖_0。p>0 时取 ρ=d/(p+1)，圆 |s−t|=ρ 上 R−|s|≥dp/(p+1)，|φ(s)|≤‖φ‖_p(dp/(p+1))^{−p}，所以 |φ′(t)|≤ρ^{−1}‖φ‖_p(dp/(p+1))^{−p}=(p+1)(1+1/p)^p‖φ‖_p d^{−p−1}≤e(p+1)‖φ‖_p d^{−p−1}。
令 p_k=⌊k/3⌋，B_k:=‖f_k‖_{p_k}（f_k 在 D_R 的闭包上解析，所以有限）。k≥3 时 p_{k−1}≤p_k，p_{k−3}=p_k−1。在 D_R 上 |1/(1−t)|≤1/(1−R)、|t|≤R，由递推、(N1)、(N2)：
  B_k ≤ (1−R)^{−1}[‖f_{k−1}‖_{p_k}+R‖f′_{k−3}‖_{p_k}] ≤ (1−R)^{−1}[B_{k−1}+eR·p_k·B_{k−3}]。
归纳证 B_k≤Mλ^k p_k!：k≤2 时 p_k=0，B_0=1/(1−R)，B_1=1/(1−R)²，B_2≤(1+R)/(1−R)³，都 ≤M≤Mλ^k（λ>1）。k≥3 时
  B_k ≤ Mλ^k p_k!·(1−R)^{−1}[λ^{−1}·p_{k−1}!/p_k! + eRλ^{−3}] ≤ Mλ^k p_k!·(1−R)^{−1}[(1−R)/2+(1−R)/2] = Mλ^k p_k!。
最后，|t|≤r 时 R−|t|≥R−r=(1−r)/2，|f_k(t)|≤B_k(R−r)^{−p_k}，即得结论。∎

## 3. 下界（t∈(0,1)）

**引理.** k≥0、m≥1 时 U_k(m)≥m^{⌊k/3⌋}。
证明：j=⌊k/3⌋。对任意 a_1,…,a_j∈{0,…,m−1}，序列 (a_1,m,m,a_2,m,m,…,a_j,m,m,m,…,m)（末尾补 k−3j 个 m）合法：每个三元组是 (a_i,m,m)（b=c）、(m,m,a_{i+1})、(m,a_{i+1},m) 或 (m,m,m)（首项 m 不小于其余两项）。这些序列两两不同，共 m^j 个（就是 T2.1 块分解中 j 个 T_{m,a} 块接 S_m 块）。∎

**定理 G2.** 0<t<1，L=ln(1/t)，j=⌊k/3⌋≥1 时，f_k(t)≥t·j!/(e·√j·L^j)。所以 t∈(0,1) 时 f_k(t) 恰为 Gevrey-1/3 阶：limsup_k (f_k(t)/Γ(1+k/3))^{1/k} 有限且为正（与 G1 合起来）。
证明：f_k(t)≥U_k(m)t^m≥m^j t^m（m≥1）。取 m=⌈j/L⌉，则 m^j≥(j/L)^j，t^m=e^{−Lm}≥e^{−j−L}=t·e^{−j}，所以 f_k(t)≥t(j/(eL))^j；再用 j!≤e·j^{j+1/2}e^{−j}，即 (j/e)^j≥j!/(e√j)。∎

t∈(−1,0) 时只证明了上界（G1）。下界（不发生大量相消）没有证明；数值上 |f_k(−1/2)|^{1/k} 在 k=75、150、300 为 1.6688、2.0355、2.4874，相邻比约 1.22（趋向 2^{1/3}≈1.26），与 Gevrey-1/3 同阶相容。

## 4. 对 B7 的意义与剩下的部分

- 原卡点一（f_k 的 Gevrey-1/3 上界）已解决，而且对 |t|<1 的紧子集一致成立，常数显式。所以 F(x,t) 作为 x 的形式级数是 Gevrey-1/3 的（对 t 一致），Borel 变换 Σ_k f_k(t)ζ^k/Γ(1+k/3) 在 ζ=0 附近收敛。
- 卡点二仍在：要说「F 在 x 方向 Borel 可和、和等于 T3.4 的积分 I」，还要证明 Borel 变换沿正实轴解析延拓且至多指数增长（或等价地，I 在 x 的一个张角 >π/3 的扇形（或 Nevanlinna 型区域 Re(x^{−3})>1/ρ）里解析，且余项一致满足 Gevrey-1/3 估计）。T3.4(4) 的余项估计只对实的 0<x<1。注意 I 的积分在 Re(x^{−3})>0 即 |arg x|<π/6 时收敛，这恰好是张角 π/3 的临界情形，所以可能要用三个旋转扇形 x、ωx、ω²x（ω=e^{2πi/3}）上的同一积分公式拼出 F 按 x 模 3 分开的三个分量，再对每个分量（关于 x³ 是 Gevrey-1）用 Nevanlinna–Sokal 定理。这一部分这轮没有做。
- 所以 B7 的完成度从「部分证明」变为「一半已证」：Gevrey 阶已定，Borel 可和性未定。
