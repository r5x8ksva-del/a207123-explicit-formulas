## 阶段性结论

1. 【已证明】(1/t!)·∇^t i^p |_{i=m} = h_{p−t}(m−t,…,m) = Broder r-Stirling 数 {p+m−t ⧵ m}_{m−t}（p<t 时为 0）。证明只用一个有理函数恒等式（定理 2）。核对：`rstirling_def`（分拆暴力枚举 n≤9）、`rstirling_rec_gf`、`nabla_rstirling`（0≤t≤m≤20, p≤40）。
2. 【已证明】提示词 (C4) 的 Θ_t(n) 恰是 Γ_m(n−3t; m−t) := [x^{n−3t}] ∏_{v=m−t}^{m} b_v^{−1}；把 c_i 展开后，它与草稿 §2 的内层和 Σ_s h_s(m−t..m)·C(n−2t−2s, t+s) **逐项相同**（第 p 项 ↔ 第 s=p−t 项）。但两条公式的**外层不逐项相同**：Θ 公式是「[x^{k+1}]1/P_m − Σ_{j≥1}[x^k]∏_{v=j}^m b_v^{−1}」（下称 F3 外层），H 公式是「[x^k]1/P_m + Σ_j j·[x^{k−2}]∏_{v=j}^m b_v^{−1}」（H 外层），二者靠望远镜恒等式 j x³Q_j = (1−x)Q_j − Q_{j+1}（或双射 φ）相等。反例：m=1, k=3 时 Θ 式两项是 (8, −2)，H 式两项是 (5, 1)。草稿「与上式逐项相同」需按此更正（§4）。
3. 【已证明，并已验证 k≤30,m≤12 与 k≤60,m≤20；另在 k≤200,m≤30 内全部对照 DP（`bench_k200_m30`）】六种等价形式（Θ 型、H 型、F3 型、H 外层 + c_i 内层、**新的 c_i 偏分式型 F4**、Γ 单和型）全部对照 DP 通过（`form_*`, `gamma_triangle`）。新公式 F4：
   U_k(m) = (1/m!)·Σ_{i=0}^{m} (−1)^{m−i} C(m,i)·[ c_i(k+3m) + Σ_{j=1}^{i} j·i^{(j)}·c_i(k+3m−3j−2) ]，i^{(j)} 为下降阶乘。
4. 【已证明】否定命题（定理 S）：对每个 m ≥ 1，不存在整数 c, d 与与 k 无关的（复）系数 A(s)，使 U_k(m) = Σ_s A(s)·C(k+c−2s, m+s+d) 对所有充分大的 k 成立——也就是说「Stirling × 二项式」型单和不论系数取什么都不存在。证明：母函数 + 在 b_1 = 1−x−x³ 的三个根处比较留数 + 范数 N(1+ξ) = 3 不是有理数的立方。同法排除形状 C(k+c−αs, βs+d)（α≥1 且 α+β 为偶数；以及 (α,β)=(3,0)）（命题 S′）。
5. 【已验证（有限范围）】两族也不行：对每个 m ≥ 2，表示 G_m = x^{g1}A_1(u) + x^{g2}A_2(u) + Laurent 多项式（u = x³/(1−x)）在 |g_i+3m+3| ≤ 150 内不存在（`two_family_residue`；探索中扩到 400 仍无解）。【猜想】对所有 g 都不存在。三族总是存在（[Q(x):Q(u)] = 3），但系数多项式没有好结构（失败方向 §10）。
6. 【已证明】结构性理由：F3 外层就是 G_m = (1/P_m − 1)/x − (Σ_{j<m} P_j)/P_m，其中 1/P_m 关于 m 是超几何项，而部分和 Σ_{j<m} P_j 不是 Gosper 可和的（定理 G）。另：F(x,t) = Σ G_m t^m 不是 D-finite（§6.6 短证明），由文献定理推出 U_k(m) 不能写成真超几何项的（多重）有限和。
7. 结论：**最短的显式公式是 H 型双和（全正项、无除法），F3 型同样短（一个减号、无权重 j）**；单族「Stirling × 二项式」单和已被严格排除，所以在这一形状内双和已是最短。计算上：整表用引理 1 递推（k≤200, m≤30 时 0.003 s，各显式公式约 0.7–1.5 s）；单值且 m 大时 Θ/F4 因交错抵消极慢（k=m=300：Θ 138 s，H 0.25 s；k=m=100 时 Θ 的单项有 289 位而结果只有 99 位）；k 小 m 大用 N 三角；k 大 m 小用引理 1 或固定 m 的线性递推。
8. N(k,q)：由二项式反演得 N(k,q) = Σ_{i=1}^{q} (−1)^{q−i} C(q,i)·U_H(k, i−1)（已证明，`N_inversion` 对照 DFS 定义 k≤8 与容斥 k≤40）；【未完成】没有找到比它更短的显式式。

## 0. 记号与约定

- 合法序列：h = (h_1..h_k) ∈ {0..m}^k，每个相邻三元组 (a,b,c) 满足 b = c 或 a ≥ max(b,c)；U_k(m) 为其个数，U_0(m) = 1。
- b_v := 1 − x − v·x³；P_m := ∏_{v=0}^{m} b_v（P_{−1} := 1）；Q_j := ∏_{v=j}^{m} b_v^{−1} = P_{j−1}/P_m（0 ≤ j ≤ m+1，Q_{m+1} = 1；依赖 m，需要时写 Q_j^{(m)}）。
- G_m := Σ_k U_k(m) x^k；W_m := 1 + x²·Σ_{j=1}^{m} j·P_{j−1}。
- u := x³/(1−x) ∈ x³Q[[x]]，于是 b_v = (1−x)(1−v·u)。代换 u ↦ x³/(1−x) 是 C((u)) → C((x)) 的连续域嵌入（u 的 x-赋值为 3）。
- h_s(j..m) := h_s(j, j+1, …, m)（完全齐次对称多项式；变量集为空时 h_0 = 1、h_s = 0 (s>0)）。由于变量 0 不起作用，h_s(0..m) = h_s(1..m) = S(m+s, m)。
- Γ_m(n; j) := [x^n] Q_j（n < 0 时为 0）。
- 二项式约定：C(a,b) := 0，除非 0 ≤ b ≤ a（与 `core.binom` 一致）。在此约定下，下文每个求和对固定参数都只有有限项非零。
- c_i(n) := [x^n] 1/b_i = Σ_{0≤l≤⌊n/3⌋} C(n−2l, l)·i^l（n < 0 时为 0；0^0 = 1）。注意：提示词写的 Σ_j C(n−2j, j)·i^j 必须配合上面的约定或限制 j ≤ n/3；若按广义二项式 C(−1,1) = −1 计算，n = 1 时就已经错了（见 §9）。
- 下降阶乘 i^{(j)} := i(i−1)⋯(i−j+1)，i^{(0)} := 1。∇f(i) := f(i) − f(i−1)。

## 1. 基础：唯一块分解与 G_m

**引理 1′（最大值首现位置）**【已证明】设 k ≥ 1，h ∈ {0..M}^k 合法且 M 在 h 中出现，i 为 M 第一次出现的位置。则 i ∈ {1, 2}；若 i = 2 且 k ≥ 3，则 h_3 = M。

证明：若 i ≥ 3，三元组 (h_{i−2}, h_{i−1}, M) 中 b = h_{i−1} < M = c，故 b ≠ c；a = h_{i−2} < M = max(b,c)，故 a ≥ max(b,c) 也不成立，非法。若 i = 2 且 k ≥ 3：三元组 (h_1, M, h_3) 中 a = h_1 < M = max(b,c)，只能 b = c，即 h_3 = M。∎

（这就是引理 1 证明里的情形 (iv) 与 (iii)；引理 1 本身由 C-1 负责，这里只用到引理 1′。）

**定理 1（唯一块分解）**【已证明；暴力核对 `block_factorization`（全部 (m+1)^k 个序列，m≤3, k≤7）】
定义三种「块」：单块 S_v := [v]（长 1，等级 v）；三块 T_{a,v} := [a, v, v]（长 3，0 ≤ a < v，等级 v，共 v 种）；截断块 E_{a,j} := [a, j]（长 2，0 ≤ a < j，等级 j，共 j 种）。则 {0..m}^k 中的合法序列恰好是如下串联：若干个 S/T 块，等级从左到右弱减、都在 0..m 内，末尾可以再接**一个** E 块（其等级不超过前面所有块的等级）；并且每个合法序列的这种分解唯一。

证明：(a) 这样的串联都合法。看任一三元组的首元素 y 所在的块。若 y 是某块中等于该块等级 ℓ 的那个元素（S_ℓ 的 ℓ，或 T_{a,ℓ} 的某个 ℓ），则其后两元素要么在同一块中（等于 ℓ），要么在后面的块中（不超过那些块的等级，从而 ≤ ℓ；E 块的元素 a < j ≤ ℓ），所以 a ≥ max(b,c) 成立。若 y 是 T_{a,v} 的首元素 a，则三元组就是块内的 (a, v, v)，满足 b = c。若 y 是 E_{a,j} 的首元素 a，它后面只剩一个元素，不构成三元组。
(b) 存在。对长度归纳（空序列是空串联）。设 h 合法、长 k ≥ 1，M := max h。由引理 1′：若 h_1 = M，则 h = S_M·h′；若 h_1 < M、h_2 = M 且 k ≥ 3，则 h_3 = M，h = T_{h_1,M}·h″；若 k = 2 且 h_1 < h_2 = M，则 h = E_{h_1,M}。h′、h″ 的三元组都是 h 的三元组，所以它们合法；由归纳它们有分解，且分解中每块的等级不超过该块元素的最大值 ≤ M，所以拼上首块后等级仍弱减。
(c) 唯一。任一合法分解中，第一块的等级 ℓ 不小于后面各块的等级，而每个元素都不超过它所在块的等级，所以 ℓ ≥ 所有元素，且 ℓ 出现在第一块中，故 ℓ = max h。若 h_1 = ℓ，第一块只能是 S_ℓ（T、E 块首元素严格小于等级）；若 h_1 < ℓ，第一块是 T_{h_1,ℓ}，除非 h 恰好长 2（这时只能是 E_{h_1,ℓ}，因为 E 块必须在末尾）。第一块确定后对剩余部分归纳。∎

**推论 1.1（母函数）**【已证明；核对 `gf_blocks`（k≤60, m≤20）】
G_m = 1/P_m + x²·Σ_{j=1}^{m} j·Q_j = W_m/P_m。

证明：由定理 1，等级为 v 的块的生成函数是 x + v·x³；等级弱减的 S/T 块串 = 依次取等级 m, m−1, …, 0 的任意块串，生成函数 ∏_{v=0}^{m} 1/(1−x−vx³) = 1/P_m。以 E 块（等级 j，j 种）结尾的序列 = （等级 ≥ j 的 S/T 块串）·E，生成函数 Q_j·j·x²。由 Q_j = P_{j−1}/P_m 得第二个等号。∎

**推论 1.2（Γ 数的内层显式式 (a) 与三角递推）**【已证明；核对 `gamma_triangle`（k≤60, m≤20）】
Γ_m(n; j) = Σ_{s≥0} h_s(j..m)·C(n+m−j−2s, m−j+s)，并且 Γ_m(n; j) = Γ_{m−1}(n; j) + Γ_m(n−1; j) + m·Γ_m(n−3; j)（m ≥ j，起点 Γ_{j−1}(n; j) = [n = 0]）。

证明：Q_j = (1−x)^{−(m−j+1)}·∏_{v=j}^{m}(1−vu)^{−1} = Σ_s h_s(j..m)·u^s·(1−x)^{−(m−j+1)} = Σ_s h_s(j..m)·x^{3s}(1−x)^{−(m−j+1+s)}。又 [x^n] x^{3s}(1−x)^{−(r+1)} = C(n−3s+r, r)（n ≥ 3s，否则 0），取 r = m−j+s 即得 C(n+m−j−2s, m−j+s)；n < 3s 时这个二项式的上指标小于下指标（或上指标为负），按约定为 0，所以可以对全部 s ≥ 0 求和。递推来自 b_m·Q_j^{(m)} = Q_j^{(m−1)}（比较 x^n 系数）。∎

**推论 1.3（H 型，草稿 §2 的双和）**【已证明；核对 `form_H`】
 U_k(m) = Σ_s S(m+s, m)·C(k+m−2s, m+s) + Σ_{j=1}^{m} j·Σ_s h_s(j..m)·C(k−2+m−j−2s, m−j+s)。
其中第一项恰好是「不以上升结尾」的合法序列数，第二项的第 j 个被加项是「以 E_{·,j} 结尾」的个数（`bijection_phi` 中对 m≤3, k≤8 暴力数过）。草稿写的 C(k+m−2s, k−3s) 与这里的 C(k+m−2s, m+s) 在上述约定下处处相等（k ≥ 3s 时对称；k < 3s 时两者都是 0）。

## 2. r-Stirling 数与差分恒等式

**定义（Broder 1984）** 对 0 ≤ r ≤ n，{n ⧵ k}_r := 把集合 {1,…,n} 分成 k 个非空块、且 1, 2, …, r 两两位于不同块中的分拆个数。r = 0 或 1 时它就是第二类 Stirling 数 S(n,k)。

**引理 2.1**【已证明；核对 `rstirling_def`（{1..n} 的全部集合分拆暴力枚举，0≤r≤k≤n≤9）、`rstirling_rec_gf`（n≤30；母函数 21 项，r≤k≤10）】
对 r ≤ k ≤ n：{n ⧵ k}_r = h_{n−k}(r, r+1, …, k)；k < r 时 {n ⧵ k}_r = 0。因此
 Σ_{n} {n ⧵ k}_r z^n = z^k / ∏_{i=r}^{k} (1 − i z)，  {n ⧵ k}_r = k·{n−1 ⧵ k}_r + {n−1 ⧵ k−1}_r（n > r），  {r ⧵ k}_r = [k = r]。

证明（双射）：从 r 个单元素块 {1}, …, {r} 出发，按 r+1, r+2, …, n 的顺序逐个放入元素；放入某元素时若当前共有 c 块（r ≤ c ≤ k），它要么新开一块（c → c+1），要么加入现有 c 块之一（c 种选择）。把块按最小元编号，每个满足条件的分拆恰对应一条放置记录。共新开 k−r 次、加入 n−k 次，加入时的块数随时间弱增、取值于 {r..k}。固定「块数为 i 时加入了 e_i 次」（Σ e_i = n−k），开 / 加的先后顺序被唯一确定，放法数为 ∏ i^{e_i}；对全部 (e_r, …, e_k) 求和正是 h_{n−k}(r..k)。k < r 时 r 个元素不可能两两异块。母函数由 Σ_d h_d(r..k) z^d = ∏_{i=r}^{k} (1−iz)^{−1} 直接得到；递推按元素 n 是否单独成块分类。∎

别名：{n+r ⧵ k+r}_r = W_{1,r}(n,k)（Mező 的 r-Whitney 数，参数 1）= S(n,k; r)（Koutras 的非中心 Stirling 数）。

**引理 2.2（Broder 跨层恒等式）**【已证明；核对 `rstirling_cross`（0≤j≤m≤20, s≤20）】
 h_s(j..m) = Σ_{t=0}^{s} C(m−j+s, m−j+t)·S(m−j+t, m−j)·j^{s−t}。
证明：记 M = m−j。由 1 − (j+i)z = (1−jz)(1 − i·w)，w := z/(1−jz)，得 ∏_{i=0}^{M}(1−(j+i)z)^{−1} = (1−jz)^{−(M+1)}·Σ_t S(M+t, M) w^t = Σ_t S(M+t, M)·z^t·(1−jz)^{−(M+1+t)}；取 z^s 系数即得。∎
（它把 H 型里的 r-Stirling「原子」换成普通 Stirling 数，代价是多一层正项求和。）

**定理 2（差分 = r-Stirling）**【已证明；核对 `nabla_rstirling`：0≤t≤m≤20, 0≤p≤40，同时与 core.h_complete 和递推表比对】
对整数 0 ≤ t ≤ m、p ≥ 0（约定 0^0 = 1）：
 (1/t!)·∇^t i^p |_{i=m} = (1/t!)·Σ_{r=0}^{t} (−1)^r C(t,r)·(m−r)^p = h_{p−t}(m−t, …, m) = {p+m−t ⧵ m}_{m−t}，
p < t 时三者都等于 0。

证明：先证形式幂级数 Q[[z]] 中的恒等式（m 可以是任意整数）
 (★) A_t(m) := Σ_{r=0}^{t} (−1)^r C(t,r) / (1 − (m−r)z) = t!·z^t / ∏_{r=0}^{t} (1 − (m−r)z)。
对 t 归纳。t = 0 显然。由 Pascal 公式 C(t+1, r) = C(t, r) + C(t, r−1) 得 A_{t+1}(m) = A_t(m) − A_t(m−1)；由归纳假设
 A_t(m) − A_t(m−1) = t!·z^t·[(1−(m−t−1)z) − (1−mz)] / ∏_{r=0}^{t+1}(1−(m−r)z) = (t+1)!·z^{t+1} / ∏_{r=0}^{t+1}(1−(m−r)z)。
取 (★) 两边 z^p 的系数：左边 = Σ_r (−1)^r C(t,r)(m−r)^p = ∇^t i^p|_{i=m}（其中 1/(1−0·z) = 1 对应 0^p = [p=0]）；右边 = t!·[z^{p−t}] ∏_{v=m−t}^{m}(1−vz)^{−1} = t!·h_{p−t}(m−t..m)（p < t 时为 0）。最后一个等号是引理 2.1，取 r = m−t、k = m、n = p+m−t（满足 r ≤ k ≤ n）。∎

## 3. Θ_t 的内层恒等式

**定理 3**【已证明；核对 `theta_rational_identity`（0≤t≤m≤20，作为多项式恒等式精确核对）、`theta_inner`（m≤12, t≤m, 0≤n<3t+45，与级数除法得到的 [x^{n−3t}]∏b_v^{−1} 对照）】
对 0 ≤ t ≤ m：
 (i) Σ_{r=0}^{t} (−1)^r C(t,r) / b_{m−r} = t!·x^{3t} / ∏_{v=m−t}^{m} b_v（Q(x) 中的恒等式；等价于多项式恒等式 Σ_r (−1)^r C(t,r)·∏_{v∈[m−t,m], v≠m−r} b_v = t!·x^{3t}）；
 (ii) 对所有整数 n：Θ_t(n) := (1/t!)·Σ_{r=0}^{t} (−1)^r C(t,r)·c_{m−r}(n) = [x^{n−3t}] Q_{m−t} = Γ_m(n−3t; m−t)；
 (iii) 把 c_i 展开：Θ_t(n) = Σ_{p=0}^{⌊n/3⌋} C(n−2p, p)·h_{p−t}(m−t..m) = Σ_{s≥0} h_s(m−t..m)·C(n−2t−2s, t+s)，它与推论 1.2 给出的 Γ_m(n−3t; m−t) = Σ_s h_s(m−t..m)·C(n−2t−2s, t+s) **逐项相同**（第 p 项 ↔ 第 s = p−t 项；p < t 的项为 0）。

证明：(i) 与 (★) 同样对 t 归纳：A_{t+1} = A_t(m) − A_t(m−1)，差中出现 b_{m−t−1} − b_m = (t+1)·x³。（也可直接在 (★) 中代入 z = u 并乘以 (1−x)^{−1}：1/b_v = (1−x)^{−1}/(1−vu)，且 (1−x)^{−1}·u^t/∏(1−vu) = x^{3t}/∏ b_v。）(ii) 取 (i) 两边 x^n 的系数，左边是 t!·Θ_t(n)，右边是 t!·[x^{n−3t}]Q_{m−t}；n < 3t 时两边都是 0。(iii) 第一个等号：交换两个有限和，再用定理 2；第二个等号：令 p = s+t。∎

推论：t = m 给出提示词 (C4) 第二式 [x^n] 1/P_m = (1/m!)·Σ_{i=0}^{m} (−1)^{m−i} C(m,i)·c_i(n+3m)；推论 1.2 取 j = 0 给出 (C4) 第一式 [x^n] 1/P_m = Σ_s S(s+m, m)·C(n+m−2s, m+s)。两式都是【已证明】。
附带的事实：由 (i)，Σ_{i=0}^{m} (−1)^{m−i} C(m,i)·c_i(N) = 0 对 0 ≤ N < 3m 成立——c_i 交错和里的大量抵消正来源于此（见 §7 的计时）。

## 4. 外层：H 型与 F3 / Θ 型，以及「逐项相同」的更正

**定理 4**【已证明；核对 `theta_vs_H_outer`、`bijection_phi`、`form_F3`、`form_Theta`】 对所有 k ≥ 0, m ≥ 0：
 (H 外层) U_k(m) = Γ_m(k; 0) + Σ_{j=1}^{m} j·Γ_m(k−2; j)；
 (F3 外层) U_k(m) = Γ_m(k+1; 0) − Σ_{j=1}^{m} Γ_m(k; j)。

证明一（望远镜）。H 外层就是推论 1.1。b_j Q_j = Q_{j+1} 即 Q_j − x Q_j − j x³ Q_j = Q_{j+1}；取 x^{k+1} 的系数：Γ(k+1; j) − Γ(k; j) − j·Γ(k−2; j) = Γ(k+1; j+1)。对 j = 0..m 求和，左边望远镜，且 Γ(k+1; m+1) = [x^{k+1}] 1 = 0（k ≥ 0），得 Γ(k+1; 0) = Σ_{j=0}^{m} Γ(k; j) + Σ_{j=1}^{m} j·Γ(k−2; j)，即 F3 外层 = H 外层。多项式形式：x³·Σ_{j=1}^{m} j P_{j−1} = P_0 − P_m − x·Σ_{j=1}^{m} P_{j−1}（`theta_vs_H_outer` 对 m≤20 精确核对；它由 j x³ P_{j−1} = (1−x)P_{j−1} − P_j 求和得到），代入 W_m 得 W_m = (1−P_m)/x − Σ_{j=1}^{m} P_{j−1}，再除以 P_m 即 G_m = (1/P_m − 1)/x − Σ_{j=1}^{m} Q_j；乘以 x·P_m 就是提示词的 (C2)：x·P_m·G_m = 1 − P_m − x·Σ_{j=0}^{m−1} P_j。

证明二（组合，双射 φ）。对长 k 的合法序列 h：若 h 不以上升结尾（k ≤ 1 或 h_{k−1} ≥ h_k），令 φ(h) := h·0；否则 h 以 E_{a,j} 结尾（定理 1），令 φ(h) := h·j。追加 0 后末三元组 (h_{k−1}, h_k, 0) 合法 ⇔ h_{k−1} ≥ h_k；追加 j 后末三元组 (a, j, j) 合法；而且 φ(h) 的块分解就是 h 的块分解末尾补上 [0]（等级 0 不超过任何等级）或把 E_{a,j} 补成 T_{a,j}。删去末元素给出逆映射。所以 φ 是「长 k 合法序列」到「长 k+1、块分解末块为 T 块或 [0] 的合法序列」的双射（`bijection_phi`：m≤3, k≤8 暴力核对像集与个数）。按末块类型直接数：末块为 T_{·,j} 的有 j·Γ(k−2; j) 个（前缀是等级 ≥ j 的块串），末块为 [0] 的有 Γ(k; 0) 个（前缀任意）——得到 H 外层；用「全部长 k+1 的 S/T 块串 Γ(k+1; 0)」减去「末块为 [v]、v ≥ 1 的 Σ_{v≥1} Γ(k; v)」——得到 F3 外层。∎

**推论 4.1（提示词 (C4) 的 Θ 公式）**【已证明；`form_Theta` 包含 k = 0】
U_k(m) = Θ_m(k+1+3m) − Σ_{t=0}^{m−1} Θ_t(k+3t) 对所有 k ≥ 0 成立（提示词只写了 k ≥ 1；k = 0 时两边都是 1）。证明：F3 外层，再用定理 3(ii)：Θ_m(k+1+3m) = Γ_m(k+1; 0)，Θ_t(k+3t) = Γ_m(k; m−t)。∎

**对草稿「逐项相同」的更正**【已证明；反例由 `theta_vs_H_outer` 核对】
草稿 §2 写道：(C4) 的 Θ_t 公式「与上式逐项相同；(C4) 只是把 c_i(n) 的内层和又展开了一遍」。准确的关系是：
- **内层逐项相同**（定理 3(iii)）：Θ_t(n) 的 c_i 展开的第 p 项 = H 型内层和的第 s = p−t 项。
- **外层不同**：Θ 公式用的是 F3 外层（[x^{k+1}]1/P_m，以及权为 −1 的 Σ_j [x^k]Q_j），H 公式用的是 H 外层（[x^k]1/P_m，以及权为 j 的 Σ_j [x^{k−2}]Q_j）；二者相等靠望远镜恒等式（或双射 φ 的两种数法），不是逐项相等。
- 反例：m = 1, k = 3。Θ 公式两项为 Θ_1(7) = [x^4]1/P_1 = 8 与 −Θ_0(3) = −[x^3](1/b_1) = −2；H 公式两项为 Γ_1(3; 0) = 5 与 1·Γ_1(1; 1) = 1；两边之和都是 U_3(1) = 6。
所以「Θ 公式 = H 公式把内层重新展开」不成立；正确的说法是「Θ 公式 = F3 公式把内层的 r-Stirling × 二项式换成 c_i 交错和」，而 F3 与 H 由望远镜恒等式联系。

## 6. 能否消掉 j 求和

### 6.1 定理 S：不存在单族「Stirling × 二项式」单和

**定理 S**【已证明；所用代数事实由 `single_family_facts` 在 Q(ξ) 中精确核对（m = 1..20）；`single_family_linsys` 给出独立的数值佐证（594 个线性方程组全部无解，对照组可解）】
固定 m ≥ 1。不存在整数 c, d, k_0 与一列与 k 无关的复数 A(s)，使得
 U_k(m) = Σ_s A(s)·C(k+c−2s, m+s+d)  对所有 k ≥ k_0 成立
（二项式按 §0 约定，所以对每个 k 右边只有有限项非零）。

证明。记 e := m+d；只有 s ≥ −e 的项可能非零。
(1) 化成母函数。对 s ≥ −e，按约定有 Σ_{k∈Z} C(k+c−2s, s+e)·x^k = x^{3s+e−c}·(1−x)^{−(s+e+1)}（令 N := k+c−3s−e：N ≥ 0 时 C(N+s+e, s+e) = [x^N](1−x)^{−(s+e+1)}，N < 0 时二项式为 0）。这些项的 x-赋值 3s+e−c → ∞，所以 Φ := Σ_s A(s)·x^{3s+e−c}(1−x)^{−(s+e+1)} 在 C((x)) 中收敛，且对每个整数 k，[x^k]Φ 就是假设中的右边。因此 L := G_m − Φ 只有有限个非零系数（L 是 Laurent 多项式）。又 x^{3s+e−c}(1−x)^{−(s+e+1)} = x^{e−c}(1−x)^{−(e+1)}·u^s，且 (1−x)^{−1} = u·x^{−3}，所以 Φ = x^g·Ã(u)，其中 g := −2e−c−3，Ã(u) := u^{e+1}·Σ_s A(s)u^s ∈ C((u))。即
 G_m = x^g·Ã(u) + L。
(2) Ã 是 u 的有理函数。x 满足 T³ + uT − u = 0（因为 u(1−x) = x³）。在 C((x)) 中，1, x, x² 在 C((u)) 上线性无关：若 α + βx + γx² = 0（α, β, γ ∈ C((u)) 不全为 0），非零各项的 x-赋值分别 ≡ 0, 1, 2 (mod 3)，互不相同，最小者无法被抵消。另一方面 T³ + uT − u 在素元 u 处满足 Eisenstein 判别法，所以 [C(x) : C(u)] = 3，R := x^{−g}(G_m − L) ∈ C(x) 可写成 r_0 + r_1x + r_2x²（r_i ∈ C(u) ⊂ C((u))）。而 R = Ã(u) + 0·x + 0·x²，由坐标唯一性得 Ã = r_0 ∈ C(u)。
(3) 在 b_1 的三个根处比较留数。b_1 = 1−x−x³ 没有有理根（b_1(±1) ≠ 0），所以在 Q 上不可约，三个根 ξ_1, ξ_2, ξ_3 互异。在 ξ = ξ_i 处：1−ξ = ξ³，b_w(ξ) = (1−w)ξ³，所以 P_m 在 ξ 处是单零点，P_m′(ξ) = b_1′(ξ)·∏_{w≠1} b_w(ξ) = b_1′(ξ)·ξ^{3m}·(−1)^{m−1}(m−1)!；又 j ≥ 2 时 P_{j−1}(ξ) = 0，所以 W_m(ξ) = 1 + ξ²·ξ³ = ξ(1+ξ) ≠ 0。由推论 1.1，G_m 在每个 ξ_i 处有单极点，留数 ρ_i = W_m(ξ_i)/P_m′(ξ_i) ≠ 0。另一方面 u − 1 = −b_1(x)/(1−x)，所以 u(ξ_i) = 1、u′(ξ_i) = −b_1′(ξ_i)/(1−ξ_i) ≠ 0：u − 1 是 ξ_i 处的局部坐标。若 Ã 在 u = 1 处有 p 阶极点，则 x^g·Ã(u(x)) 在每个 ξ_i 处恰有 p 阶极点（p ≤ 0 时正则）；L 在 ξ_i ≠ 0 处正则。比较两边得 p = 1，并且记 κ := Res_{u=1} Ã，有 ρ_i = ξ_i^g·κ/u′(ξ_i)，即 ρ_i·u′(ξ_i)·ξ_i^{−g} = κ 对 i = 1, 2, 3 都相同。直接计算
 ρ_i·u′(ξ_i) = −W_m(ξ_i) / ((1−ξ_i)·∏_{w≠1} b_w(ξ_i)) = (−1)^m·(1+ξ_i)·ξ_i^{−3m−2}/(m−1)!，
所以 θ := (1+ξ_1)·ξ_1^{−M}（M := 3m+2+g）∈ Q(ξ_1) 的三个共轭 θ(ξ_i) 全相等。
(4) 矛盾。共轭全相等 ⇒ θ 在 Q(ξ_1)/Q 上的特征多项式是 (X−θ)³ ∈ Q[X] ⇒ θ ∈ Q，且 θ³ = N(θ) = N(1+ξ)·N(ξ)^{−M}。由 f(X) := X³ + X − 1 = ∏(X − ξ_i) 得 N(ξ) = −f(0) = 1，N(1+ξ) = −f(−1) = 3。于是 θ³ = 3，与 θ ∈ Q 矛盾。∎

说明：m = 0 时 U_k(0) = 1 = C(k, 0)，单族显然存在；1/P_m 本身就是单族（系数 S(m+s,m)，即 H 型第一项）。所以定理 S 说的是：**以上升结尾的那一族序列（H 型第二项）破坏了单族结构**，且无论系数 A(s) 取什么都补不回来。

### 6.2 命题 S′：其他二项式形状

**命题 S′**【已证明】 固定 m ≥ 1、整数 α, β ≥ 0、s_0。下列形状的单和 U_k(m) = Σ_{s≥s_0} A(s)·C(k+c−αs, βs+d)（A 与 k 无关，对 k ≥ k_0 成立）也不存在：
 (i) α ≥ 1 且 α+β 为偶数（例如 (1,1)：Fibonacci 型 C(k+c−s, s+d)；(2,0)；(1,3)；(2,2)；…）；
 (ii) (α, β) = (3, 0)。
另外 α+β = 1 的形状平凡地总能表示（例如 U_k(m) = Σ_s (Δ^s U_·(m))(0)·C(k, s)），所以「没有单和」必须指明形状才有意义。

证明：同 6.1 的 (1)(2)：Φ = x^{d−c}(1−x)^{−(d+1)}·A(v)，v := x^{α+β}/(1−x)^β（x-赋值 α+β ≥ 2），x 是 T^{α+β} − v(1−T)^β 的根（α ≥ 1 时该多项式首一且在素元 v 处满足 Eisenstein；(3,0) 时是 T³ − v），1, x, …, x^{α+β−1} 在 C((v)) 上线性无关（赋值模 α+β 互异），所以 A ∈ C(v)。设 ξ ∈ (0,1) 是 b_1 的实根（G_m 在此有单极点），v_0 := v(ξ) > 0；v′(x) = x^{α+β−1}(1−x)^{−β−1}·((α+β) − αx) 只在 x = 0 与 x = (α+β)/α ≥ 1 处为零，所以 v′(ξ) ≠ 0。前因子 x^{d−c}(1−x)^{−(d+1)} 在 ξ 处正则非零，所以 A 在 v_0 有极点；于是在纤维 {v = v_0} 中任一满足 v′(η) ≠ 0、η ∉ {0, 1} 的点 η 处，G_m − L 有极点，G_m 也必须有极点，即 P_m(η) = 0。
(i) 多项式 x^{α+β} − v_0(1−x)^β 在 x = 0 取 −v_0 < 0，x → −∞ 时 → +∞（α+β 偶且 α ≥ 1），所以有负实根 η，且 v′(η) ≠ 0；但 P_m 没有负实根（x < 0 时 b_w(x) = 1 − x − w x³ > 0）。矛盾。
(ii) v = x³，取 η = ωξ（ω = e^{2πi/3}），v′(η) = 3η² ≠ 0。若 b_w(ωξ) = 0，结合 ξ³ = 1−ξ 得 (1−w) + (w−ω)ξ = 0，即 ξ = (w−1)/(w−ω) ∈ Q(ω)（次数 ≤ 2），与 ξ 是三次无理数矛盾。∎

未覆盖的形状：α+β 为奇数且 (α,β) ∉ {(2,1), (3,0)}，例如 (1,2)、(2,3)。

### 6.3 两族：必要条件、有限范围验证与猜想

设 U_k(m) 是两族 (2,1)-形单和之和，即 G_m = x^{g_1}A_1(u) + x^{g_2}A_2(u) + L（A_i ∈ C((u))，g_1 < g_2，L 为 Laurent 多项式）。
- 【已证明】必要条件。① x^δ ∉ C(u)（δ ≠ 0）：若 x^δ = R(u)，则在 u 的纤维 {u = 1} = {ξ_1, ξ_2, ξ_3} 上 x^δ 取同一值，但 |ξ_1| ≈ 0.682 ≠ |ξ_2| = |ξ_1|^{−1/2}，矛盾。所以 x^{g_1}, x^{g_2} 在 C(u) 上线性无关，与 6.1(2) 同理（Cramer 法则）得 A_1, A_2 ∈ C(u)。② 对每个不可约的 b_v（1 ≤ v ≤ m）的根 ξ，G_m 有单极点（W_m(ξ) = W_v(ξ) ≠ 0 见下）。若 A_1, A_2 在 u = 1/v 有 p ≥ 2 阶极点，首项系数 d_1, d_2 必须使 ξ_i^{g_1}d_1 + ξ_i^{g_2}d_2 = 0 对三个根都成立，即 ξ_i^{g_2−g_1} 对三根相同，与 |ξ_1| ≠ |ξ_2| 矛盾（实根与复根模不同：|ξ_1| = |ξ_2| 会推出 vξ_1³ = 1，再由 b_v(ξ_1) = 0 得 ξ_1 = 0）。所以只能是单极点，留数条件为 ρ_ξ·u′(ξ) = κ_{v,1}ξ^{g_1} + κ_{v,2}ξ^{g_2} 对三根成立；因 Q(ξ) ⊗ C ≅ C³（Vandermonde 可逆），这等价于 θ_v := ρ_ξ u′(ξ)、ξ^{g_1}、ξ^{g_2} 在 Q(ξ) 中 Q-线性相关。③ 与 6.1(3) 同样的计算给出：对 m ≥ v，θ_v = −W_v(ξ)/(v²·ξ^{3m+3}·(−1)^{m−v} v!(m−v)!)，其中 W_v(x) := 1 + Σ_{j=1}^{v} j·v^{(j)}·x^{3j+2}（W_1 = 1+x⁵，W_2 = 1+2x⁵+4x⁸）与 m 无关。所以令 a := g_1+3m+3、b := g_2+3m+3，纤维 v = 1, 2 的条件化为与 m 无关的条件：W_v(ξ_v), ξ_v^a, ξ_v^b 线性相关（v = 1, 2）。
- 【已验证】（`two_family_residue`）纤维 1 的条件在 |a|, |b| ≤ 150 内恰有 14 组解，没有一组同时满足纤维 2 的条件；探索脚本 `e7b_twofamily_shifted.py` 扩到 |a|, |b| ≤ 400 仍只有这 14 组、无公共解（`logs/c2a_e7b_twofamily_shifted_A400.log`）。另 `e7_twofamily.py` 对 m = 2..6 直接用全部不可约纤维穷举 |g_i| ≤ 45，也无解；m = 1 时有 14 对 (g_1, g_2) 通过（F3 就是一个两族表示）。结论：对每个 m ≥ 2，指数满足 |g_i + 3m + 3| ≤ 150 的两族表示不存在。
- 【猜想】对每个 m ≥ 2，任意 (g_1, g_2) 的两族表示都不存在。缺的一步是证明纤维 1 的指数方程（三阶线性递推数列的行列式为零）只有这 14 组解，属于指数丢番图 / S-单位方程问题，本轮未完成。

### 6.4 三族总存在，但系数不好（失败方向）
因为 [Q(x):Q(u)] = 3 且 (1−x)^{−1} = 1 + u + x + x²（`e4_basis.py` 自检），总可写 G_m = (a_m(u) + b_m(u)x + c_m(u)x²)/D_m(u)，D_m = ∏_{i=1}^{m}(1−iu)，a_m, b_m, c_m ∈ Z[u]，从而得到「三族单和」U = Σ_s Σ_{e=0}^{2} κ_{m,e}(s)·C(k−e−2s−1, s−1)（加边界项）。但系数多项式没有可辨认的结构，例如 m = 4：a = 1+55u+64u²+102u³−6u⁴+u⁵，b = 5+50u+29u²+16u³+u⁴，c = 25+42u+87u²−7u³+u⁴（`logs/c2a_e4_basis.log`，m ≤ 6）。κ_{m,e}(s) 是这些多项式与 S(m+s, m) 的卷积，本质上仍是双和，而且有负号。所以这条路不比 H 型短。

### 6.5 定理 G：Σ_{j<m} P_j 关于 m 不是 Gosper 可和的

F3 外层的母函数形式是 G_m = (1/P_m − 1)/x − (Σ_{j=0}^{m−1} P_j)/P_m。其中 1/P_m 关于 m 是超几何项（相邻比 1/b_{m+1} 是 m 的有理函数）；唯一「不闭」的部分是部分和 Σ_{j<m} P_j。注意 P_m = (1−x)·(a)_m·z^m，a = 1 − (1−x)/x³，z = −x³，所以它是 2F0 级数的部分和。

**定理 G**【已证明】 取基域 K := Q(x)（x 为参数）。不存在关于 m 的超几何项 T(m)（T(m) ∈ K 非零，T(m+1)/T(m) ∈ K(m)）与常数 C ∈ K，使 Σ_{j=0}^{m−1} P_j = T(m) + C 对所有充分大的 m 成立。

证明：否则 P_m = T(m+1) − T(m) = T(m)(ρ(m) − 1)，ρ := T(m+1)/T(m) ∈ K(m)。P_m ≠ 0，所以 ρ ≢ 1，令 y := 1/(ρ − 1) ∈ K(m)，则 T(m) = y(m)P_m。代回并除以 P_m（P_{m+1}/P_m = b_{m+1}）得 y(m+1)·r(m) − y(m) = 1，r(m) := 1 − x − (m+1)x³ ∈ K[m]（m 的一次多项式，首项系数 −x³ ≠ 0）；该式对无穷多个 m 成立，故是 K(m) 中的恒等式。写 y = A/B，A, B ∈ K[m] 互素、B 首一，得 r(m)A(m+1)B(m) − A(m)B(m+1) = B(m)B(m+1)。若 β 是 B 的根（在 K 的代数闭包中），代入 m = β 得 −A(β)B(β+1) = 0，而 A(β) ≠ 0，所以 B(β+1) = 0；归纳得 β, β+1, β+2, … 都是 B 的根（特征 0，两两不同），矛盾。故 B = 1，y 是多项式；y ≠ 0（否则 0 = 1）。比较次数：r(m)y(m+1) − y(m) 的次数是 deg y + 1 ≥ 1（首项系数 −x³·lc(y) ≠ 0），而右边次数 0，矛盾。∎

这说明在母函数层面，j 求和对应的是一个没有超几何闭式的部分和；它是消不掉 j 的结构性原因（但它本身不推出定理 S，定理 S 是独立证明的系数层面结论）。

### 6.6 注记：F(x,t) 不是 D-finite，因而没有真超几何多重和表示

**命题 D**【已证明】 F(x,t) := Σ_m G_m(x)t^m 关于 x 不满足任何系数为 Q[x,t] 中多项式的非平凡线性微分方程；特别地 F 不是 D-finite。
证明：设 Σ_{i=0}^{I} p_i(x,t)·∂_x^i F = 0，p_i 不全为 0；除去 t 的公共幂次后可设某个 p_i(x,0) ≠ 0。写 p_i = Σ_{j=0}^{J} p_{ij}(x)t^j，取 t^m 系数（m ≥ J）：Σ_i Σ_{j=0}^{J} p_{ij}(x)·G_{m−j}^{(i)}(x) = 0，这是有理函数的恒等式。令 i* := max{i : p_{i0} ≠ 0}。记 x_m ∈ (0,1) 为 b_m 的实根（b_m 在 (0,1) 上严格减，b_m(0) = 1 > 0 > b_m(1)）；x_m 两两不同，所以可取 m ≥ J 充分大使 p_{i*0}(x_m) ≠ 0。在 x_m 处：b_v(x_m) = (m−v)x_m³ ≠ 0（v ≠ m），所以 P_m 在 x_m 是单零点、P_{m−j}（j ≥ 1）在 x_m 不为零；W_m(x_m) = 1 + Σ_{j=1}^{m} j·m^{(j)}·x_m^{3j+2} > 0。于是 G_m 在 x_m 有单极点，G_m^{(i)} 恰有 i+1 阶极点，而 G_{m−j}（j ≥ 1）在 x_m 解析。上式中 i = i*, j = 0 的项有 i*+1 阶极点，其余项的极点阶数都 ≤ i*，不可能相消，矛盾。∎
推论（依赖文献，本文不重证）：按 Lipshitz（1989）D-finite 与 holonomic 等价，Wilf–Zeilberger（1992）真超几何项是 holonomic 的、且 holonomic 序列对（每点有限支撑的）定和封闭，所以 U_k(m) 不能写成真超几何项 T(k,m,s_1,…,s_r) 的有限多重和。注意 S(m+s, m)、h_s(j..m)、c_i(n) 都不是真超几何项（它们的显式式里有 i^n 这类以求和变量为底的幂），所以这与 H 型、Θ 型的存在并不矛盾——它说明这些「Stirling 型」原子是必需的。

### 6.7 其他尝试与卡点
- r-Stirling 跨层恒等式：带权 j 的和本身可以望远镜塌缩，Σ_{j=1}^{m} j·h_{s−1}(j..m) = S(m+s, m)（由 j z·R_j = R_j − R_{j+1}，R_j := ∏_{v=j}^{m}(1−vz)^{−1}）。但 H 型里的二项式 C(k−2+m−j−2s, m−j+s) 也依赖 j（来自 (1−x)^{−(m−j+1)} 的幂次），塌缩被它挡住。用 Vandermonde C(A+B, n) = Σ_l C(A, l)C(B, n−l)（A = m−j）把 j 依赖移到 C(m−j, l) 上，再做 Abel 求和，只能把权 j 换成 Σ_j C(m−j, l−1)·(…)，j 和仍在。
- 以 b_m 为中心展开：b_v = b_m + (m−v)x³ 给出 Q_j = Σ_t (−1)^t S(m−j+t, m−j)·x^{3t}·b_m^{−(m−j+1+t)}，于是 j 和变成 Σ_M (m−M)·S(M+t, M)·y^M（y = 1/b_m）这种「多项式 × 几何」的部分和；它确实有闭式（用二阶 Euler 数），但会引入 (1−y)^{−(2t+1)} = (−b_m/(x(1+mx²)))^{2t+1}，即新的分母 (1+mx²) 与 x 的负幂，必须在总和中相消，没有带来化简。
- 直接用 u 消去 x：不可能，因为 x 在 Q(u) 上是三次的（6.1(2)），这也正是定理 S 的出发点。

### 7.3 推荐
- **最短的显式公式**：F2（H 型）
  U_k(m) = Σ_s S(m+s, m)·C(k+m−2s, m+s) + Σ_{j=1}^{m} j·Σ_s {m+s ⧵ m}_j·C(k−2+m−j−2s, m−j+s)，
  两层和、全正项、无除法、每项有组合意义（不以上升结尾 / 以 E_j 结尾）。允许一个减号时 F3 同样短且没有权重 j。由定理 S，在「Stirling × 二项式」这种单族形状里不可能更短。
- 若必须用 c_i（线性递推序列）作原子：F4 只做一次除法（除以 m!），比提示词的 Θ 型（m+1 次除以 t!）短；但两者都有严重的交错抵消。整表且 m ≪ k 时，c_i 型在 c 表预先算好后每个 (k,m) 只需 O(m²) 次查表，比 H 型的 O(mk) 个乘积还快一些（K=200, M=30：Θ 约 0.3–0.95 s 对 H 约 1.1–1.6 s，视是否计入原子表）；m 与 k 同量级或更大时则相反，而且差距是数量级的（单值 k=m=300：138 s 对 0.25 s）。
- **计算**：整表一律用引理 1 递推（比任何显式公式快约 300–1000 倍）；单值、k 极大且 m 小：引理 1 或固定 m 的线性递推（后者可配合矩阵幂做到 O(m³ log k) 次乘法，本轮未实现）；单值、k 小 m 极大：N 三角（O(k²) 预处理 + O(k) 求和）或 H 型；**不要**用 Θ / F4 计算 m 较大的值。

## 8. N(k,q) 的显式式

**命题 N**【已证明；核对 `N_inversion`：对照 DFS 定义 N_brute（k≤8）与 core 容斥 N_from_U（k≤40, q≤20）】 对 k ≥ 1：
 N(k,q) = Σ_{i=1}^{q} (−1)^{q−i} C(q,i)·U_k(i−1)
  = Σ_{i=1}^{q} (−1)^{q−i} C(q,i)·[ Σ_s S(i−1+s, i−1)·C(k+i−1−2s, i−1+s) + Σ_{j=1}^{i−1} j·Σ_s h_s(j..i−1)·C(k+i−3−j−2s, i−1−j+s) ]。
证明：三元组条件只依赖大小关系，严格增映射保持合法性，所以 U_k(i−1) = Σ_q C(i,q)·N(k,q)（先选值集）；二项式反演，再代入 F2。∎
这是三层和（外层交错），并不比「先算 U 再反演」更短。【未完成】更短的 N 公式。试过的两条路：(a) φ 对「值集恰为 {0..q−1}」的词保持值集（追加的 0 或 j 已在值集中），所以 N(k,q) = #{长 k+1、值集恰为 {0..q−1}、末块为 T 或 [0] 的块串}，但满射条件把 T/E 块的 a 值与等级耦合在一起，没有乘积结构；(b) 对 S(i−1+s, i−1) 关于 i 做二项式变换会引出 Stirling 对角线的高阶差分（关联 Stirling 数），仍是三层和。

## 9. 发现的草稿 / 提示词问题

1. 草稿 §2「(C4) 的 Θ_t 公式 … 与上式逐项相同；(C4) 只是把 c_i(n) 的内层和又展开了一遍」——不准确。内层逐项相同（定理 3(iii)），外层不同：Θ 公式对应 F3 外层，H 公式对应 H 外层，二者由望远镜恒等式相等。反例 m=1, k=3：Θ 式两项 (8, −2)，H 式两项 (5, 1)（`theta_vs_H_outer`）。
2. 提示词 (C4) 写 Θ 公式对 k ≥ 1 成立；实际对 k ≥ 0 都成立（k=0 时两边为 1），属于范围写窄了（`form_Theta` 含 k=0）。
3. 提示词 c_i(n) := Σ_j C(n−2j, j)·i^j 没写求和范围，必须约定 C(a,b) = 0（a < 0）或限制 0 ≤ j ≤ ⌊n/3⌋；按广义二项式（C(−1,1) = −1）则 n = 1 时多出 −i + 6i² − … 的非零项，公式错误。
4. 草稿 §0 说「1 ≤ j ≤ m 时 H(m,s,j) = Broder r-Stirling 数」并单列 j = 0；其实按 Broder 定义 r = 0 时也给出 S(n,k)，所以 H(m,s,j) = {m+s ⧵ m}_j 对全部 0 ≤ j ≤ m 成立（只是表述冗余，不是错误）。
5. 草稿说 (C4) 是「三重和、交错符号、除以 t!」——层数描述正确，但它并不是 H 型的重新展开（见第 1 条）；按原子计，Θ 型用 O(m²) 个 c 值，H 型用 O(mk) 个 r-Stirling 乘积，二者谁更「短」取决于原子的选取。

没有发现提示词 / 草稿中有数值错误的公式：(C4) 两式、Θ 公式、草稿的块分解、G_m = W_m/P_m、H 双和都被独立证明并对照 DP 通过。

## 10. 失败方向

1. 消掉 j 求和（r-Stirling 跨层恒等式 / Vandermonde 拆分 / Abel 求和）：带权 j 的和能塌缩，但二项式经 (1−x)^{−(m−j+1)} 依赖 j，塌缩被挡住；Abel 求和只能把权 j 换成另一个 j 和（§6.7）。
2. 以 b_m 为中心展开 + 二阶 Euler 数闭式：引入新分母 (1+mx²) 与 x 的负幂，必须在总和中相消，没有化简（§6.7）。
3. Q(u)-基 {1, x, x²} 的三族表示：存在，但系数多项式（m=4：1+55u+64u²+102u³−6u⁴+u⁵ 等）无结构、带负号，仍是卷积双和（§6.4）。
4. 两族表示对所有指数的不可能性：只在有限范围内验证（|a|,|b| ≤ 400），完整证明需要指数丢番图方程的有限性结果，本轮未完成（§6.3）。
5. 命题 S′ 未覆盖 α+β 为奇数的形状（如 (1,2)、(2,3)）：纤维中除 ξ 外的点可能是非实复数，无法用实根或次数论证直接排除。
6. 更短的 N(k,q) 显式式：只得到反演式（§8）。

## 11. 我最不确定的三处

1. 两族不可能性只是有限范围的验证加猜想；纤维 1 的解集在 |a|,|b| ≤ 400 内恰为 14 组是数据，不是定理。
2. §6.6 的推论（不存在真超几何多重和）依赖 Lipshitz 与 Wilf–Zeilberger 的文献定理及其支撑条件，我只陈述未重证；命题 D 本身的证明是完整的（且属于 C-3 的主题，这里只作为结构性理由引用）。
3. 计时数据受同时运行的其他子 Agent 干扰，只能看量级；「最短」也依赖于把 r-Stirling 数还是 c_i 当作原子（我的判断：H 型无除法、全正、每项可组合解释，故最短；若以 c_i 为原子，F4 最短）。
