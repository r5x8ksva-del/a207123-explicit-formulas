## 0. 记号与约定

- 合法序列：h = (h_1..h_k) ∈ {0..m}^k，每个相邻三元组 (a,b,c) 满足 `b == c 或 a >= max(b,c)`；个数 U_k(m)，U_0 ≡ 1。
- b_i(x) := 1 − x − i·x³；P_m := ∏_{i=0}^{m} b_i，P_{−1} := 1；G_m(x) := Σ_k U_k(m) x^k，G_{−1} := 1。
- H(m,s,j) := h_s(j, j+1, …, m)（完全齐次对称多项式）。H(m,s,0) = H(m,s,1) = S(m+s, m)；1 ≤ j ≤ m 时 H(m,s,j) = Broder r-Stirling 数 {m+s ⧵ m}_j（r = j）。
- 「三元组条件只依赖大小关系」：严格增映射保持 `b==c` 与 `a>=max(b,c)`。

## 1. 引理 1 的独立证明（主 Agent 已逐情形检查）

按最大值 m 第一次出现的位置 i 分类：
- (i) 不出现：U_k(m−1)（k ≥ 1 时 U_k(−1) = 0）。
- (ii) i = 1：三元组 (m,·,·) 恒合法，其余三元组只涉及 h_2..h_k：U_{k−1}(m)。
- (iii) i = 2：h_1 < m。k = 2 时直接 m 种（= m·U_{−1}）。k ≥ 3 时 (h_1, m, h_3) 要合法只能 h_3 = m；随后 (m,m,·)、(m,·,·) 恒合法，h_4..h_k 是任意长 k−3 的合法序列：m·U_{k−3}(m)（k = 3 用 U_0 = 1）。k = 1 时此情形不存在（U_{−2} = 0）。
- (iv) i ≥ 3：(h_{i−2}, h_{i−1}, m) 中 h_{i−1} < m = c 故 b ≠ c，h_{i−2} < m 故 a < max(b,c)：不合法。

## 2. 新发现：块分解（唯一因子分解）——C-2 的组合核心

令 B_v := {[v]} ∪ {[a, v, v] : 0 ≤ a < v}（长 1 的「单块」S 与长 3 的「三块」T，T 有 v 种），E_v := {[a, v] : 0 ≤ a < v}（长 2 的「截断块」，只能出现在末尾）。则（不交并、表示唯一）

  合法序列(值域 ⊆ {0..m}) = B_m* · ( 合法序列(值域 ⊆ {0..m−1}) ∪ E_m ),  合法序列(值域 ⊆ ∅) = {空序列}。

证明要点：由引理 1 的分类，含 m 的合法序列要么以 [m] 开头、要么以 [a,m,m] 开头（k ≥ 3）、要么恰为 [a,m]（k = 2）；拼接处的三元组 (m,·,·)、(a,m,m)、(m,m,·) 恒合法，所以任意拼接都合法。展开得：

  合法序列 = B_m* B_{m−1}* ⋯ B_0*  ∪  ⋃_{j=1}^{m} B_m* ⋯ B_j* E_j。

等价刻画：序列里的「上升」h_i < h_{i+1} 只出现在 T 块或 E 块的第 2 位；以上升结尾 ⇔ 有 E 块。

推论（已快速核对 k ≤ 40, m ≤ 12）：
- G_m = W_m / P_m，W_m := 1 + x² Σ_{j=1}^{m} j·P_{j−1}（与 (C2) 的分子 (1 − P_m − xΣ_{j<m}P_j)/x 相同，用 j x³ P_{j−1} = (1−x)P_{j−1} − P_j 望远镜求和即得）。
- G_m = 1/P_m + x² Σ_{j=1}^{m} j / ∏_{v=j}^{m} b_v。
- 用 u := x³/(1−x)，b_v = (1−x)(1 − v u)，得 [x^n] ∏_{v=j}^{m} b_v^{−1} = Σ_s H(m,s,j)·C(n + m − j − 2s, n − 3s)。
- **显式公式（双和、全正项）**：
  U_k(m) = Σ_{s≥0} S(m+s, m)·C(k+m−2s, k−3s) + Σ_{j=1}^{m} j·Σ_{s≥0} H(m,s,j)·C(k−2+m−j−2s, k−2−3s)。
  第一项（单和，「Stirling × 二项式」）恰好数「不以上升结尾」的合法序列；第二项数以截断块 E_j 结尾的。
- (C4) 的 Θ_t 公式里的 (1/t!)∇^t i^p |_{i=m} 就是 H(m, ·, m−t)：Θ_t(n+3t) = [x^n] P_{m−t−1}/P_m，与上式逐项相同；(C4) 只是把 c_i(n) 的内层和又展开了一遍（三重和、交错符号、除以 t!）。

## 3. 其余主线结论草稿（各子任务负责严格化）

- (C1) 望远镜求和；次数与首项系数：summand U_{k−1}(j) + j·U_{k−3}(j) 的次数 k−1、首项 = U_{k−1} 的首项（k ≥ 3）；k = 2 时 summand = 2j+1 给出因子 2；故首项 2/k!（k ≥ 2）。多项式 S(m) := Σ_{j≤m} f(j) 满足 S(−1) = S(0) − f(0) = 0。
- (C2) 归纳：令 H_m := xP_mG_m，则 H_m = H_{m−1} + m x³ P_{m−1} = H_{m−1} + (1−x)P_{m−1} − P_m。
- ρ_m（建议定理）：y³ − y² − i 只有一个实根 ρ_i > 1，且 ρ_i 关于 i 严格增；复根模长 √(i/ρ_i) < ρ_i。G_m = (G_{m−1} + m x²)/b_m，G_{m−1} 在 |x| < 1/ρ_{m−1} 解析且系数非负，故在 x_m := 1/ρ_m 处 G_{m−1}(x_m) + m x_m² > 0：x_m 是 G_m 唯一的最小模奇点、单极点、留数非零。于是 U_k(m) = c_m ρ_m^k (1 + O(θ^k))，
  c_m = (G_{m−1}(x_m) + m x_m²) / (x_m (1 + 3 m x_m²))。m = 4 时 ρ = 2（8 = 4 + 4），c_4 为有理数；m = 18 时 ρ = 3。
- (C3) N 三角递推：按最大值 q 首次出现位置分类；位置 1 给 N(k−1,q) + N(k−1,q−1)；位置 2（w_1 = a < q，w_2 = w_3 = q，尾巴 T 的值域）给 (q−1)[N(k−3,q−2) + 2N(k−3,q−1) + N(k−3,q)]。N(k,k) = N(k−1,k−1) = 2；N(k,k−1) − N(k−1,k−2) = 2 + 2(k−2)（k ≥ 5），N(4,3) = 8 ⇒ k² − k − 4（k ≥ 4）。
- D(k,d) := N(k,k−d) 满足 D(k,d) = D(k−1,d) + D(k−1,d−1) + (k−d−1)[D(k−3,d−1) + 2D(k−3,d−2) + D(k−3,d−3)]，故最终是 k 的 2d 次多项式，首项 2/(2^d d!)（是 S(k,k−d) 首项的 2 倍）；成立门槛的粗估 k ≥ 2d+2（待精确化）。
- (C7) 分子 Num_q := P_{q−1}·Σ_k N(k,q)x^k 满足（已快速核对 3 ≤ q ≤ 12）：
  Num_q = (x + 2(q−1)x³)·Num_{q−1} + (q−1)x³·b_{q−2}·Num_{q−2}，Num_1 = x，Num_2 = 2x² + x⁴。
  由此首项系数 L_q = (q−1)[2L_{q−1} − (q−2)L_{q−2}] = (q−1)!，最低项 2x^q，次数 3q−2。另有容斥式 Num_q = Σ_i (−1)^{q−i}C(q,i)·W_{i−1}·∏_{v=i}^{q−1} b_v（W_{−1} = 1）。
- (C5) PDE 由 (C2) 乘 t^m 求和得到。显式解（待严格核对）：
  Σ_m t^m / P_m = ₁F₁(1; 1−λ; −t/x³)/(1−x)，λ := (1−x)/x³（逐项就是 (1−λ)_m 的展开，属于 Q(x)[[t]]）；
  F(x,t) = (1/(1−x))·ℒ_s[ exp( (t/x³)(e^{us} − 1) )·( 1 + x² t e^{us}/(1 − t e^{us})² ) ]，u = x³/(1−x)，ℒ_s[s^n] := n!（形式 Laplace，逐项良定义：(e^{us}−1)/x³ = (e^{us}−1)/(u(1−x)) 是 u 的幂级数）。
  解析版本（t < 0）：F = x^{−3}∫_0^∞ exp((t(e^σ−1) − (1−x)σ)/x³)·g(te^σ) dσ，g(w) = 1 + x²w/(1−w)²；常数项部分 = x^{−3} e^{a} E_{λ+1}(a)，a = −t/x³（广义指数积分 / 不完全 Gamma）。
- **F 不是 D-finite（建议定理，待对抗复核）**：若 Σ_{i≤I} p_i(x,t) ∂_x^i F = 0（p_i ∈ Q[x,t]，不全被 t 整除），取 t^m 系数得 Σ_{i,j} p_{ij}(x) G_{m−j}^{(i)}(x) = 0。取 i* = max{i : p_{i0} ≠ 0}，m 充分大使 p_{i*0}(x_m) ≠ 0；G_m 在 x_m 有单极点（留数非零），G_m^{(i*)} 有 i*+1 阶极点，而 G_{m−j}（j ≥ 1）在 x_m 解析（b_v(x_m) = (m−v)x_m³ ≠ 0），矛盾。所以 F 关于 x 不满足任何多项式系数线性 ODE，因而不是 D-finite（尽管关于 t 满足一阶 ODE，且数组满足引理 1 这条「只依赖 m 的系数」的递推）。
- (C6) 由 PDE 取 x^k 系数：(1−t)f_k = f_{k−1} + t f'_{k−3}（k ≥ 3），f_k = h_k/(1−t)^{k+1}。h_k(1) = N(k,k) = 2。
- 固定 k、m → ∞：[m^{k−1}] U_k(m) = (k² − 2k − 1)/(k−1)!（k ≥ 4，由 N(k,k) = 2、N(k,k−1) = k²−k−4 与 C(m+1,q) 的展开得到；待核对）。
- U_3(m) = (m+1)(m²+5m+3)/3 = 2C(m+3,3) − (m+1) = {0..m}³ 中单调三元组个数，有显式双射：b>c 或 (b=c, a≥b) 的合法三元组本身就是非增三元组；(a<b=c) ↦ (a,a,b)；(b<c≤a) ↦ (b,c,a)。
