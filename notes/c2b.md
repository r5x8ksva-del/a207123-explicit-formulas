## 0. 记号

- 合法序列：h=(h_1..h_k)∈{0..m}^k，每个相邻三元组 (a,b,c)=(h_i,h_{i+1},h_{i+2}) 满足 good(a,b,c) :⟺ b=c 或 a≥max(b,c)。个数 U_k(m)，U_0(m)=1。
- 上升：下标 i 使 h_i<h_{i+1}；asc(h) = 上升个数。U_k(m,s) = 恰有 s 个上升的合法序列数。
- 完整序列：不以上升结尾（k≤1，或 h_{k−1}≥h_k）。A_m(k) = 完整序列个数；E(k,m) = U_k(m)−A_m(k) = 以上升结尾的个数；E(k,m,s) 同理按 s 分层。
- b_v(x,y) = 1−x−v y x³，P_m(x,y) = Π_{v=0}^m b_v，P_{−1}=1；y=1 时记 b_v, P_m。
- h_s(z_0..z_r) 为完全齐次对称多项式；H(m,s,j) := h_s(j, j+1, …, m)（0≤j≤m）；s<0 时为 0。
- A^{(j)}_m(n) := [x^n] Π_{v=j}^m b_v^{−1}（A^{(0)}_m = A_m，见推论 4.1）。
- C(n,r)：组合约定（n<0、r<0 或 r>n 时为 0，与 core.binom 一致）。S(n,k)：第二类 Stirling 数。

## 1. 定理 1：块分解（唯一分解 + 任意拼接合法 + 截断块只在末尾）

### 1.1 定义

- **块**（0≤a<v）：单块 S_v = (v)；三块 T_{v,a} = (a, v, v)；截断块 E_{v,a} = (a, v)。块的**层次** lev = v。T、E 的第一项 a 称为**谷**，其余位置称为**非谷位置**（取值都等于层次 v）。
- **块词**：块的有限序列 β=(β_1,…,β_r)（r≥0），满足 lev(β_1) ≥ lev(β_2) ≥ … ≥ lev(β_r)，β_1..β_{r−1} ∈ {S,T}，只有 β_r 可以是 E。「层次 ≤ m」指 lev(β_1) ≤ m。拼接 κ(β) = 各块依次连写。

### 1.2 引理 1.1（非谷位置支配其后全部值）

设 h=κ(β)，p 是非谷位置，则对所有 q>p 有 h_q ≤ h_p。

证明：p 落在某块 β_i（层次 v）中，且 h_p = v。q>p 时，要么 q 仍在 β_i 内（只可能是 T 的第 2、3 项，值为 v；E 的第 2 项之后没有项），要么 q 在后面的块 β_{i'}（i'>i）里，其值为该块层次 lev(β_{i'}) ≤ v 或其谷值 < lev(β_{i'}) ≤ v。∎

### 1.3 引理 1.2（最大值的首次出现）

设 h 合法、非空、M = max h。则 M 首次出现在位置 1 或 2；若在位置 2 且 k≥3，则 h_3 = M。

证明：若首次出现位置 i≥3，则三元组 (h_{i−2}, h_{i−1}, M) 中 h_{i−1}<M（故 b≠c）且 h_{i−2}<M=max(b,c)，不合法。若 i=2 且 k≥3：三元组 (h_1, M, h_3) 中 h_1<M，故 a≥max(b,c) 不成立，只能 b=c 即 h_3=M。∎

### 1.4 定理 1

(a) **任意拼接合法**：任一层次 ≤ m 的块词 β，κ(β) ∈ {0..m}^k 且合法。
(b) **存在**：每个合法序列都是某个块词的拼接。
(c) **唯一**：每个序列至多是一个块词的拼接。
(d) **截断块只能在末尾**：对 0≤a<v，good(a,v,c) ⟺ c=v；因此 (a,v) 后若还有项，该项必为 v，三项合成 T_{v,a}。所以只需 S、T 两种「内部块」和一个可选的末尾 E。
于是（不交并）合法序列(值 ≤ m) = B_m^* · ( 合法序列(值 ≤ m−1) ⊔ E_m )，其中 B_m = {S_m} ∪ {T_{m,a}}，E_m = {E_{m,a}}；展开即 B_m^*⋯B_0^* ⊔ ⨆_{j=1}^m B_m^*⋯B_j^* E_j。

证明。
(a) 值域：层次 ≤ m，谷 < 层次。三元组 (h_p,h_{p+1},h_{p+2})：若 p 非谷，由引理 1.1 h_{p+1},h_{p+2} ≤ h_p，满足 a≥max(b,c)；若 p 是 T_{v,a} 的谷，三元组是 (a,v,v)，b=c；若 p 是 E 的谷，E 是最后一块、p+1 是最后位置，没有以 p 开头的三元组。
(b) 对长度 k 归纳（k=0 是空块词）。设 h 合法非空，M=max h。由引理 1.2：若 h_1=M，令 β_1=S_M，余下 h'=(h_2..h_k) 仍合法（它的三元组都是 h 的三元组），由归纳 h'=κ(β')，且 β' 的层次 ≤ max h' ≤ M，故 (S_M, β') 是块词。若 h_1<M=h_2：k=2 时 h=E_{M,h_1}；k≥3 时 h_3=M，令 β_1=T_{M,h_1}，余下 (h_4..h_k) 合法，同理接上。
(c) 设 κ(β)=h 非空。β 中所有值 ≤ lev(β_1)，且 lev(β_1) 本身出现在 β_1 中（S 的唯一项，T 的第 2、3 项，E 的第 2 项），故 lev(β_1)=max h=:M。若 h_1=M，则 β_1 不能是 T/E（它们以谷 <M 开头），只能是 S_M；若 h_1<M，则 β_1 ∈ {T_{M,h_1}, E_{M,h_1}}，而 E 只能是唯一的最后一块，所以 β_1=E 当且仅当 k=2。故 β_1 由 h 唯一决定，剩余块词 (β_2..β_r) 的拼接是 h 去掉前 |β_1| 项，对长度归纳即得唯一。
(d) a<v 时 a≥max(v,c) 不可能，所以 good(a,v,c) ⟺ c=v。递归形式：取块词中层次为 m 的最长前缀（全是 S_m、T_{m,·}，或以 E_{m,·} 结束——此时它就是整个块词的结尾），其余部分是层次 ≤ m−1 的块词；由 (c) 这种拆分唯一。∎

### 1.5 统计量（【已证明】）

对 h=κ(β)：(i) asc(h) = #T + #E；(ii) h 以上升结尾 ⟺ β 末块是 E；(iii) max h = lev(β_1)；(iv) h 完整时末项 = lev(β_r)；(v) 值集 = {各块层次} ∪ {各谷值}。
证明：上升 h_p<h_{p+1} 要求 p 不是非谷位置（引理 1.1），即 p 是谷；反之每个谷后面紧跟其层次（> 谷），构成上升。故上升 ↔ 谷，个数 #T+#E，得 (i)。最后一对构成上升 ⟺ 位置 k−1 是谷 ⟺ 末块是 E（T 的谷后还有两项），得 (ii)。(iii) 见 (c) 的证明。(iv)：末块是 S 或 T，末项是其层次。(v) 显然。∎

## 2. 定理 2：母函数（含上升数）

**定理 2**【已证明】。按权 x^{长度} y^{上升数}，单块 S_v ↦ x，T_{v,a} ↦ y x³（a 有 v 种），E_{v,a} ↦ y x²（v 种）。由定理 1 的递归形式与 1.5(i)：

  G_m(x,y) = ( G_{m−1}(x,y) + m y x² ) / (1 − x − m y x³)，G_{−1} = 1（层次 ≤ −1 的块词只有空词）。

展开：G_m = 1/P_m + y x² Σ_{j=1}^m j·Π_{v=j}^m b_v^{−1} = W_m/P_m，W_m := 1 + y x² Σ_{j=1}^m j P_{j−1}。

**推论 2.1**【已证明】（与 (C2) 一致）。j y x³ P_{j−1} = (1−x−b_j) P_{j−1} = (1−x)P_{j−1} − P_j，求和望远镜得 x W_m = 1 − P_m − x Σ_{j=0}^{m−1} P_j（m≥1 时用 P_0 = 1−x；m=0 时两边都是 x）。y=1 即 (C2) 的 x P_m G_m = 1 − P_m − x Σ_{j<m} P_j。[c2b.T2.WP]

**推论 2.2**【已证明】（引理 1 的 s-细化 / 三变量方程）。取 (1−x−m y x³)G_m = G_{m−1} + m y x² 的 [x^k y^s] 系数：
  U_k(m,s) = U_k(m−1,s) + U_{k−1}(m,s) + m·U_{k−3}(m,s−1) + m·[k=2][s=1]（k,s,m≥0；约定 U_k(−1,s) = [k=0][s=0]（即 G_{−1}=1），k<0 或 s<0 时取 0）。
乘 t^m 求和：F(x,t,y) := Σ U_k(m,s) x^k t^m y^s 满足 (1−x−t)F − y x³ t ∂F/∂t = 1 + y x² t/(1−t)²（y=1 即 (C5)）。组合意义：首块是 S_m（U_{k−1}(m,s)）、T_{m,a}（m U_{k−3}(m,s−1)，多一个上升）、整个序列是 E_{m,a}（k=2，s=1），或不含 m（U_k(m−1,s)）。[c2b.T2.pde_xty]

## 3. 系数提取：「m 根竖线 + T 块 + S 块」模型

**引理 3.1（竖线模型）**【已证明】。对 s 个 T 与 L 根竖线 | 组成的所有字（共 C(s+L,s) 个），
  Σ_字 Π_{每个 T} ( j + 该 T 右侧的竖线数 ) = h_s(j, j+1, …, j+L)。
证明：从左到右读出各 T 的值 λ = j + 右侧竖线数，得到弱降序列 j+L ≥ λ_1 ≥ … ≥ λ_s ≥ j；反之任一这样的弱降序列唯一确定一个字（第 t 个 T 左侧恰有 (j+L)−λ_t 根竖线）。所以左边 = Σ_{j+L≥λ_1≥…≥λ_s≥j} λ_1⋯λ_s = h_s(j..j+L)。∎ [c2b.T3.tbar：L≤5、s≤5、j≤3 暴力]

**定理 3**【已证明】。0≤j≤m，n≥0：
  [x^n y^s] Π_{v=j}^m (1 − x − v y x³)^{−1} = H(m,s,j)·C(n+m−j−2s, n−3s)。

组合证明：由定理 1 的递归（只用 S、T，层次限制在 [j,m]），Π_{v=j}^m b_v^{−1} 是「只含 S、T 块、层次 ∈ [j,m] 的块词」的母函数。把块词写成字母表 {S, T, |} 上的字：从层次 m 出发，每当层次下降 1 就写一根竖线，末尾补竖线到层次 j；共 m−j 根竖线，每个字母的层次 = j + 其右侧竖线数。层次序列 ↔ 竖线位置是双射。长 n、s 个 T 时 S 有 n−3s 个。(1) 去掉 S 后是 s 个 T、m−j 根竖线的字，T 的谷有 (层次) 种选法，由引理 3.1 加权和为 h_s(j..m)；(2) 把 n−3s 个 S 插回 s+(m−j)+1 个缝隙：C(n−3s+s+m−j, n−3s) = C(n+m−j−2s, n−3s) 种。相乘即得。∎
代数证明：u := x³/(1−x)，b_v = (1−x)(1−v y u)，Π_{v=j}^m b_v^{−1} = Σ_s h_s(j..m) y^s x^{3s} (1−x)^{−(m−j+1+s)}，而 [x^n] x^{3s}(1−x)^{−N} = C(n−3s+N−1, n−3s)。∎
[c2b.T3.coef：n≤30、0≤j≤m≤12，对双变量级数逐系数]

**引理 3.2**【已证明】。(i) h_s(0,1,…,m) = h_s(1,…,m)；(ii) 1≤j≤m 时 h_s(j..m) = {m+s ⧵ m}_j := 把 [m+s] 分成 m 个非空块且 1,…,j 两两不同块的划分数（Broder r-Stirling 数）；(iii) j=1 即 h_s(1..m) = S(m+s,m)。

### 6.5 规范三项 u 分解（观察）

因 {1,x,x²} 是 Q((x)) 在 Q((u)) 上的基，G_m(1−x)^{m+1} = F_0(u) + xF_1(u) + x²F_2(u) 唯一（【已证明】），于是 U_k(m) = Σ_s Σ_{r=0}^2 f_{r,s}(m)·C(k+m−r−2s, m+s)，系数可由三角消元唯一求出。但系数有正有负（如 m=2：f_{0,s} = −2^s（s≥1），m≥5 时 f_{2,s} 出现负值），且 f_{r,s}(m) = Σ_{i=1}^m α_{r,i}(m) i^s 型（F_r 是以 Π(1−iu) 为分母的有理函数）——写成闭式又回到双和。故它不构成更短公式（`logs/c2b_explore3_canonical.log`；只是观察，不作为正式结论）。

## 7. 合法满射词 N(k,q)

N(k,q)：长 k、值集恰为 {0..q−1} 的合法词数（条件只依赖大小关系）。按结尾拆成 N = N^c + N^E（不以 / 以上升结尾），容斥 N^c(k,q) = Σ_i (−1)^{q−i}C(q,i)A_{i−1}(k)，N^E 同理（A_{−1}(k)=[k=0]，E_{−1}≡0）。[c2b.T8.Nsplit：与 DFS 暴力 k≤8 一致；N 的容斥 = core.N_from_U，k≤30、q≤12]

### 7.1 定理 7（N^c 的骨架 + 覆盖公式）

**T 骨架**：s 条弧 (v_1,a_1),…,(v_s,a_s)，0≤a_t<v_t，v_1≥…≥v_s（同头的弧有序）。它等价于一个 T/竖线字带谷（引理 3.1 的双射）。端点集 cov(σ) = {v_t} ∪ {a_t}。R(p,s) := 端点集恰为 {0..p−1} 的 s 弧骨架数。

**定理 7**【已证明】。N^c(k,q) = Σ_{s≥0} Σ_{p=0}^{2s} C(q,p)·R(p,s)·C(k−2s+p−1, s+q−1)。
证明：不以上升结尾、值集为 V={0..q−1} 的合法词 ⟷ 不含 E 的块词（定理 1、1.5）⟷（骨架 σ：其 T 块序列；S 的放法：k−3s 个 S 放进 s+(q−1) 个字母的 s+q 个缝隙）。词的值集 = cov(σ) ∪ {含 S 的段的层次}。值 v∉cov(σ) 时第 v 段没有 T（否则 v 是头），这一段恰是一个缝隙，v 出现 ⟺ 该缝隙至少一个 S。所以满射 ⟺ 这 d = q−|cov(σ)| 个指定缝隙都非空，放法 C(k−3s−d+s+q−1, s+q−1)。按 X = cov(σ) 分组：骨架条件（a<v、头非增）在保序双射下不变，故端点集恰为 X（|X|=p）的骨架数 = R(p,s)，X 有 C(q,p) 种。代入 d=q−p 即得。∎
[c2b.T8.Nc：k≤30、q≤12]

**R 的性质**：
- R(p,s) = Σ_{i=0}^p (−1)^{p−i}C(p,i)·S(i−1+s, i−1)（i=0 项取 [s=0]）【已证明】：端点 ⊆ {0..i−1} 的骨架数 = h_s(0..i−1) = S(i−1+s,i−1)（引理 3.1、3.2）= Σ_p C(i,p)R(p,s)，二项式反演。
- R(p,s) = 0 当 p>2s 或 (s≥1, p<2)；R(2s,s) = (2s−1)!!【已证明】：端点两两不同 ⟹ 头两两不同、弧序由头决定，弧构成 {0..2s−1} 的完美匹配。
- R(p,s) = Σ_k ⟨⟨s,k⟩⟩·C(2s−2−k, 2s−p)（⟨⟨·,·⟩⟩ 为二阶 Euler 数）【已验证 1≤s≤11】：由 GKP (6.43) {x ⧵ x−n} = Σ_k ⟨⟨n,k⟩⟩ C(x+n−1−k, 2n) 取 x=i−1+s、n=s，再按 Vandermonde 展开成 C(i,p) 基即得（本推导引用教科书恒等式，故只标已验证）。
- 前几行（p 从 0 起）：s=2: 0,0,1,4,3；s=3: 0,0,1,12,36,40,15；s=4: 0,0,1,28,183,496,655,420,105。
[c2b.T8.R：骨架暴力枚举 p≤7、s≤4 = 容斥；(2s−1)!! 与消失性 s≤8；c2b.T8.Reul]

与标准容斥比较：N^c 的标准式 Σ_i (−1)^{q−i}C(q,i)Σ_s S(i−1+s,i−1)C(k+i−1−2s,k−3s) 是交错双和、约 q·k/3 项；定理 7 是正项双和、约 k²/9 项（与 q 无关），代价是需要辅助三角 R。

### 7.2 N^E：同类公式需要三重和

**命题 7.2**【已证明 + 已验证】。N^E(k,q) = Σ_{s≥1} Σ_{p,h0} R'(p,s,h0)·C(q−1−h0, p−1−h0)·C(k−1−2s+p−h0, s+q−2−h0)，R'(p,s,h0) = 端点恰为 {0..p−1} 且最小头为 h0 的 s 弧骨架数，且
  R'(p,s,h0) = Σ_{z1=0}^{h0} Σ_{z2=0}^{p−1−h0} (−1)^{z1+z2} C(h0,z1) C(p−1−h0,z2) [ h_s(h0−z1, …, p−1−z1−z2) − h_s(h0−z1+1, …, p−1−z1−z2) ]。
证明：由命题 5.1(ii)（补末项保持值集），N^E(k,q) = 长 k+1、末块为 T 的完整满射词数。骨架的最后一个 T 层次 j = 最小头；S 只能放在最后一个 T 之前的 s+q−1−j 个缝隙里；层次 < j 的段在最后一个 T 之后，不能放 S，所以低于 j 的值必须被骨架覆盖；未覆盖的 q−p 个值都在 j 之上，各需一个 S。把骨架标准化到 {0..p−1}（最小头 h0），嵌入 {0..q−1} 时 {0..h0} 必须原样对应，其余 p−1−h0 个值在 q−1−h0 个位置里选：C(q−1−h0, p−1−h0)。S 的放法 C((k+1−3s)−(q−p)+(s+q−1−h0)−1, s+q−2−h0)。
R' 的公式：对「未被覆盖的值集」Z 容斥（Z ∌ h0，因为 h0 是头），端点 ⊆ {0..p−1}∖Z 的骨架保序重标号到 {0..w−1}（w=p−|Z|），h0 变为 r0 = h0−|Z∩[0,h0)|；「头全 ≥ r0」的骨架数是 h_s(r0..w−1)（引理 3.1），「最小头恰为 r0」再减去 h_s(r0+1..w−1)；按 z1=|Z∩[0,h0)|、z2=|Z∩(h0,p−1]| 分组即得。∎
[c2b.T8.NE：R' 容斥式与骨架暴力枚举一致（s≤4），Σ_{h0}R' = R（s≤10）；N^E 公式 = 直接 DP 的容斥值，k≤30、q≤12]
展开后是五重（含两重交错）求和、辅助数组三维，不算「短公式」。

### 7.3 「a 值覆盖」容斥等价于标准容斥（【已证明】）

对完整满射词，设 Λ = 非空段的层次集（必含 q−1），其余值须被谷覆盖。对未覆盖集 Z 容斥：Σ_{Z⊆V∖Λ} (−1)^{|Z|}·#(谷避开 Z)。谷避开 Z 时删去 Z 并保序重标号，得到值集大小 q−|Z| 的词，其中原 Λ 的段非空、其余段为空——对 Λ 求和后只剩「顶层段非空」这一条件，计数 A_{q−1−z}(k) − A_{q−2−z}(k)（只依赖 z=|Z|，Z⊆{0..q−2} 有 C(q−1,z) 种）。用 C(q−1,z)+C(q−1,z−1)=C(q,z) 合并，恰为标准容斥 Σ_i (−1)^{q−i}C(q,i)A_{i−1}(k)。所以这条路线不会给出新的短公式；定理 7 改为对「骨架未覆盖的值」做**正向**计数（每个未覆盖值强制一个 S），才得到正项双和。

## 8. 最终推荐公式（一页）

记 S(n,k) 为第二类 Stirling 数，H(m,s,j) = h_s(j,j+1,…,m)（= r-Stirling {m+s ⧵ m}_j；H(m,s,0)=H(m,s,1)=S(m+s,m)）。

**U_k(m) = Σ_{s=0}^{⌊k/3⌋} S(m+s,m)·C(k+m−2s, k−3s) + Σ_{j=1}^{m} j·Σ_{s=0}^{⌊(k−2)/3⌋} H(m,s,j)·C(k−2+m−j−2s, k−2−3s)。**

- 第一项 = 不以上升结尾的序列（单和，每个 s 是单项），第二项 = 以截断块 E_j 结尾的序列。
- 按上升数细化：U_k(m,s) = S(m+s,m)C(k+m−2s,k−3s) + Σ_j j H(m,s−1,j) C(k+m−j−2s, k+1−3s)；母函数 G_m(x,y) = W_m/P_m。
- 等价的「单和减双和」：U_k(m) = A_m(k+1) − Σ_{j=1}^m A^{(j)}_m(k)，与 (C4) 逐项相同。
- 何时用：单个 (k,m) 值或需要按 s 分层、需要正项/组合意义时；O(mk) 次大整数运算。要整张表时用引理 1 的三项递推（O(km)）。
- 何时不要指望更短：u 型单和对 1≤m≤30 已被严格排除（定理 6），参数盒内的单和与两项 u 型和全部被排除。

## 9. 失败或未解决的方向

1. **消去截断块部分的 j-和**：试了 (i) 生成函数望远镜：只得到一个关系 xΣQ_j + x³ΣjQ_j = Q_1 − 1，无法分别闭合；(ii) 对 u 部分分式：Σ_j Q_j 化为截断指数和（§6.6 的式子，[c2b.T9.misc]），无闭式；(iii) 规范三项 u 分解：系数有正有负，闭式仍是双和（§6.5）。卡在：E 部分的极点结构（u=1/i 处留数元不是 x 的单项式）正是定理 6 的阻碍，说明「单个 u 型和」从结构上不可能。
2. **u 型单和**：已严格证明不存在（m≤30，逐 m 证书）；没有对一般 m 的统一证明（需要统一控制 N(ν_i) 的素因子，未做）。
3. **其它形状单和**：参数盒（11760 族）内全部被反驳；盒外（更大参数、两个以上二项式的乘积、下指标含 k 且系数 ≠1、非二项式型系数）未穷举。
4. **E(k,m,s) 单项**：一般不成立（(2,2) 反例）。
5. **N(k,q) 的单和/短双和**：「a 值覆盖」容斥与标准容斥等价（§7.3）；改用正向覆盖只对 N^c 成功（定理 7），N^E 需要再记录骨架最小头，成为三重和（R' 本身又是交错双和）；R(p,s) 只找到「二项式反演」与「二阶 Euler 数卷积」两种表示，未找到乘积型闭式。
6. **两项 u 型**：E(k,m)（3≤m≤6）、U_k(m)（2≤m≤6）在盒内全部形状对不可解（§6.4）；没有对一般 (N_1,N_2) 的结构性证明。
